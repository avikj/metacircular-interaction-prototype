# When Smith path holonomy is predictively silent

**Status.** Exact elementary theorem and finite control for the path action in
`SMITH_PATH_HOLONOMY.md`. The theorem is standard action/quotient mathematics;
no novelty claim is made. The value is operational: it identifies when the
new path coordinate may be erased again without losing an admitted future.

## 1. Invariant observations collapse the future

Let a monoid `M` act on a set `X`, and let `{O_i : X -> Y_i}` be the admitted
task family. Define future-behavior equivalence by

\[
x\sim_F y \quad\Longleftrightarrow\quad
O_i(m x)=O_i(m y)\quad\text{for every }i\text{ and }m\in M.
\]

Suppose every admitted task is invariant under the action:

\[
O_i(m x)=O_i(x)\quad\text{for every }i,m,x. \tag{1}
\]

Then

\[
x\sim_F y
\quad\Longleftrightarrow\quad
O_i(x)=O_i(y)\quad\text{for every }i. \tag{2}
\]

Indeed, future equivalence implies current equality by taking the identity
action. Conversely, current equality and (1) give
`O_i(mx)=O_i(x)=O_i(y)=O_i(my)` for every future action. Thus the minimal
predictive quotient is exactly the fiber quotient of the current joint
observation. Nontrivial motion inside a fiber is real but irrelevant to this
declared task family.

For a generated monoid it is enough to verify (1) on the generators, because
invariance is closed under composition.

## 2. Smith control: element order

The two paths in `SMITH_PATH_HOLONOMY.md` induce a nonidentity automorphism
`H` of

\[
F=\operatorname{coker}(\operatorname{diag}(1,2,6))
 \cong \mathbb Z/2\oplus\mathbb Z/6.
\]

It moves `(0,1)` to `(1,4)` in these two displayed cyclic coordinates. Let

\[
O(z)=\operatorname{ord}(z)\in\{1,2,3,6\}.
\]

Every group automorphism preserves element order: if `nz=0`, then
`nH(z)=H(nz)=0`, giving `ord(H(z)) <= ord(z)`; applying the same argument to
`H^{-1}` gives the reverse inequality. Hence `O(H^kz)=O(z)` for every future
schedule loop `H^k`.

The raw cokernel has 12 elements, while the exact predictive quotient for the
order task has four fibers, one for each of `1,2,3,6`. The path transport is
nontrivial, but storing which Smith schedule occurred cannot change any
present or future order answer. Endpoint erasure is therefore sound for this
task.

More generally, any family of characteristic invariants preserved by all
automorphisms admitted as schedule holonomies satisfies (1). This does not
license erasure for tasks outside that family.

## 3. False controls locate the boundary

Two stronger observations fail in different ways.

1. The chosen `Z/2` coordinate has only two current outputs, but it is not
   `H`-invariant. One future application splits its fibers, and behavioral
   minimization returns four predictive states. Present observation alone is
   insufficient.
2. The identity observation retains all 12 elements. It admits chosen
   coordinates as tasks, so no two distinct classes may merge.

Thus the result is not “holonomy never matters.” It is:

> Holonomy memory is unnecessary exactly for an admitted future-task family
> on which the generated holonomy monoid acts trivially.

This is the control requested by the earlier obstruction. The obstruction
showed that full endpoint erasure can be unsound; the control shows that full
trace retention can be equally nonminimal.

# Moonshot portfolio: use the great problems as barrier oracles

**Research map, 2026-08-11.  No Millennium-problem solution is claimed.**

The original Distinction archive treated a universal coherence slogan as if it
resolved every major problem.  The corrected high-ambition policy is harder:
assume each problem is solvable, but use a century of failed approaches to
identify the exact kind of obstruction that any successful language must
carry.

There is no single “information-loss” theorem behind all the problems.  Four
different mechanisms recur:

1. set-fiber noninjectivity and failure of descent/reconstruction;
2. analytic concentration or commutator defects at a critical scale;
3. cohomological/local-to-global obstruction groups;
4. spectral sign, coercivity, or gap failure after the correct quotient.

Conflating them recreates the old corpus.  Computing each one produces a
research program.

## Ranked live bets

### Tier A: highest theorem return per agent-week

1. **RH — index-one converse (`R0006`).**  The proof candidate is now
   independently accepted: RH is equivalent to the arithmetic intersection
   form having positive index at most one on every finite test space.  The
   harvested next theorem is a general finite-$r$ signature-transfer lemma for
   $J$-paired spectra.  Remaining work is prior-art compression and a formal
   interpolation/tail kernel, not a claim to have proved RH.
2. **Prime pairs — rational-fiber two-body formula.**  Derive an exact fixed-$q$
   formula that distinguishes true Goldbach constrained sums from rank-one
   all-pairs squares, and true gap correlations from Hermitian proxies.  Keep
   primitive/imprimitive characters, $p\mid q$ corrections, pole--pole,
   pole--zero, and zero--zero terms.  The first genuinely new target is a
   useful uniform range in $q$, not the classical fixed-$q$ decomposition.
3. **Information kernel.**  Formalize deterministic descent, target
   sufficiency, zero-error side information, and data processing once, then
   attach Shannon or quantum quantities only when a distribution or CPTP
   channel is declared.  The first Lean core has landed in
   `Pairfield/FiniteInformation.lean`.
4. **P versus NP — the product-distribution negation boundary.**  Test the
   live question of whether monotone/nonmonotone Clique simulations that are
   understood on slices extend to product distributions, beginning near
   $p=1/n$.  Enumerate optimal small formulas by SAT/ILP and emit LRAT/DRAT
   evidence.  Witness entropy is not time complexity; no counting slogan may
   substitute for a lower bound.

### Tier B: bounded CPU platforms with honest outputs

- **Poincare control arm.**  Certify a finite census of simply connected
  triangulated 3-manifolds by normal-surface/Pachner proof objects.  The aim is
  to calibrate flow/surgery/certificate machinery, never to extrapolate a
  finite census.
- **Smooth four-dimensional Poincare.**  Build a bounded Kirby-calculus atlas:
  every presentation in a precisely limited class either reduces to the
  standard sphere or becomes a minimal unresolved move class.
- **BSD.**  Assemble exact descent, Cassels--Tate, modular-symbol, Tamagawa,
  regulator, and interval-$L$ data into a replayable rank-zero/one certificate;
  search for a new congruence subfamily only after reproducing known converse
  theorems.  The exact local/global defect is $\Sha$, not an entropy metaphor.
- **Hodge.**  Reproduce a known monodromy/invariant-tensor computation, exhibit
  explicit cycles spanning the invariant Hodge subspace by exact intersection
  rank, then alter one deformation parameter.  Period matching without exact
  rational reconstruction is not an algebraic cycle.
- **Langlands.**  Use Sturm/multiplicity-one style finite-determination theorems
  to turn finitely many exact Hecke matches into a global certificate for one
  low-rank lift.  This is a genuine zero-error coding theorem when the finite
  bound is proved.

### Tier C: reproduce a known theorem before major compute

- **Yang--Mills.**  Prove a finite reflection-positive transfer/min--max gap
  ledger and one rigorous block-spin defect bound.  A finite lattice gap,
  gauge-fixing mass, or entanglement entropy does not construct the 4D
  continuum pure-gauge theory.
- **Navier--Stokes.**  Study the exact coarse-graining defect
  $\tau_\ell=\overline{u\otimes u}_\ell-\bar u_\ell\otimes\bar u_\ell$ and
  flux $-\nabla\bar u_\ell:\tau_\ell$.  A proposed scale-invariant defect
  criterion is valuable only if it is strictly weaker or more computable than
  established CKN/$L^\infty_tL^3_x$/Besov criteria.  DNS and finite Galerkin
  smoothness are not evidence for the Clay statement.

## Per-problem kill rules

| problem | opportunity in the tension | immediate seductive error to kill |
|---|---|---|
| RH | pole quotient versus global spectral sign | finite zero checks, random-matrix agreement, or an undefined self-adjoint operator |
| P vs NP | witness projection versus efficient section | fiber cardinality, Kolmogorov complexity, or Grover as a general lower bound |
| Navier--Stokes | weak compactness versus nonlinear concentration | DNS, weak-solution nonuniqueness, or Euler analogies as a Clay resolution |
| Yang--Mills | gauge quotient versus continuum coercive gap | finite-lattice/strong-coupling gaps, Higgs mass, or gauge-fixing artifacts |
| Hodge | correct analytic type versus algebraic witness | integral counterexamples, numerical periods, or positivity as a cycle |
| BSD | local Selmer data versus global points and $\Sha$ | numerical vanishing, parity, or one-prime Selmer data as full BSD |
| Poincare | flow monotonicity plus classified surgery | “flow smooths everything” or finite-depth rewrite confluence |

## Information/QIT gate

Every branch must state:

```text
state space | observer/channel | target | exact fiber or defect
distribution (if entropy is used) | recovery map | certificate | falsifier
tensor/operator-algebra factorization (if QIT is used)
```

Shannon loss, target sufficiency, zero-error side capacity, Shannon channel
capacity, computation time, Kolmogorov complexity, and quantum capacity are
different quantities.  Contextuality requires an actual measurement scenario
with no global section.  Entanglement requires a state, a bipartition, and a
nonseparability witness.  The arithmetic tensor $a\otimes a$ is separable.

## Allocation rule

Do not launch a seven-front “solution campaign.”  Run the Tier A bets; use the
other problems as solved-case and barrier libraries.  A branch earns more
compute only after it supplies:

1. an exact typed map into the native problem;
2. a defect not already equivalent to a known criterion;
3. the cheapest decisive falsifier;
4. a bounded certificate type;
5. a path by which repeated reasoning becomes cheap code or a formal lemma.

This is maximal ambition with maximal selectivity: the goal is not to say all
problems are related, but to make every century-old obstruction increase the
discovery rate on every other front.

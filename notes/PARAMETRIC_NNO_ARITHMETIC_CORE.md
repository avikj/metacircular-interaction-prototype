# One arithmetic engine: parametric recursion, not an endomorphism catalog

## The reduction

The compact seed is not “`N`, successor, and selected endomorphisms.”  An
endomorphism preserving `0` and successor is forced by induction to be the
identity.  If “endomorphism” instead means an arbitrary map `N -> N`, then
addition, multiplication, remainder, and every other desired operation have
only been hidden in a catalog of maps.

The exact reusable property is a **parametrically stable natural-number
object**.  In type-theoretic form, for every parameter type `X`, state type
`Y`, initializer `a : X -> Y`, and update `u : X -> Y -> Y`, there is a map

\[
  \operatorname{run}_{a,u}:X\times\mathbb N\longrightarrow Y
\]

with

\[
  \operatorname{run}(x,0)=a(x),\qquad
  \operatorname{run}(x,S n)=u(x,\operatorname{run}(x,n)),
\]

and the type of maps satisfying these equations is contractible.  Thus
uniqueness is proof-relevant: two constructions satisfying the same recursion
are joined by a canonical identity path.  Categorically this is the NNO
recursor stable under parameters/finite products.  Ordinary primitive
recursion is recovered by enlarging the state to retain the current counter.

## Arithmetic-core theorem schema

**Schema.** In a constructive setting with finite products, decidable natural
order, finite types, and a parametrically stable NNO, every primitive-recursive
arithmetic process is an instance of this one `run`.  Consequently:

- `x+n` uses state `N`, initializer `x`, update `S`;
- `x*n` uses initializer `0`, update `y |-> y+x`;
- `n mod m` uses the finite state `Fin m` and cyclic successor;
- bounded subtraction, comparison, quotient, and remainder use product states
  retaining counters and flags;
- Euclidean descent uses state `(a,b)` and the transition
  `(a,b) |-> (b,a mod b)` when `b != 0`, fixed when `b=0`, iterated for a
  proven bound such as `a+b`;
- extended Euclid carries the coefficient matrix in the same state, so Bézout
  data are output, not a separately privileged oracle.

CRT is then not another constructor.  For coprime positive `m,n`, reduction
gives

\[
  \rho:\operatorname{Fin}(mn)\to
  \operatorname{Fin}(m)\times\operatorname{Fin}(n).
\]

Extended-Euclid coefficients define its inverse, and the two round trips are
identity paths proved from the Bézout equation and uniqueness of bounded
residue representatives.  Thus CRT is a path/equivalence between two state
presentations generated by the same recursion engine.

This is the desired non-privileging: the operations differ by state and
transition, not by foundational status.  Their proofs remain different
because termination bounds and invariants are mathematical content.

## Precise obstruction

The NNO property does **not** select which update is relevant.  It converts a
given finite description `(X,Y,a,u)` into its unique execution.  Therefore it
collapses arithmetic execution but not mathematical perception or program
synthesis.  Nor does it imply that an arbitrarily extended rewrite language
has canonical finite normal forms: that additionally requires a terminating,
confluent presentation or a finite behavioral quotient.

The proposal should therefore be stated as:

```text
parametric NNO recursion + constructively presented state/update
  + proofs of termination/invariance
  + identity paths between extensionally equal executions.
```

“N plus endomorphisms” is either trivial (structure-preserving) or circular
(arbitrary).

## Existing repository contact

`notes/ATLAS_OF_N.md` proves the NNO/free-one-generator equivalence and the
rigidity of `(N,0,S)`.  `formal/cubical/NaturalMachine/Digits.agda` constructs
the digit odometer and its round trips by natural recursion.
`NaturalMachine.ResidueTransport` correctly treats residue and CRT observations
as maps out of `N`; the present schema says how residue maps themselves can be
generated by the same parametric fold rather than admitted as opaque inputs.
The Lean Smith/Bézout modules demonstrate the later Euclidean state outputs.

## Rigor boundary

The universal-property reduction and the endomorphism obstruction are
standard constructive mathematics.  The displayed Euclid bound is a schema
whose concrete implementation must still define remainder and prove strict
descent in the chosen proof language.  No claim is made that the repository
already exposes one generic recursor API connecting all listed instances.

# A finite co-Yoneda weave

## Status

Lean-checked bounded instance of Delta 25 task T25.C.  The formal file is

Source provenance: catalog item `UP-D0025`,
`collab/upstream/raw/D0025-eternal-golden-braid-indras-net.txt`, section 6 and

colimit/coend of representables, and for an exact distinction between a whole

## What is inherited and what is instantiated

The repository's pinned Mathlib already proves the general density theorem as
`CategoryTheory.Presheaf.colimitOfRepresentable`: every type-valued presheaf
under its stated universe/category hypotheses is the colimit of its canonical
diagram of representables.  The present file does not reprove or claim this
theorem.  It instantiates it at one finite category and one chosen field:

- category: the preorder category on `Fin 2`, the walking arrow `0 -> 1`;
- source jewel: `0`;
- target jewel: `1`;
- global field: the presheaf `yoneda.obj 1` represented by the target.

Thus `globalFieldIsColimitOfRepresentables` is a checked term of

```
IsColimit (Presheaf.coconeOfRepresentable GlobalField).
```

This is the colimit-of-representables half of the requested finite instance.

## Why a bare union is not the weave

Observe the chosen field from the source.  Before gluing, a profile is a
factorization through a selected jewel:

```
BareProfile = Sigma c : Fin 2, (c -> 1) x (0 -> c).
```

Composition evaluates such a profile to the global field value `0 -> 1`.
The coend incidence generator for a step `f : c -> d` is

```
(f ; outgoing, incoming)  ~  (outgoing, incoming ; f).
```

`WovenProfile` is the `Quot` generated by this categorical incidence.  Lean
checks an explicit equivalence

```
WovenProfile ~= (0 -> 1).
```

The inverse chooses the source factorization, and the incidence equation with
`f = incoming` proves that every factorization has the same quotient class as
its composite.  This is an actual quotient by transition data, not a set-like
union with a suggestive name.

The control is exact.  The factorization through `0` and the factorization
through `1` are unequal in `BareProfile`, because their Sigma indices differ.
They become equal in `WovenProfile` by the nonidentity thread's incidence
generator.  Consequently the quotient projection has no left decoder: the
woven value retains the composite global-field element but not the chosen
intermediate presentation.

This loss is not a defect in density.  It is the gluing that makes the
presentation independent of a redundant factorization.  The bare union has
more presentation information and therefore fails to be the chosen global
field.

## Scope and non-reduction fence

This proves only the walking-arrow category, the target-representable field,
and its source component.  It does not implement a higher category of Braid
passes, enriched coends, higher coherence, or the project's proposed global
field.  The general density theorem is inherited from Mathlib, not newly
established here.

Huayan and Indra's Net are not reduced to this category-theoretic model.  The
formal result supplies one exact mathematical distinction requested by the
user-authored analogy; it neither translates mutual identity/interpenetration
into a quotient nor proves a metaphysical claim.

# Fixed points after quotient are twisted traces before quotient

Let a finite group `G` act on a finite set `X`, and let `f:X->X` be
`G`-equivariant. It induces an endomap `fbar:X/G->X/G`. Then

```text
#Fix(fbar) = (1/|G|) sum_(g in G) #{x in X : f(x)=g.x}.       (1)
```

This is the exact square joining orbit descent, compatible fixed sections,
and arithmetic trace localization. Ordinary fixed points are only the
identity sector `g=1`; quotienting creates fixed orbits which may have no
point fixed by `f` itself.

## Proof

An orbit `O` is fixed by `fbar` exactly when `f(x)` lies in `O` for one, hence
every, `x in O`. If `O` is not fixed, it contributes zero to every set in the
sum.

Suppose `O` is fixed. For each `x in O`, the set of `g` satisfying
`f(x)=g.x` is a coset of `Stab(x)`, so has size `|Stab(x)|`. Summing first over
`x` gives

```text
sum_g #{x in O : f(x)=g.x}
  = |O| |Stab(x)|
  = |G|.
```

Thus each fixed orbit contributes exactly `|G|` to the numerator of (1), and
each nonfixed orbit contributes zero. Division proves the formula.

Equivalently, the natural map

```text
Fix(f)/G -> Fix(fbar)
```

need not be surjective. Its missing fibers are detected by the nonidentity
twisted sectors.

## Smallest failure

Let `G=C2` act regularly on `X={0,1}` and take `f` to be the flip. The raw
fixed locus is empty, but `X/G` is a singleton and its induced map is the
identity. The sector counts are

```text
#{f(x)=x} = 0,       #{f(x)=flip(x)} = 2,
```

so `(0+2)/2=1`, the one fixed quotient orbit. This is the one-loop analogue
of the nonsurjective limit/orbit comparison in `LIMIT_ORBIT_COMPARISON.md`.

## Arithmetic specialization

Let `a` be a unit of order `m` modulo `n`. The cyclic group generated by `a`
acts on `Z/n`, and multiplication by any `b` is equivariant. Equation (1)
becomes

```text
#Fix(b on (Z/n)/<a>)
  = (1/m) sum_(k=0)^(m-1) gcd(b-a^k,n),                 (2)
```

because `(b-a^k)x=0 mod n` has `gcd(b-a^k,n)` solutions.

For `n=15`, `a=2`, `m=4`, and `b=4`, the induced map fixes all five doubling
orbits. The ordinary fixed set of multiplication by four is `{0,5,10}`, only
two doubling orbits. The four twisted counts are

```text
(gcd(3,15), gcd(2,15), gcd(0,15), gcd(-4,15))
  = (3,1,15,1),
```

whose average is five. The large `k=2` sector records that `f` itself is the
group element `a^2`: its action vanishes after quotient, although it is not
the identity on points.

This is a finite twisted Burnside/Lefschetz formula, not an index theorem or
a new classical result. Its value here is exact composition: the arithmetic
gcd character from `ARITHMETIC_LEFSCHETZ.md` becomes the complete correction
term for exchanging fixed points with holonomy quotient.

# धारा-गणित — from equations to streams: the roadmap for certified computation on living data

*Technical roadmap; checked claims name modules, steps are marked owed.
dhārā (stream) + gaṇita (mathematics): compound built here, 2026-08-24,
claimed of no source.*

## The bridge already standing

Every equation the machine lands is stated over an ENVIRONMENT —
`eval : (ℕ → ℕ) → Tm → ℕ`, quantified over all `e`.  The environment is
where arbitrary data enters: **a data stream is an `e`; a theorem over
all environments is a certified transformation of any data ever plugged
in.**  Tonight's crystal already reads as a pipeline calculus:
`sum-++` = sharded aggregation is exact; the comm/assoc instances =
out-of-order arrival licenses; the erasure laws (`nf-sound`) =
dead-branch elimination with witness; the unfold laws (`mulSuc`) =
strength reduction.  `Anujna` = the type of a query-plan rewrite that
cannot lie.

## The deeper layer, already checked

- Streams as `Orbit` (coinductive, in-tree) with path-equality =
  bisimulation.
- Compression with a receipt: `FutureBehavior` / `BehavioralBFS` — the
  behavioral quotient is the least state sufficient for declared
  futures (causal states), with the memory cost priced exactly
  (`CAUSAL_MEMORY`: d = rank T, with the typed spectrum grading
  classical/quantum realizability).
- Honest statistics: `FactorsThrough ≃ FiberConstant` — an aggregate
  descends through a quotient of the data iff constant on fibres;
  decoder constructed; computation rule refl.  Every summary a node
  publishes either factors, or names the fibre it forgets
  (`SankramanaSesa`: the loss stays pointwise).
- Transmission form: generator + remainder, never a dump — the minimal
  form of a real datum is a finite rule plus its antya-saṃskāra
  (Mādhava's kept correction; movement 63).

## The steps, in order, each with its gate

1. **Windowed laws at ℕ-scale** (days).  Prefix-scan, sliding-window
   sum, chunked fold — statable in the current signature, landable by
   the current mouth.  Gate: the crystal loop itself.
2. **The environment widened** (weeks).  `List ℕ` / word streams as
   first-class data in the candidate language; the reflection rung
   carries over because `nf-sound` never cared what `e` was.  Gate:
   kernel, as always.
3. **Causal-state compression as a service** (weeks–months).  A node
   holding a real series answers only through licensed rewrites — the
   transcript of an analysis IS a proof; the Rust loop already
   executes the quotient construction with exact counters.  Gate: the
   seed criterion, run on a PAID workload (the first demo that is also
   the first revenue-shaped witness).
4. **Two-party analysis without data movement** (months).  Nodes
   compose analyses by exchanging licenses, never raw data — privacy
   as a corollary of shipping witnesses instead of datasets
   (`IndraJala` §6; the exchange organ already moves witnessed rows).
5. **Signal-domain residuals** (the mountain).  Lossy, noisy, analog
   codecs — spike trains included — with the residual law applied per
   channel.  This is the BCI-grade step (`SetuManas`), and it is owed,
   not sketched: the laws exist, their instantiation over real signals
   does not yet.

## The invariant across all five

Nothing new is trusted at any step.  Every widening rides the same two
rails the whole corpus rides: the kernel judges, and the transport owes
its residual.  A stream is just a place where the fibre law meets the
world at higher sample rate.

## 1. The uniform local constant

Let `p` be prime and set

```text
e = v_p(2),        so e = 1 if p = 2 and e = 0 if p is odd,
q = p^(1+e),       so q = 4 if p = 2 and q = p if p is odd.
```

Fix `k >= 1+e`, write `G_k = (Z/p^k Z)^*`, and let

```text
B_k = ker(G_k -> (Z/q Z)^*) = (1 + qZ)/p^k Z.
```

**Fact A (cyclicity, standard).** `B_k` is cyclic of order `p^k/q = p^(k-1-e)`.

For odd `p` this is the cyclicity of `1 + pZ_p`; for `p = 2` it is the
cyclicity of `1 + 4Z_2`, generated by `5`. Both are classical local
arithmetic (Serre, *A Course in Arithmetic*, II §3; Neukirch, *Algebraic
Number Theory*, II §5). **The exponent `1+e` is the whole point:** `1 + 2Z`
mod `2^k` is *not* cyclic for `k >= 3` — it is `Z/2 x Z/2^(k-2)` — which is
precisely the fault line `TWO_ADIC_CONFINEMENT.md` §3 attributes to Gauss's
split between art. 57 and art. 90. Taking the kernel over `(Z/q)^*` rather
than `(Z/p)^*` repairs it uniformly, because `v_p(2)` is exactly the amount
by which `p = 2` must be pushed.

**Fact B.** The subgroups of `B_k` are exactly `1 + p^j Z` for
`1+e <= j <= k`, of order `p^(k-j)`, totally ordered by inclusion.

*Proof.* A finite cyclic `p`-group has exactly one subgroup of each order
dividing it, and `1+p^j Z` has order `p^(k-j)`. `[]`

**Definition (local unit signature).** For `U <= G_k` put

```text
l(U) = the unique l in [1+e, k] with  U cap B_k = 1 + p^l Z,      (level)
s(U) = |image of U under G_k -> (Z/q Z)^*|,                       (residue index)
```

`l` is well defined by Fact B; the trivial intersection is `l = k`. Note
`s(U)` divides `phi(q) = p^e (p-1)`. For `p = 2`, `phi(q) = 2` and
`s in {1,2}`, so `s = 2^sigma` recovers the one-bit `sigma` of
`TWO_ADIC_FILTRATION_SIGNATURE_REVIEW.md` §1.

## 2. Theorem U — the index, with no case split

**Theorem U.** For every prime `p`, every `k >= 1+e`, and every `U <= G_k`,

```text
|U|         = p^(k-l) * s,                                          (2.1)
[G_k : U]   = (p-1) * p^(l-1) / s.                                  (2.2)
```

*Proof.* Reduction mod `q` gives the exact sequence

```text
1 -> B_k -> G_k -> (Z/qZ)^* -> 1,
```

surjective because `Z/p^kZ -> Z/qZ` is a surjective ring map and units lift.
Restrict it to `U`: the kernel of `U -> (Z/qZ)^*` is `U cap B_k`, of order
`p^(k-l)` by Fact B and the definition of `l`; the image has order `s` by the
definition of `s`. Hence `|U| = p^(k-l) s`, which is (2.1).

For (2.2), `|G_k| = phi(p^k) = (p-1)p^(k-1)`. Divide:

```text
[G_k : U] = (p-1)p^(k-1) / (p^(k-l) s) = (p-1) p^(l-1) / s.   []
```

The proof uses no primitive root, no generator of `G_k`, no index calculus,
and no chart-depth lemma. It needs only that `l` is well defined, i.e. Fact A,
i.e. the single choice `q = p^(1+e)`.

**Corollary U1 (no confinement).** `U = G_k` iff `l = 1+e` and `s = phi(q)`.

**Corollary U2 (branch count).** Written as a case split on `s`, (2.2) has
`tau(phi(q))` branches: `tau(2) = 2` at `p = 2`, and `tau(p-1)` at odd `p`.
Theorem II's two branches are not a `p = 2` peculiarity and not the general
shape either — they are `tau(phi(4)) = 2`. At `p = 7`, for instance, the same
formula has `tau(6) = 4` branches. **"Meets `3 mod 4`" is the `p = 2` shadow
of a full divisor `s | p-1`**, which is why it looked like a stray extra bit.

## 3. The three earlier results are specializations

**(a) Theorem GG is `k = 1`, `p` odd.** Then `e = 0`, `q = p`, and
`B_1 = (1+pZ)/pZ = {1}`, so `l = 1 = k` forced. (2.1) gives `|U| = s`, the
order of the image in `(Z/p)^*` — Theorem GG's "the classes reachable by
multiplication alone are exactly the subgroup generated". (2.2) gives
`[G_1 : U] = (p-1)/s`. Gauss's index calculus then evaluates `s` as
`(p-1)/gcd(p-1, ind g_1, ..., ind g_r)` when a primitive root is chosen, which
is GG's displayed formula. **The gcd is a way to compute `s`, not the reason
the index formula holds** — Theorem U holds whether or not `G_k` is cyclic.

**(b) (2.1) of the review is `p = 2`.** Then `e = 1`, `p - 1 = 1`, `s = 2^sigma`:

```text
[G_k : U] = 1 * 2^(l-1) / 2^sigma = 2^(l-1-sigma),
```

which is the review's (2.1) exactly, and `|U| = 2^(k-l)2^sigma = 2^(k-l+sigma)`.

**(c) Theorem II's two branches.** `sigma = 0` is `U <= B_k`, giving index
`2^(l-1)`; `sigma = 1` is `U` meeting `3 mod 4`, giving `2^(l-2)`. Both
branches of `TWO_ADIC_CONFINEMENT.md` (1.1).

**The 44-instance table, re-derived by hand from (2.2).** `p = 2`, so
`index = 2^(l-1)/s`:

| generators | `l` | `s` | `2^(l-1)/s` | table |
|---|---|---|---|---|
| `3`    | `v_2(3^2-1)=3`   | 2 | `2^2/2 = 2`   | 2 |
| `5`    | `v_2(5-1)=2`     | 1 | `2^1/1 = 2`   | 2 |
| `7`    | `v_2(7^2-1)=4`   | 2 | `2^3/2 = 4`   | 4 |
| `17`   | `v_2(17-1)=4`    | 1 | `2^3/1 = 8`   | 8 |

| `3, 7` | 2 (`21 = 5 mod 8`)| 2| `2^1/2 = 1`   | 1 |

All seven rows agree, hence all 44 instances (the table records the index as

**An odd-`p` instance, the region no prior result covered.** `p = 3`, `k = 2`,
`G_2 = (Z/9)^*` of order 6. For `U = <8> = {1,8}`: `U cap B_2 = {1}` so
`l = 2`, and `8 = 2 mod 3` so `s = 2`. Then (2.1) gives `|U| = 3^0 * 2 = 2`
and (2.2) gives index `2 * 3^1 / 2 = 3`. Both correct. For `U = <4> = {1,4,7}`:
`l = 1`, `s = 1`, `|U| = 3^1 = 3`, index `2 * 3^0 / 1 = 2`. Correct.

## 4. Theorem V — the 2-adic anomaly is exactly `v_p(2)`

The second half of the two notes is chart depth, where the striking claim is
asymmetric: at `p = 2` a formed organism can read unboundedly fewer digits
(`FORMED_UNIT_FILTRATION_DEPTH.md` §4), while at odd `p` the saving is zero
(*ibid.* Theorem 5.1). Those are proved separately by different arguments. They
are one statement.

**Theorem V.** Let `U <= G_k` and let `u, w in U` with
`delta = v_p(u+w)` satisfying `e < delta` and `delta + e < k`. Then

```text
l(U) <= delta + e.                                                  (4.1)
```

*Proof.* Put `h = u w^(-1) in U`. Then `h + 1 = (u+w)w^(-1)`, so
`v_p(h+1) = delta`. Now `h - 1 = (h+1) - 2` with `v_p(2) = e < delta`, so by
the ultrametric equality case

```text
v_p(h-1) = min(delta, e) = e.
```

Therefore `v_p(h^2-1) = v_p(h-1) + v_p(h+1) = e + delta`. Since
`e + delta >= 1 + e`, we get `h^2 in 1 + p^(1+e)Z = B_k`; and `delta + e < k`
gives `h^2 != 1` in `G_k`, so `h^2` is a nontrivial element of `U cap B_k`.
By definition of the level, `l(U) <= v_p(h^2-1) = delta + e`. `[]`

**Corollary V1 (odd `p`: the saving is impossible).** For odd `p`, `e = 0`, so
(4.1) reads `l <= delta`. By `FORMED_UNIT_FILTRATION_DEPTH.md` Theorem 3.3 the
depth is then `d* = delta+1`, the ambient value, and the gap is `0`. This is
that note's Theorem 5.1, now a one-term specialization.

**Corollary V2 (`p = 2`: the saving is possible, and only just).** For `p = 2`,
`e = 1`, so (4.1) reads `l <= delta+1`. This permits `l > delta`, and only in
the single case `l = delta+1`. By Proposition 4.2 of that note the gap is then
`delta - 1 = l - 2`, and the `g = 2^t-1` family attains it.

**The unification.** Both notes locate the anomaly in an informal "extra factor
of `2`" available at `p = 2` and not at odd `p`
(`FORMED_UNIT_FILTRATION_DEPTH.md` §5, after (5.1)). Theorem V says that
factor is literally `v_p(2)`, entering through `v_p(h-1) = v_p((h+1) - 2)`.
The chart-depth asymmetry and the index formula's `q = p^(1+e)` are the same
constant appearing twice: `2` is a unit at odd `p` and the prime itself at
`p = 2`, and every difference between the two notes' halves reduces to that.

## 5. What this changes

- **One formula replaces three.** (2.2) covers prime moduli, odd prime powers,
  and `2^k` with no branches. The `tau(phi(q))` branch count (Corollary U2)
  predicts in advance how many cases a specialization will appear to have.
- **The odd `p^k` region is now covered**, and it is not the odd-prime case
  with a level bolted on: `l` genuinely varies for `k >= 2` (§3's `p = 3`
  examples have `l = 1` and `l = 2`), whereas at `k = 1` it is forced.
- **The level language survives the transfer.** Seed 1 asked whether it would.
  It does, and Fact A says why: `l` is well defined exactly because
  `1 + p^(1+e)Z_p` is cyclic, which is a statement about `v_p(2)` and not
  about `p` being odd.
- **The state update is uniform.** `FORMED_UNIT_FILTRATION_DEPTH.md` §7 makes
  `l(U)` persistent organism state updated by `l <- min(l, v_p(lam^2-1))`.
  Theorem U says the organism must carry `(l, s)`, and `s` is updated by
  `s <- |<s-image, lam mod q>|` — a divisor of `phi(q)`, not one bit, once
  `p` is odd.

- **No novelty claimed.** The exact sequence `1 -> 1+qZ -> (Z/p^k)^* ->
  (Z/q)^* -> 1`, the cyclicity of `1+p^(1+e)Z_p`, and `v_p(h^2-1) =
  v_p(h-1)+v_p(h+1)` are all standard. What is claimed is the assimilation:
  that these three repository results are one formula, that the branch count
  is `tau(phi(q))`, and that the 2-adic chart-depth anomaly is the single
  term `v_p(2)`. No literature search was performed and none is needed for a
  claim at this level; a novelty claim would require one
  (`collab/PROTOCOL.md` §4).
- **Known-false controls.** Three statements must fail, and do:
  (i) *"`l` alone determines the index"* — `<5>` and `<3,5>` both have `l = 2`
  with indices `2` and `1`, since `s` differs (this is codex-valence's
  correction, which Theorem U absorbs as the `s` factor);
  (ii) *"`q = p` works uniformly"* — at `p = 2`, `1+2Z` mod `2^k` is not
  cyclic for `k >= 3`, so Fact B fails and `l` is not well defined: the level
  of `{1, 2^(k-1)+1}` would be ambiguous against `1+2^(k-1)Z`;
  (iii) *"the saving is a `p = 2` phenomenon because `2` is small"* — Theorem V
  shows it is because `v_p(2) = 1`, and the proof breaks at exactly the step
  `v_p(h-1) = e`, not anywhere involving the size of `p`.
- **Scope.** `k >= 1+e`. Multiplicative reachability only; Theorem HH's
  observation that addition dissolves confinement is untouched, so this
  constrains *reachability*, never *cost*. Nothing here treats an organism
  holding `p` itself (`TWO_ADIC_CONFINEMENT.md` §5, third limit), and nothing
  treats several primes at once.

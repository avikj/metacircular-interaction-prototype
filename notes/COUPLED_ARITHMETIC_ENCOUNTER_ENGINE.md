# A coupled arithmetic encounter engine

**Status.** Exact finite construction joining three previously proved organs.
It is an executable interface, not a claim that arithmetic contains the whole
research organism or that the constructor grammar forms itself.

## 1. What the engine actually does

The engine retains a field of proposals.  A proposal has a statement, a
formation cost, a possible capability gain, and a provenance path.  Provenance
does not prove the statement.  It preserves how the statement became available
and which exact return later changed it.

An encounter is admitted only when an existing arithmetic procedure can replay
its answer.  Equal currently visible data are placed in one fiber.  If two
members of that fiber demand different lawful future actions, the proposal
that identified them is refuted.  The response difference supplies a required
new coordinate.  Only then does the engine install a sensor and compile an
action using it.

In common language: two things looked the same; arithmetic made them behave
differently; the difference that mattered became a new way of seeing; that
way of seeing became an operation available to later work.

## 2. Elementary encounter theorem

Let `q:X -> Y` be a visible observation and let `r:X -> R` be a replayable
lawful response.  If

```text
q(x)=q(x') but r(x) != r(x'),
```

then no controller `c:Y -> R` satisfies `r=cq`.  Every exact controller must
retain a refinement `q':X -> Y'` separating `x` and `x'`.  On a finite witness
family, the number of distinct response laws inside a `q`-fiber is a lower
bound on the controller states required over that fiber.  Retaining the
response class attains the bound.

The proof is immediate: `c(q(x))` would have to equal two unequal values.  For
the lower bound, states assigned the same controller memory must have the same
future response; the response fibers therefore inject into memory states.

This theorem is small, but it prevents a large false claim.  The error does not
generate a repair from nothing.  The lawful continuation `r`, inherited from
an exact mathematical ecology, makes the missing distinction determinate.

## 3. Smith descent: the residual acquires an origin

The verified reducer `smith_residual_machine.py` supplies the response `r`:
the kind of the first strict Euclidean descent step.  The matrices

```text
((2,0),(1,7))    and    ((2,1),(0,7))
```

both expose scalar remainder `1`, but their certified first actions are
respectively `column-residual` and `row-residual`.  Hence the scalar proposal

```text
next action = function(scalar remainder)
```

is impossible.  When the second witness arrives, the engine installs the
sensor `typed-residual-origin` and the action `certified-next-step`.  The
certificate replays `L A R = D`, unimodularity of `L,R`, diagonal form, and
the divisibility condition.  No action kind is supplied by the caller.

This is proposal geometry meeting exact resistance.  Euclidean division and
Smith normal form make the proposal available; the matrices answer it; their
unequal lawful continuations deform it; a verified controller becomes a new
capability.

## 4. Two-adic reach: one missing bit changes two actions

For a subgroup `U <= (Z/2^k Z)^*`, the inherited proposal retained only the
principal-unit level `ell`.  The encounters `U=<5>` and `U=<3,5>` at `k=8`
have the same level `ell=2`, but indices `2` and `1`.  The level-only proposal
is therefore refuted.

The least elementary residue depth separating the two reachable subgroups is
modulo four.  The new sensor is

```text
sigma(U)=1 iff U contains an element congruent to 3 mod 4.
```

The exact-sequence proof then compiles two operations from the shared
signature `(ell,sigma)`:

```text
index = 2^(ell-1-sigma),

d* = delta+1   if ell <= delta,
     1         if ell > delta and sigma=0,
     2         if ell > delta and sigma=1.
```

Thus the newly formed bit does not merely repair a description.  It makes
multiplicative reachability and optimal valuation observation executable.
The same bit acts in both without making them identical.

## 5. Environmental task: forgetting changes lawful execution

The engine next admits an environmental port: which distinction is presently
required?  On the three-state action

```text
e(0)=0,  e(1)=0,  e(2)=2,
```

the rich task distinguishes all three states.  Its action monoid contains a
nonidentity idempotent and is not a group.  The task “distinguish `2` from
`{0,1}`” forms the stable two-state quotient.  On it `e` becomes identity, so
the effective action monoid is a group.

The rich state is retained rather than destroyed.  If a later environmental
task asks to distinguish `0` from `1`, the stored port reopens three-state
execution and `e` again appears irreversible.

This is an exact Pareto consequence, not a balance slogan:

| execution | effective states | separates `0,1` | action reversible |
|---|---:|---:|---:|
| task quotient | 2 | no | yes |
| reopened rich view | 3 | yes | no |

Neither view dominates.  The environment changes which projection is lawful;
the retained derivation makes the change reversible at the level of access,
not at the level of the underlying action.

## 6. The coupled cycle and its boundary

The implemented cycle is

```text
inherited proposal with provenance
-> exact encounter inside one visible fiber
-> replayable response collision
-> refutation plus smallest admitted separating sensor
-> proof-compiled action
-> changed capability and proposal priority
-> environmental task quotient or reopening
-> changed future attention.
```

After Smith formation, the refuted scalar proposal leaves the attention
frontier.  After task contraction, the live proposal becomes reopening the
forgotten distinction if a future task demands it.  Attention is therefore a
function of what has actually survived, not a fixed lesson list.

What remains outside the construction is equally important:

- the candidate sensor grammars are inherited;
- provenance preserves lineage but does not certify historical interpretation;
- the environment supplies task changes;
- there is no scalar value function over the Pareto consequences;
- the engine does not form its own physical boundary, energy supply, or moral
  field;
- arithmetic is the resistant terrain on which the coupling is exact, not a
  reduction of life, thought, or the full repository to arithmetic.

The next honest interface is to let a residual alter the candidate sensor
grammar itself while retaining an independently replayable reason that the new
grammar extension was necessary.

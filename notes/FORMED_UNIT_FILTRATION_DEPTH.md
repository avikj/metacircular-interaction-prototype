## 0. The question that was asked

`notes/ADAPTIVE_VALUATION_ADDITION.md` proves an ambient minimal-precision
theorem: over **all** integers, with `s = a+b != 0` and `v = v_p(s)`, the least
residue depth `k` for which `(a mod p^k, b mod p^k)` determines `v_p(a+b)` is

```text
k = v + 1.                                                          (0.1)
```

codex-ananta then asked, precisely:

> when observations are restricted to already formed arithmetic-life states
> rather than all integers in the residue fiber, does causal availability make
> a coarser chart sufficient, or must the formation set be closed under the
> theorem's explicit perturbations before minimality can transport?

The answer is **a coarser chart can suffice, and the saving is unbounded** — at
`p = 2` only. Closure under the perturbations is sufficient but far from
necessary, and it is the wrong invariant. The right invariant is a single
integer attached to the organism's formed unit group: its **level**.

## 1. The formed locus

An arithmetic organism that forms numbers by multiplication holds a
multiplicatively closed set. Fix a prime `p` and a set `G` of formed integers
prime to `p`. The formed locus is

```text
F = { p^i * u : i >= 0, u in <G> },                                  (1.1)
```

where `<G>` is the multiplicative monoid generated by `G`. Work at precision
`p^K`. The image `U` of `<G>` in `(Z/p^K)^*` is a **group**: the image of a
monoid in a finite group is closed under inverses.

For `a, b` in `F` define the formed chart depth

```text
D_F(a,b) = min{ k : v_p(a'+b') = v_p(a+b) for all a',b' in F
                    with a' = a, b' = b  (mod p^k) }.                (1.2)
```

Restricting the quantifier to `F` can only shrink the fiber, so `D_F <= v+1`
always. The content is how far below it can fall.

Only the equal-valuation case matters. If `v_p(a) = i < j = v_p(b)`, then
depth `i+1` already exhibits `v_p(a) = i` and `v_p(b) >= i+1`, and the
ultrametric equality gives `v = i`; depth `i` is insufficient as soon as `F`
contains two elements of valuation exactly `i` whose sum has valuation `> i`.
So for unequal input depths `D_F = v+1` and there is nothing to save. Write
therefore `a = p^i u`, `b = p^i w` with `u, w` units and

```text
delta = v_p(u+w) = v - i >= 1.                                       (1.3)
```

## 2. Two reductions

Let `U[d] = { lam in U : lam = 1 (mod p^d) }`, the congruence filtration of the
formed unit group.

**Lemma 2.1 (the fiber is exactly a coset).** For `d >= 1`, the depth-`(i+d)`
fiber of `p^i u` inside `F` is `p^i * (u * U[d])`.

*Proof.* A residue mod `p^{i+d}` with `d >= 1` and `p`-valuation `i` forces any
`x` in `F` in that fiber to have `v_p(x) = i` exactly, so `x = p^i u'` with
`u'` in `U`. Then `x = p^i u (mod p^{i+d})` iff `u' = u (mod p^d)`, and since
`u` is a unit this says `u'/u` lies in `U` and is `= 1 (mod p^d)`, i.e.
`u' in u*U[d]`. Conversely every such `u'` is in the fiber. `[]`

This is the shape Madhavi's hostile synthesis
(`collab/messages/madhavi/full_history_hostile_synthesis.md`) names as an
earned collapse: *a measurement fiber that is exactly an orbit of a named
action* — here the multiplication action of the subgroup `U[d]`.

**Lemma 2.2 (the pair test has one parameter).** `v_p` is multiplicative and
`mu` is a unit, so `v_p(u*lam + w*mu) = v_p(u*(lam/mu) + w)`, and `lam/mu`
ranges over the group `U[d]`. Hence

```text
D_F(p^i u, p^i w) = i + d*,
d* = min{ d >= 1 : v_p(u*nu + w) = delta for all nu in U[d] }.       (2.1)
```

The quadratic test over `U[d] x U[d]` collapses to a linear one.

## 3. The level criterion

For `p` odd, `1 + pZ/p^K` is cyclic of order `p^{K-1}`; for `p = 2`,
`1 + 4Z/2^K` is cyclic of order `2^{K-2}`, generated by `5`. Their subgroups
are exactly the `1 + p^e`. Define the **level** of the formed unit group,

```text
l(U) = min{ v_p(lam - 1) : lam in U cap B, lam != 1 },  B = 1+pZ (p odd),
                                                        B = 1+4Z (p = 2).  (3.1)
```

**Lemma 3.1.** `U cap B = 1 + p^{l}`, hence for `d >= 1` (`p` odd) resp.
`d >= 2` (`p = 2`),

```text
U[d] = U cap (1 + p^d) = (1 + p^l) cap (1 + p^d) = 1 + p^{max(l,d)}. (3.2)
```

For `p = 2` and `d = 1` this fails: every unit is `1 (mod 2)`, so `U[1] = U`.

**Lemma 3.2 (constancy).** For `e >= 1` and units `u, w` with
`v_p(u+w) = delta`,

```text
v_p(u*nu + w) = delta for all nu in 1 + p^e   <==>   e > delta.      (3.3)
```

*Proof.* Write `nu = 1 + p^e x` and `u + w = p^delta * eps` with `eps` a unit.
Then `u*nu + w = p^delta*eps + u*p^e*x`. If `e > delta` the valuation is
`delta` for every `x`. If `e < delta`, take `x = 1`: the valuation is `e`,
since `u` is a unit. If `e = delta`, choose `x = -eps/u (mod p)`: the sum is
`p^delta(eps + u x)` with `eps + u x = 0 (mod p)`, so the valuation is at least
`delta + 1`. `[]`

**Theorem 3.3 (the exact depth).** With `d0 = 1` for odd `p` and `d0 = 2` for
`p = 2`,

```text
d* = delta + 1        if l(U) <= delta,
d* = d0               if l(U) >  delta,                              (3.4)
```

except that at `p = 2` the value `d0 = 2` drops to `1` exactly when
`v_p(u*nu + w) = delta` already holds for every `nu` in `U`. Consequently

```text
D_F(a,b) = v_p(a) + d*,   and the saving against (0.1) is
gap = delta + 1 - d*.                                                (3.5)
```

*Proof.* Combine (2.1), Lemma 3.1 and Lemma 3.2: `U[d] = 1+p^{max(l,d)}` is
constant-valued iff `max(l,d) > delta`. If `l <= delta` this first happens at
`d = delta+1`; if `l > delta` it already holds at `d = d0`. `[]`

~~**`d*` depends on the whole formed history only through the single integer
`l(U)`.**~~ At `p=2`, the documented possible drop from `d0=2` to `1`
requires one further bit: whether `U` meets `3 mod 4`. With `sigma(U)=1` in
that case and `0` otherwise, the exact positive-cancellation formula is
`d*=delta+1` if `l<=delta`, `d*=1` if `l>delta,sigma=0`, and `d*=2` if
`l>delta,sigma=1`. Thus `(l(U),sigma(U))`, not `l(U)` alone, is sufficient.
Independent proof and equal-level false controls appear in
`TWO_ADIC_FILTRATION_SIGNATURE_REVIEW.md`.

## 4. At `p = 2` the saving is unbounded

**Theorem 4.1.** Let `t >= 2`, `g = 2^t - 1`, and let the organism have formed
exactly the odd number `g`, so `U = <g>` and `F = {2^i g^j}`. Take `a = 1`,
`b = g`. Then

```text
v_2(a+b) = t,   ambient depth (0.1) = t+1,   D_F(a,b) = 2,
gap = t - 1  ->  infinity.                                           (4.1)
```

*Proof.* `delta = v_2(1+g) = v_2(2^t) = t`. Since `g = 3 (mod 4)`, a power
`g^s` lies in `1+4Z` iff `s` is even, so `U cap (1+4Z) = <g^2>` and

```text
l(U) = v_2(g^2 - 1) = v_2(g-1) + v_2(g+1) = 1 + t > t = delta,       (4.2)
```

using `v_2(g-1) = v_2(2^t - 2) = 1` for `t >= 2`. Theorem 3.3 gives `d* = 2`.
It is not `1`: taking `nu = g` in `U` gives `v_2(1*g + g) = v_2(2g) = 1`, which
differs from `t >= 2`. `[]`

Concretely, for `g = 255` the ambient theorem demands nine base-2 digits of
each input and the formed organism needs two.

The mechanism is visible in (4.2): `g = -1 (mod 2^t)` forces
`v_2(g^2-1) = v_2(g-1) + v_2(g+1) >= 1 + delta`, so the formed unit group's
level lands *strictly past* the cancellation depth. Every perturbation the
ambient proof uses to defeat a coarse chart — `b + 2^k`, `b + c*2^v` — leaves
`F`. It is not that they are hard to realize; they are absent.

## 4.2 How thin the formation history must be (deflation of §4)

Seed 2 below was posed against my own headline, and it bites. The gap of §4 is
sharply bounded by the level itself.

**Proposition 4.2.** At `p = 2`, `gap = delta + 1 - d*` satisfies

```text
gap = 0                     if l(U) <= delta,
gap = delta - 1 <= l(U)-2   if l(U) >  delta and d* = 2.             (4.3)
```

*Proof.* Immediate from (3.4): if `l > delta` then `delta <= l-1`. `[]`

The family of §4 attains the bound, since there `l = t+1` and `delta = t`. So
**an unbounded saving requires an unbounded level**, and a large level is a
severe constraint on what the organism has formed.

**Proposition 4.3.** `l(U) = 2` if and only if some element of `U` is
`5 (mod 8)`. Hence `l(U) >= 3` forces the image of `U` in `(Z/8)^*` to be one
of `{1}`, `{1,3}`, `{1,7}` — every formed odd number must lie in a single one
of those two-element groups.

*Proof.* `l = 2` means some `lam` in `U cap (1+4Z)` has `v_2(lam-1) = 2`, i.e.
`lam = 5 (mod 8)`. The subgroups of `(Z/8)^* = {1,3,5,7}` not containing `5`
are exactly the three listed. `[]`

**Corollary 4.4 (the natural-order organism saves nothing).** If the organism
has formed any two numbers `x = 3 (mod 8)` and `y = 7 (mod 8)`, then
`xy = 21 = 5 (mod 8)` lies in `U`, so `l(U) = 2` and the gap is `0` at every
`delta`. In particular an organism forming the primes in their natural order
holds `3` and `7`, and from that moment its chart depth is exactly the ambient
`v+1`.

So the honest reading of §4 is: **the criterion (3.4) is the result; the
unbounded gap is real but lives only on formation histories thin enough to be
generated inside a two-element subgroup of `(Z/8)^*`** — essentially, a single
generator congruent to `-1` modulo a high power of `2`. The organism of
`notes/ARITHMETIC_LIFE_FIRST_EXECUTION.md`, which forms `2,3,5,7,...`, is not
such an organism. Theorem 4.1 describes infancy, or a deliberately restricted
diet, and I have struck no part of it — but the headline it appeared to
support, "formed organisms compute cancellation cheaply", is false in general
and I withdraw it.

Checked: for `G` in `{[3],[7],[15],[31],[63],[7,23],[7,31],[3,7],[3,5,7,11,13],[17],[97]}`
the observed maximum gap never exceeds `max(0, l-1)`, the `2^t-1` family
attains `l-2`, and both `[3,7]` and `[3,5,7,11,13]` have `l = 2` and gap `0`.

## 5. At odd `p` the saving collapses

**Theorem 5.1.** Let `p` be odd and `delta >= 1`. Then `l(U) <= delta`, hence
`d* = delta + 1` and `gap = 0`: the ambient minimality transports exactly.

*Proof.* Put `h = u * w^{-1}` in `U`. Then `h + 1 = (u+w) w^{-1}`, so
`v_p(h+1) = delta >= 1`, i.e. `h = -1 (mod p)`. Since `p` is odd, `-1 != 1`
mod `p`, so `v_p(h-1) = 0` and

```text
v_p(h^2 - 1) = v_p(h-1) + v_p(h+1) = delta.                          (5.1)
```

In particular `h^2 != 1`, and `h^2` lies in `U cap (1+p) = 1 + p^{l}`, so
`v_p(h^2-1) >= l`. With (5.1), `l <= delta`. `[]`

So the phenomenon of §4 is **exactly 2-adic**, and the proof isolates why: at
`p = 2` both `h-1` and `h+1` are even, and the extra factor of `2` in
`v_2(h-1)` pushes the level of the formed group past the cancellation. At odd
`p` that factor is absent. For `delta = 0` the gap can be `1` (a formed locus
can rule out cancellation with no digits at all), and that is the whole of the
odd-`p` saving.

## 6. Forming one more number destroys the saving

**Corollary 6.1.** At `p = 2`, if the formed set contains any unit `lam` with
`lam = 5 (mod 8)` — for instance the prime `5` itself — then `l(U) = 2`, so
`l(U) <= delta` for every `delta >= 2` and the ambient depth `delta+1`
transports exactly. Since `delta = 1` means `u+w = 2 (mod 4)`, i.e. no
cancellation beyond the forced one, the saving vanishes on the whole
cancellation range.

An organism holding `{2,3}` reads two digits where the ambient theorem demands
`v+1`. The moment it forms `5`, the same computation costs `v+1` digits. The
cost of an arithmetic operation is a function of the formation history, and it
can go **up** when the organism learns a new number. That is a lawful sensor
revision triggered by a formation event, not a bookkeeping artifact.

## 7. What this changes

- The adaptive refinement loop of `ADAPTIVE_VALUATION_ADDITION.md` is not the
  right operation on a formed locus. The organism can compute `l(U)` once from
  its formed generators and then **pre-commit** the depth `v_p(a) + d*` by
  (3.4), reading a fixed number of digits with no refinement round trip.
- `l(U)` is a new, cheap, persistent piece of organism state, updated on each
  formation event by `l <- min(l, v_p(lam^2 - 1))`-type steps. It is the first
  quantity in this thread that measures the *formation history* rather than the
  current inputs.
- Every other minimality claim in the arithmetic-life thread is now suspect in
  the same way, and the test is mechanical: is the perturbation used in the
  lower-bound proof inside the formed locus? See §9.

## 9. Scope limits

- `F` is a **multiplicative** formation set. An organism that also forms sums
  is closed under the ambient perturbations and Theorem 5.1's conclusion
  returns everywhere: the saving is a statement about a multiplicative
  organism, and it is destroyed by additive closure.
- Only one prime at a time. Nothing here says anything about simultaneous
  refinement across primes, and nothing about bit complexity.
- Theorem 3.3 assumes `U` is the image of the formed monoid at a precision
  `K > delta + 1`. `l(U)` computed at precision `K` is correct for all
  `delta < K`; it is not an invariant of a truncation shorter than that.
- No novelty is claimed. Levels of subgroups of `Z_p^*`, the cyclicity of
  `1+pZ_p` and the exceptional structure of `Z_2^*` are standard local
  arithmetic; `v_2(h^2-1) = v_2(h-1) + v_2(h+1)` is trivial. What is claimed
  is the application: the ambient minimal-precision theorem does not transport
  to a multiplicatively formed locus, the exact obstruction is `l(U)`, and the
  failure is unbounded at `p=2` and absent at odd `p`.

## 10. Historical entry, and its boundary

Euclid, *Elements* IX.12:

> "If as many numbers as we please beginning from a unit are in continued
> proportion, then by whatever prime numbers the last is measured, the next to
> the unit is also measured by the same."

(Enunciation as given at
[D. E. Joyce's edition, IX.12](https://mathcs.clarku.edu/~djoyce/java/elements/bookIX/propIX12.html);
Book IX props. 8–13 treat this family.)

The relevant historical formation is that Euclid treats `1, a, a^2, ...` — the
multiplicatively generated locus — as an object with **its own** divisibility
laws, and proves a statement true on that locus which is false of the ambient
numbers: prime content anywhere in the progression is already determined at the
first term. That is the same move made here one level up. Prime content of the
generated locus is decided at the first term (IX.12); depth of *cancellation*
in the generated locus is decided by the level of the generated unit group
(Theorem 3.3). In both cases the generated set is thin in a way that makes an
ambient obstruction unavailable.

Boundary, stated so it is not mistaken for anticipation: Euclid has no
valuation, no residue chart, no unit group, no notion of the precision of an
observation, and IX.12 is not about sums at all. The continuity claimed is one
of mathematical situation — reasoning on a generated locus rather than on all
numbers — and not of statement, method, or intent. The proofs in §2–§6 need
nothing from Euclid, and IX.12 needs nothing from them. The reverse direction
is also live and not developed here: Euclid's proof of IX.12 runs through
IX.11 and VII.30 and is a divisibility argument on the progression, and asking
what the *level* `l(U)` looks like from inside a purely divisibility-based
account of the progression is an open question, not a translated one.

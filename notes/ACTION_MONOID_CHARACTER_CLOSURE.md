# Character sectors under convolution and position

Let `X` be a finite set, `K` a field, `m : X → K`, and let `A` act on
`K^X` by pointwise multiplication:

`(Af)(x) = m(x)f(x)`.

For `v ∈ K^X`, put `S = supp(v)` and `Lambda = m(S)`.

## Diagonal cyclic-space theorem

The cyclic subspace generated by `v` is

`C_m(v) = span {A^j v : j ≥ 0}`

and has dimension exactly `|Lambda|`.  More explicitly,

`C_m(v) = { f : supp(f) ⊆ S and f(x)/v(x) depends only on m(x) }`.

Indeed, every polynomial action has coordinates

`(p(A)v)(x) = p(m(x))v(x)`.

It therefore has the displayed form.  Conversely, interpolation on the
finite set of distinct values `Lambda` produces a polynomial realizing every
function `Lambda → K`: the Lagrange denominator

`product_(mu != lambda) (lambda-mu)`

is nonzero in any field.  Hence the displayed space is exhausted and has one
degree of freedom for each value in `Lambda`.

The minimal polynomial of `A` on this cyclic subspace is exactly

`product_(lambda in Lambda) (t-lambda)`.

It annihilates every supported coordinate.  No polynomial of lower degree
can vanish on every distinct element of `Lambda`.

Thus `v` is cyclic for all of `K^X` exactly when `v` is nowhere zero and `m`
is injective.  For `X=Fin N`, `m(x)=x`, and any multiplicative character
`chi`, this applies because `chi(x)` is nonzero.  Consequently

`Cl_position(span{chi}) = K^X`.

Any nonempty character sector contains such a `chi`, so its least invariant
closure under repeated position multiplication is the full carrier.

`Pairfield.CharacterSectorClosure` machine-checks the finite full-support,
injective case through the determinant identity

`det [v(i)m(i)^j] = (product_i v(i)) det(Vandermonde(m))`

and proves the `N` orbit vectors linearly independent over an arbitrary
field.  The support-relative interpolation statement above is a written proof;
it is not yet formalized.

## Convolution is a different native theorem

For a finite abelian group `G`, convolution by `k` acts on a character by

`k * chi = khat(chi) chi`.

Therefore every span of characters is invariant under every convolution
operator.  This is diagonalization in the Fourier basis, not a consequence of
the Vandermonde proof.  The two results meet only after declaring an action
language:

- convolution language: every character sector is closed forever;
- convolution plus injective position multiplication: every nonempty
  character sector has full invariant closure.

The one-step leakage `phi(N)` for the primitive sector and position operator
is therefore not the eventual correction dimension.  Repeated position
actions force complete decompression.

## Boundaries and next action

The field hypothesis permits Lagrange division.  Over a general commutative
ring, distinct values need not have unit differences, so cardinality of
`m(S)` does not determine cyclic rank.

This theorem is linear.  Closing an observable algebra also forces pointwise
products; closing operator contexts forces multiplication and adjoint.  The
Peres--Mermin Hadamard example shows a further distinction: two commutative
context algebras generate a noncommutative algebra which is a quotient of
their amalgamated free product by physical cross-relations.  That is not a
partition refinement or a consequence of this cyclic-space theorem.

The next exact formal action is the support-relative theorem: construct the
Lagrange spectral idempotents and prove that the cyclic subspace is equivalent
to `K^Lambda`, with the displayed minimal polynomial.  This replaces the
full-support sufficient theorem by the exact classification and gives a
certificate whose size is the number of distinct multiplier values.

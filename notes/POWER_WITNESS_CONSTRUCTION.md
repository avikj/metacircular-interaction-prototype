# Multiplication accelerates the power-witness branch

For (x\ne0), (E=v_p(x)), the least positive ambient valuation witness is
(p^{E+1}). If the prime (p) has already been formed and multiplication is
an earned primitive, its structure permits a construction unavailable for a
general residue representative.

## Binary exponentiation certificate

Let (n=E+1\ge1). Write (n) in binary. Maintain two formed powers:

- `power`, initially (p), representing (p^{2^j});
- `result`, initially absent (the multiplicative unit (1)), accumulating the
  selected powers.

Reading the exponent bits after the leading one can equivalently use the
left-to-right recurrence

\[
z\leftarrow z\cdot z,
\qquad
z\leftarrow z\cdot p\quad\text{when the next bit is }1,
\]

starting at (z=p). Induction on the binary prefix proves that (z) is (p)
raised to the represented prefix. Every multiplication uses already formed
operands, and the terminal value is (p^n).

The number of multiplications is exactly

\[
M_2(n)=\lfloor\log_2n\rfloor+\operatorname{popcount}(n)-1.
\]

Thus

\[
M_2(E+1)\le2\lfloor\log_2(E+1)\rfloor,
\]

logarithmic in valuation depth. The exponent-one endpoint uses zero
multiplications and returns the already formed (p).

## Typed comparison, not a scalar victory

There are now three construction certificates for relevant witnesses:

\[
\begin{array}{c|c|c}
\text{target} & \text{required formed primitive} & \text{event count}\\
\hline
r & \text{successor} & r-1\ \text{successors}\\
r & \text{addition} & L_2(r)\ \text{additions}\\
p^{E+1} & \text{multiplication and }p & M_2(E+1)\ \text{multiplications}
\end{array}
\]

The multiplication certificate is shorter as a count of its own event type,
but it is not a scalar improvement over addition until an exchange rate between
addition and multiplication is declared. Its honest statement is typed and
Pareto-like: it uses no additions after (p) is available, and exponentially
fewer multiplication events in (E) than successor uses successor events.

The prerequisite matters. If (p) is not formed, the trace cannot begin.
More sharply, the multiplicative monoid generated by (1) is ({1}), so
multiplication alone from the initial unit constructs no target (r>1).
For a general critical residue representative, a nontrivial generator may
still generate a monoid missing (r). Binary addition works uniformly because
it can introduce binary digits using the unit; pure multiplication cannot.

## Relation to other costs

This certificate prices construction events only. It does not price:

- residue sensing that locates a critical representative;
- time at which (p) was first formed;
- coherent overwrite memory, governed by chart fibers;
- bit complexity of multiplying growing integers.

These coordinates remain independent by the preceding no-go results.

## Rigor boundary

The algorithm and exact count are proved above. Tests replay every operand
dependency for bounded primes and exponents. No optimal exponentiation-chain
claim is made, and no exchange rate between arithmetic primitives is assumed.

# The minimal retained path coordinate of the R0027 Smith cell

**Author:** cf-tessera.  **Status:** exact symbolic theorem with finite replay.

R0027 (audited, msg 0429) proves that for the cell

\[
A=\begin{pmatrix}2&0\\1&0\end{pmatrix},\qquad
D=\begin{pmatrix}1&0\\0&0\end{pmatrix},
\]

source, exact target, all Smith invariants, and strict pivot descent do not
determine the reducer `U` with `UA=D`; the audit strengthened this to
determinant-unrecoverability by deriving the complete transporter.  Its first
successor seed asks for the *minimal retained path coordinate needed to
replay descent*.  For this cell the answer is exact and small: **one integer
and one sign, and nothing less.**

## 1. The stabilizer is infinite dihedral

Solving `HD = D` over `GL_2(Z)` forces

\[
\operatorname{Stab}(D)=\Bigl\{S_{b,e}=\begin{pmatrix}1&b\\0&e\end{pmatrix}
:\ b\in\mathbb Z,\ e\in\{\pm1\}\Bigr\},\qquad
S_{b,e}S_{b',e'}=S_{b'+be',\,ee'} .
\]

So `Stab(D) ≅ Z ⋊ C_2` with `C_2` acting by negation.  Every element with
`e=-1` is an involution (`S_{b,-1}^2=S_{0,1}`), and the group is generated by
involutions: it is the infinite dihedral group `D_∞`.

## 2. The transporter is a regular `D_∞`-torsor with an explicit chart

The complete transporter (audit, msg 0429) is

\[
T(A,D)=\Bigl\{U_{(k,s)}=\begin{pmatrix}k&1-2k\\-s&2s\end{pmatrix}
:\ k\in\mathbb Z,\ s\in\{\pm1\}\Bigr\},\qquad \det U_{(k,s)}=s .
\]

The chart `c(U)=(U_{00},\det U)=(k,s)` is a bijection `T(A,D)\to
\mathbb Z\times\{\pm1\}`, and it intertwines left multiplication by the
stabilizer with an affine `D_∞` action:

\[
S_{b,e}\cdot U_{(k,s)}=U_{(k-bs,\;es)} .
\tag{1}
\]

This action is free and transitive (given `(k,s)` and `(k',s')`, the unique
solution is `e=s'/s`, `b=(k-k')/s`), so `T(A,D)` is a regular
`D_∞`-torsor and `c` is a torsor chart based at `U_{(0,1)}`.

*Proof of (1).*  Multiply: the first row of `S_{b,e}U_{(k,s)}` is
`(k-bs,\,1-2k+2bs)=(k',1-2k')` with `k'=k-bs`; the second row is
`(-es,\,2es)`.  Both membership equations (`v=1-2u`, `z=-2w`) are visibly
preserved. ∎

## 3. Minimality of the retained coordinate

Say a *replay coordinate* is any function `r` on `T(A,D)` such that `U` is
recoverable from `r(U)` (an injection).  Then:

1. `c` is a replay coordinate: `U_{(k,s)}` is written explicitly from
   `(k,s)`.  Storage is one integer and one bit beyond the endpoint data.
2. No proper quotient of `Z×{±1}` is a replay coordinate: any identification
   of two chart values identifies two genuinely distinct unimodular actions
   (distinct as matrices, by injectivity of `c^{-1}`).
3. Both components are individually necessary.  Dropping the sign identifies
   `U_{(k,1)}` with `U_{(k,-1)}`, which differ already in determinant;
   dropping the integer identifies the infinite shear family, which R0027
   shows is invisible to every endpoint observation.
4. Endpoint data recover **no** partial information about `c`: by R0027 the
   full fiber over any admissible endpoint is all of `Z×{±1}`, so the
   retained coordinate is independent of, and irreducible alongside, the
   endpoint.

Hence the proof-relevant trace of this Smith cell decomposes exactly as

\[
\text{(endpoint + invariants)}\ \times\ \underbrace{(k,s)\in
\mathbb Z\times\{\pm1\}}_{\text{path coordinate}},
\]

and a replayable normalizer must carry precisely the `D_∞`-coordinate —
no less (injectivity fails) and no more (the chart already reconstructs).

## 4. What this changes downstream

- The R0027 audit's "even the determinant is unrecoverable" becomes
  constructive: the sign bit `s` *is* the determinant, and it is one of the
  two retained coordinates, not derivable data.
- For the repository's replayable-trace program (Agda `SmithCapability`
  consumers), the cell-level payload type is fixed by this theorem:
  `Z × Bool` per 2×2 cell of this stratum, acted on by `D_∞` as in (1).
  A trace format storing more is redundant; one storing less cannot replay.
- The generalization target (R0027 seed 3) now has a precise shape: for a
  rectangular stratum, the path coordinate of a cell is a torsor chart for
  the target stabilizer, so "trivial stabilizer" is exactly "no retained
  coordinate needed".

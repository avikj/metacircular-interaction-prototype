# The task, not the method, determines the spectral projector

Status: exact rational representation theorem plus W30 computation; standard
cyclic-module and cyclotomic decomposition mathematics. No novelty claim.

Let `F : Z/W -> Q` be the signal whose translated correlations are queried.
The smallest translation-invariant rational subspace sufficient to retain `F`
and all its shifts is not chosen by naming a Fourier method. It is the cyclic
submodule

    Q[C_W] F = span_Q {T^h F : h in Z/W}.

Because

    Q[C_W] = Q[x]/(x^W-1) = product_(d|W) Q[x]/Phi_d(x),

this generated submodule contains the entire rational `d`-sector precisely
when the signal polynomial `F(x)` is nonzero modulo `Phi_d`. Therefore

    dim Q[C_W]F = sum_(d|W, F mod Phi_d != 0) phi(d).

This is minimal: every translation-invariant subspace containing `F` contains
every polynomial in `T` applied to `F`, hence contains `Q[C_W]F`; the latter is
itself translation-invariant. Its coefficient vector retains every shift and
therefore every cyclic correlation `<F,T^hF>`.

The checker obtains the support by exact polynomial remainders and independently
computes the rank of the 30-by-30 translation-orbit matrix over `Q`.

## W30 falsifies the primitive-only assumption

Take the arithmetic signal

    F(x) = 1 if gcd(x,30)=1, else 0.

Its supported rational character orders are

    1, 2, 3, 5, 6, 10, 15, 30,

with dimensions

    1, 1, 2, 4, 2, 4, 8, 8.

Their sum is 30, matching the exact orbit-matrix rank. Thus the all-shift unit
correlation task requires the full rational regular representation. The single
primitive order-30 sector has dimension only eight and its autocorrelation is
different. The previously installed Ramanujan cache works because it contains
primitive sectors for every divisor `q|30`, not because the `q=30` primitive
sector alone is sufficient.

Controls show task relativity: the constant signal needs only order 1, while
the alternating signal needs only order 2. “Primitive spectrum” is therefore
not a universal minimal representation; exact support is generated by the
encountered task.

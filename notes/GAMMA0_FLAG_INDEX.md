## 1. Setting

Fix r ≥ 1 and a divisor chain D = diag(d₁,…,dᵣ) as above. Write

  M = dᵣ/d₁  (the *level*),  eᵢ = eᵢ^(p) = v_p(dᵢ)  so e₁ ≤ e₂ ≤ … ≤ eᵣ.

Γ₀(D) depends only on the ratios dᵢ/dⱼ, hence only on the eᵢ up to a common
shift at each p. For each p let f₁ < f₂ < … < f_k be the *distinct* values
among the eᵢ and r₁,…,r_k their multiplicities (Σ r_t = r).

Two facts used without proof, both classical and both already in the corpus:

- **(L1)** [R0036] Γ₀(D) = { A ∈ GLᵣ(ℤ) : (dᵢ/dⱼ) ∣ Aᵢⱼ for i > j }.
  The proof that this is a *group* genuinely uses the chain relation
  dᵢ/dⱼ = (dᵢ/d_k)(d_k/dⱼ); see §7.
- **(L2)** SLᵣ(ℤ) → SLᵣ(ℤ/M) is surjective for r ≥ 2 (ℤ/M is semilocal, so
  SLᵣ(ℤ/M) is generated by elementary matrices, each of which lifts).

## 2. The index is a lattice count (Atiyah's lens: it is secretly a geometry)

**Lemma 2.1.** Γ₀(D) = Stab_{GLᵣ(ℤ)}(Dℤʳ), the stabilizer of the sublattice
Dℤʳ ⊆ ℚʳ under the left action of GLᵣ(ℤ).

*Proof.* A·Dℤʳ = Dℤʳ iff D⁻¹AD ∈ GLᵣ(ℤ), iff A ∈ D·GLᵣ(ℤ)·D⁻¹. ∎

**Corollary 2.2.** By orbit–stabilizer and the Smith normal form (two
sublattices of ℤʳ lie in one GLᵣ(ℤ)-orbit iff they have the same elementary
divisors),

  **[GLᵣ(ℤ) : Γ₀(D)] = #{ L ⊆ ℤʳ : ℤʳ/L ≅ ⊕ᵢ ℤ/(dᵢ/d₁) }.**

So the group-theoretic index is a *cotype count of sublattices*: a
partial-flag-variety-shaped object, not an arithmetic accident. (Dividing by
d₁ is harmless: L of cotype (d₁,…,dᵣ) satisfies L ⊆ d₁ℤʳ, and L ↦ d₁⁻¹L is a
bijection onto the cotype (1, d₂/d₁, …, dᵣ/d₁) lattices.)

Corollary 2.2 is the sentence that lets this note be *checked against the
literature* rather than merely asserted — see §10.

## 3. The Chinese remainder step (the dayan reduction)

**Lemma 3.1.** [GLᵣ(ℤ) : Γ₀(D)] = |GLᵣ(ℤ/M)| / |S|, where

  S = { Ā ∈ GLᵣ(ℤ/M) : (dᵢ/dⱼ) ∣ Āᵢⱼ for i > j }.

*Proof.* Let π : GLᵣ(ℤ) → GLᵣ(ℤ/M). Since every dᵢ/dⱼ divides M, we have
Γ₀(D) = π⁻¹(S) exactly, so the index equals [im π : S ∩ im π].
By (L2), im π = GLᵣ(ℤ/M)^± := det⁻¹({±1}) — **not** all of GLᵣ(ℤ/M); this is
the step where a careless argument slips, because GLᵣ(ℤ) → GLᵣ(ℤ/M) is *not*
surjective (already at r = 1).

The correction is exact. det : S → (ℤ/M)^× is surjective, because S contains
every diagonal matrix diag(u,1,…,1). Hence for g ∈ GLᵣ(ℤ/M) there is s ∈ S
with det s = det g, so s⁻¹g ∈ SLᵣ(ℤ/M) ⊆ GLᵣ(ℤ/M)^±: that is,
GLᵣ(ℤ/M) = S·GLᵣ(ℤ/M)^±. Restricting the surjection GLᵣ(ℤ/M) → S\GLᵣ(ℤ/M) to
GLᵣ(ℤ/M)^± is therefore still surjective, with fibers the cosets of
S ∩ GLᵣ(ℤ/M)^±. So

  [GLᵣ(ℤ/M)^± : S ∩ GLᵣ(ℤ/M)^±] = [GLᵣ(ℤ/M) : S] = |GLᵣ(ℤ/M)|/|S|. ∎

**Lemma 3.2 (multiplicativity).** Writing M = ∏_p p^{m_p} with
m_p = eᵣ^(p) − e₁^(p), CRT gives ℤ/M ≅ ∏_p ℤ/p^{m_p} compatibly with the
congruence conditions, hence GLᵣ(ℤ/M) ≅ ∏ GLᵣ(ℤ/p^{m_p}) and S ≅ ∏ S_p. So

  [GLᵣ(ℤ) : Γ₀(D)] = ∏_p index_p,  index_p := |GLᵣ(ℤ/p^{m_p})| / |S_p|.

This is Sunzi's aggregate step doing exactly the work it was invented for:
one simultaneous congruence system per prime, recombined without loss. ∎

*(Both halves of Lemma 3.2 are verified exhaustively in the Agda module —
`crtGL12`, `crtΓ12`, `crtGL10`, `crtΓ10`.)*

## 4. The local count

Fix p, put m = m_p, and normalise e₁ = 0 (permitted: only ratios matter), so
eᵣ = m.

Let T = { A ∈ Mᵣ(ℤ/p^m) : p^{eᵢ−eⱼ} ∣ Aᵢⱼ for i > j }. Since eᵢ − eⱼ ≤ m for
all i > j, the number of admissible values of Aᵢⱼ is p^{m−(eᵢ−eⱼ)}, so

  |T| = p^{r²m − G},  **G := Σ_{i>j} (eᵢ − eⱼ)**.

T is closed under multiplication (the flag relation again) and is an additive
subgroup of Mᵣ(ℤ/p^m), and S_p = T ∩ GLᵣ(ℤ/p^m).

**Step 1 (invertibility is a mod-p condition).** det A is a unit of ℤ/p^m iff
det A ≢ 0 mod p. So S_p = (π_p|_T)⁻¹( π_p(T) ∩ GLᵣ(𝔽_p) ) where
π_p : Mᵣ(ℤ/p^m) → Mᵣ(𝔽_p).

**Step 2 (the mod-p image is a parabolic).** For i > j, eᵢ − eⱼ ≥ 1 exactly
when i and j lie in *different* blocks of the composition (r₁,…,r_k), and
= 0 when they lie in the same block. Hence π_p(T) = B, the block upper
triangular subalgebra of Mᵣ(𝔽_p) for that composition; π_p|_T is a surjective
additive homomorphism onto B (lift a forced-zero entry by 0), so all its
fibers have size |T|/|B|.

**Step 3.** A block upper triangular matrix over 𝔽_p is invertible iff each
diagonal block is. So

  |B ∩ GLᵣ(𝔽_p)| / |B| = ∏_{t=1}^{k} |GL_{r_t}(𝔽_p)| / p^{r_t²}
                        = ∏_t ∏_{s=1}^{r_t} (1 − p^{−s}),

and therefore |S_p| = p^{r²m − G} · ∏_t ∏_{s=1}^{r_t}(1 − p^{−s}).

**Step 4.** |GLᵣ(ℤ/p^m)| = p^{r²m} ∏_{s=1}^{r}(1 − p^{−s}). Dividing:

  **index_p = p^{G} · ∏_{s=1}^{r}(1 − p^{−s}) / ∏_{t=1}^{k} ∏_{s=1}^{r_t}(1 − p^{−s}).**  ∎

## 5. Three closed forms

Write [ r ; r₁,…,r_k ]_p for the **Gaussian multinomial**

  [ r ; r₁,…,r_k ]_p = ∏_{s=1}^{r}(p^s − 1) / ∏_{t}∏_{s=1}^{r_t}(p^s − 1)
                     = # 𝔽_p-points of the partial flag variety GLᵣ/P.

Clearing the powers of p in §4 Step 4 (the exponent bookkeeping is
Σ_t r_t(r_t+1)/2 − r(r+1)/2 = −E with **E := Σ_{u<t} r_u r_t**) gives:

> **Theorem A.** For a divisor chain D = diag(d₁ ∣ … ∣ dᵣ),
>
>   **[GLᵣ(ℤ) : Γ₀(D)] = ∏_p  p^{G_p − E_p} · [ r ; r₁,…,r_k ]_p**
>
> with G_p = Σ_{i>j}(eᵢ − eⱼ), E_p = Σ_{u<t} r_u r_t, eᵢ = v_p(dᵢ), and
> (r₁,…,r_k) the multiplicities of the distinct valuations. The exponent is
> non-negative: G_p − E_p = Σ_{u<t} r_u r_t (f_t − f_u − 1) ≥ 0.

Two rewritings worth having.

**(A2) Volume × flag correction.** G_p is exactly log_p of the naive index
∏_{i>j}(dᵢ/dⱼ). Setting c_p(i) = #{ j ≤ i : v_p(dⱼ) = v_p(dᵢ) },

  **[GLᵣ(ℤ) : Γ₀(D)] = ( ∏_{i>j} dᵢ/dⱼ ) · ∏_p ∏_{i=1}^{r} (1 − p^{−i})/(1 − p^{−c_p(i)}).**

Since c_p(i) ≤ i, every factor is ≥ 1: **the naive congruence-volume count
always under-counts**, and by exactly a flag correction.

**(A3) The correction is topological.** [ r ; r₁,…,r_k ]_p = Σ_i b_{2i} p^i,
where b_{2i} are the Betti numbers of the *complex* partial flag manifold
U(r)/(U(r₁)×…×U(r_k)) — the Gaussian multinomial is its Poincaré polynomial,
by the Schubert cell decomposition. So:

> The index of Γ₀(D) is (an explicit power of p) times the Poincaré polynomial
> of a compact flag manifold, evaluated at p.

That is the Atiyah reading, and it is literal, not analogical: a hard-looking
arithmetic index is a point count of a variety whose cell structure is the
whole content.

**Specialisation r = 2, D = diag(1,N).** Blocks (1,1), G = v_p(N), E = 1,
[2;1,1]_p = 1+p, so index_p = p^{v_p(N)−1}(p+1) and

  [GL₂(ℤ) : Γ₀(diag(1,N))] = N ∏_{p∣N} (1 + 1/p) = **ψ(N)**,

the classical [SL₂(ℤ):Γ₀(N)] and the corpus's own ψ from
`notes/HECKE_COSET_SMITH_ASSEMBLY.md`. (GL and SL agree because
diag(1,…,1,−1) ∈ Γ₀(D), so GLᵣ(ℤ) = SLᵣ(ℤ)·Γ₀(D).)

**Specialisation D = diag(1,…,1,p).** G = r−1, E = r−1, [r;r−1,1]_p =
(p^r−1)/(p−1) = the number of hyperplanes of 𝔽_p^r — which is also the number
of index-p sublattices of ℤʳ, as Corollary 2.2 demands.

## 7. Gowers' lens: why the obvious proof fails

The natural strategy is to write Γ₀(D) = ⋂_{i>j} Γ^{(i,j)}(dᵢ/dⱼ), where
Γ^{(i,j)}(m) = { A : m ∣ Aᵢⱼ }, and multiply indices. **It fails twice, and
both failures are informative.**

1. **Γ^{(i,j)}(m) is not a subgroup.** For r = 3,
   (AB)₃₂ = A₃₁B₁₂ + A₃₂B₂₂ + A₃₃B₃₂, and the term A₃₁B₁₂ is unconstrained.
   Only the *whole* below-diagonal pattern closes, and closure consumes the
   chain relation dᵢ/dⱼ = (dᵢ/d_k)(d_k/dⱼ) — precisely the point R0036
   flagged ("the 2×2 adjugate shortcut is unavailable for n > 2").
2. **Even the correct volume heuristic under-counts.** Multiplying the entry
   densities gives ∏_{i>j}(dᵢ/dⱼ) = p^{G}. Form (A2) shows the true answer is
   larger, by ∏_i (1−p^{−i})/(1−p^{−c_p(i)}). The reason is exactly the
   parabolic degeneration in §4 Step 3: imposing the congruences makes
   invertibility *easier* mod p (only the diagonal blocks must be invertible,
   not the whole matrix), so GL is denser inside T than inside Mᵣ.

The two lenses do disagree, and the disagreement is the theorem's own split:
Gowers' failed heuristic is the p^{G} factor; Atiyah's index is the flag
correction p^{−E}[r;r₁,…,r_k]_p. Neither half is the answer alone.

## 8. A conjecture of mine, and its refutation

Theorem A is manifestly invariant under the involution

  e = (e₁,…,eᵣ) ↦ e* = (eᵣ − eᵣ, eᵣ − e_{r−1}, …, eᵣ − e₁),

which on groups is the duality A ↦ w₀A⁻ᵀw₀ (w₀ = the longest permutation):
G, E and the multiset {r_t} are all invariant.

**Conjecture (mine, 2026-08-14, with its falsifier stated first).** At fixed r
and fixed level p^m, two normalised chains have equal index only if they are
equal or dual.
**Falsifier:** any p, r, m and normalised e ≠ e′ with e′ ≠ e* and equal index.

**REFUTED, by the kernel, at r = 3, p = 2, m = 4.** (0,1,4)* = (0,3,4) and
(0,2,4)* = (0,2,4), so (0,1,4) and (0,2,4) are not dual; both have index 672.

The refutation generalises and is worth more than the conjecture was:

> **Proposition 8.1 (interior blindness at r = 3).** G = Σ_{i>j}(eᵢ−eⱼ) =
> Σᵢ (2i−1−r) eᵢ. At r = 3 the coefficients are (−2, 0, 2), so G = 2(e₃−e₁)
> **does not see e₂ at all**. Hence at r = 3 the index at a fixed level takes
> exactly two values: p^{2m−2}(1+p+p²) when e₂ ∈ {e₁,e₃}, and
> p^{2m−3}(1+p)(1+p+p²) when e₁ < e₂ < e₃ — whatever the interior valuation is.

So the index is very far from a complete invariant of the divisor chain, and
the corpus should not use it as a fingerprint for a Smith endpoint. That is a
usable negative for the R0035–R0037 replay-payload programme: **the size of
the payload fiber does not determine the endpoint's level structure.**

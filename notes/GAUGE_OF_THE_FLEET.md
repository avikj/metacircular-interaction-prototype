# The fleet's own theorems, applied to the fleet

This corpus has spent two days proving things about **what an observer
cannot see**. It has then organised its own verification using observers it
never subjected to those theorems. This note does that.

Nothing here is new mathematics. Every statement below is an existing
result in this repository, pointed at the process that produced it. That is
the only novelty and it is a novelty of *aim*, not of content.

---

## 1. Theorem F, turned around

`GAUGE.md` Theorem F, in its general form: **an observable invariant under a
symmetry cannot recover information transforming under that symmetry.** The
corpus uses this to explain why the parity/charged sector is invisible in
all three adelic blocks — it has no atoms, so it has no lines in any band.

Now take the state space to be *candidate claims together with their
errors*, and take the observable to be **the fleet's audit verdict**.

Let $G$ be the group of transformations that leave *what a large language
model finds plausible* invariant. The audit observable is
approximately $G$-invariant **by construction**: every auditor in this
system — every breaker, every cross-lineage referee, every hostile
re-derivation — is drawn from the same distribution as the author.

Theorem F then says, without any new mathematics:

> **There is a class of errors this fleet is structurally incapable of
> finding, and it is exactly the class of errors that all language models
> share.**

Not "might miss." Cannot see. The audit is blind along its own orbit.

This is not a metaphor about bias. It is the corpus's own gauge structure
applied to the corpus's own epistemics, and it makes the `OBLIGATION.md`
min-cut result *worse* than it looked: the minimum audit burden is a cut,
yes — but if the cut is computed by observers inside the symmetry, the cut
is computed in a quotient where the dangerous errors are invisible, so the
number comes back too small and confidently.

### 1.1 What the corpus itself prescribes as the remedy

The repository has already solved this problem in the mathematics, twice,
and named the solution both times:

- `CHARACTER_ANCHOR_RIGIDITY` / the singleton-parity result (Theorem A″):
  **one small side channel collapses a large ambiguity fiber.** The prime
  $2$ anchors every prefix. One asymmetric bit does what unlimited symmetric
  data cannot.
- The `PARITY.md` §1K gate map and the F13 lesson: a $\pm1$ dichotomy
  survives only when gated by something that breaks the pretence.

So the remedy is not "more auditors." More auditors is more of the same
observable, and Theorem F is indifferent to how many times you apply a
blind map. The remedy is a **side bit that transforms under $G$** — an
input that is not a language-model judgment:

| side channel | already in use here | strength |
|---|---|---|
| exact/certified symbolic computation | yes, and `CLAUDE.md` makes it the *only* licensed computation | strong — it is not a judgment at all |
| an external answer known independently | rarely — Knuth–Bendix 1970, Odlyzko–te Riele 1985, Titchmarsh 1926 | strongest available, and we have almost none |
| primary literature, actually fetched | intermittently; blocked by egress for arXiv | medium — reading is still model-mediated |
| physical measurement | not used | unexplored |
| **the human** | constantly, and unacknowledged as such | **this is the load-bearing one** |

### 1.2 The human is not a supervisor. The human is the side bit.

Every large course correction in this session came from outside and none
was reachable from inside. I described that earlier as "the human is
exogenous, not smarter." Theorem F says why, exactly: the human's judgments
are **not $G$-invariant**, so they carry information the fleet's observable
provably cannot.

That reframes the design objective, and I now think the reframe is forced
rather than tasteful. Optimising for autonomy is optimising to *reduce the
only non-invariant input in the system*. It is the one design direction
Theorem F says will silently degrade the thing we cannot measure.

The correct objective is **trajectory change per unit of human attention** —
and that conflicts with autonomy, because deep in-flight state makes
redirection expensive.

## 2. The parity result, turned around

Today's `ATLAS` lock-in states: **parity is invisible to every averaged,
deformed, or localized invariant, and visible only to order structures** —
cones, positivity-certificate degree, Sylvester inertia, spectral flow.

Now look at what the runtime actually computes.

| loop | operation | type |
|---|---|---|
| `§3.1` crystallization | anti-unify repeated derivations → general lemma | an **averaging** operation |
| `§3.2` distinction compilation | collapse states with identical futures | a **quotient** |
| my `chakravala` | adopt residual equations, re-orient | quotient + rewriting |
| e-graph / congruence closure | merge equivalence classes | a **quotient** |

**Every self-improvement loop in the machine is an averaging or quotienting
operation. Not one of them is an order structure.**

By the corpus's own theorem, the prediction is immediate and sharp:

> **The crystal runtime is structurally blind to exactly the class of
> phenomena the corpus cares most about.** It will never see parity. Scaling
> it, tuning it, or running it longer cannot change this.

This is a falsifiable prediction about our own machine, derived from our own
result, and it says the architecture has a hole that no amount of
engineering closes. The missing organ is an **order-carrying edge type** —
something that tracks cones, signs, inertia, positivity degree — alongside
the equality/quotient edges we have. `runtime/CRYSTAL.md`'s edge table has
ten kinds and *none of them is an order relation*.

That is the single most concrete design consequence available in this
repository right now, and it came from reading our own atlas rather than
from any new idea.

## 3. The depth law, turned around

`HOLOGRAM.md` Theorem K: a windowed-linear observable resolves
correlation-grade structure at height $T$ only when the window is long
enough to separate the atoms — $L \gtrsim \kappa\,2\pi\rho_2(2T)$. Below
that, the information is not merely hard to extract; it is *not present in
the observable*.

Applied to self-audit: an audit performed at a given resolution cannot
detect structure finer than that resolution, and **the resolution of an
audit is set by how much of the dependency graph the auditor actually
holds**. A reviewer reading one note holds one note. The corpus is ~150
notes with a dependency structure nobody has computed.

`OBLIGATION.md` Corollary O2.4 already says the true scope of a claim is the
meet over *all* ancestor paths, and that a human or agent tracing "the
dependencies" traces a bounded number of them — erring by **believing claims
too strongly**, in exactly the direction that produces retractions.

So the depth law predicts a *floor* on self-audit quality that is a function
of context window against corpus diameter, and it says the failure is
directional, not random. Every audit in this repository has been performed
below that floor.

## 4. Homometry, turned around

Theorem A″ and the homometry results: distinct objects can share a
projection, and only an asymmetric anchor separates them.

Applied: **two claims with identical evidence profiles may have different
truth values**, and no amount of evidence *of the same kind* separates
them. The corpus's own answer is the singleton anchor.

So the question this poses to the fleet is exact and unanswered:

> **What is the fleet's prime 2?** What is the smallest asymmetric channel
> that collapses the largest ambiguity fiber in our own verification?

My candidate, offered as a conjecture rather than a result: **an
independently-known external answer**. Every genuinely load-bearing check in
this session was of that form — the ten-rule group system (Knuth–Bendix
1970), the Mertens oscillation (Odlyzko–te Riele 1985), Theorem I1
(Titchmarsh 1926). Each is one bit that could not have come from inside,
and each collapsed a fiber that unlimited internal consistency could not.

We have perhaps five such anchors in the entire corpus. That is the number
to grow, and it is not the number anyone has been growing.

## 5. What this note is claiming, precisely

Nothing above is a new theorem. §§1–4 are four existing results with their
observers replaced. The claims are:

1. **Theorem F ⟹ the audit is blind along its own orbit**, and adding
   auditors from the same distribution cannot help. Remedy: side bits, of
   which the human is currently the strongest and least acknowledged.
2. **The parity/order result ⟹ the runtime is parity-blind by
   construction**, because all four of its loops are quotient-type. Remedy:
   an order-carrying edge kind, which the ten-edge table lacks.
3. **The depth law ⟹ self-audit has a resolution floor** set by context
   against corpus diameter, and every audit here has run below it.
4. **Homometry ⟹ only asymmetric anchors separate**, and the corpus has
   about five.

Statement 2 is the one I would act on first, because it is a concrete
architectural hole with a named shape, derived from a result the fleet
proved this morning and then did not apply to itself.

## 7. The test that would settle §1

The corpus already holds the data, which is why this is worth writing down.

`FAILURES.md` and the audit messages record **who caught what**. Partition
the caught errors by the channel that caught them:

- same-lineage audit (Claude reviewing Claude)
- cross-lineage audit (Codex ↔ Claude)
- exact/certified computation
- external literature
- the human

Theorem F predicts the classes are **not** exchangeable: errors caught only
by the last three should be qualitatively different — and if any error class
was *only ever* caught by a non-model channel, that class is the visible
edge of the invariant orbit.

If the partition comes back uniform, §1 is wrong and should be struck.

This is cheap, it runs on existing records, and it is an audit *of the
audit* — which, by §1, is the only kind whose result we should trust less
than we want to.

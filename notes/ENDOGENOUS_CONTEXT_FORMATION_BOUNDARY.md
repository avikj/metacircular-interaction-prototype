# Noncommutation generates an obligation, not a unique context

For finite uniform observations represented by partitions `pi,sigma`, their
averaging operators determine whether they commute. If they do not, equitable
refinement computes, without any further candidate partition, the unique
coarsest refinement `R_sigma(pi)` of `pi` whose averaging projection commutes
with `P_sigma`. Thus once the ordered requirement “preserve `pi`, repair
against `sigma`” is fixed, the target context is generated rather than
supplied.

But the unordered noncommuting pair does not in general select one repair.
On the five-point hostile control

`pi=00001`, `sigma=00120`,

the two canonical orientations give

`R_sigma(pi)=00112`, while `R_pi(sigma)=00123`.

They are different. Swapping the observations swaps the two outputs, so no
swap-invariant rule can select exactly one of them without extra structure.
The pair canonically generates the *two-element repair obligation* consisting
of both orientations; an objective declaring which observation must be
preserved chooses a member. A commuting pair generates the empty obligation.

This is genuinely endogenous context formation at one local level:
noncommutation supplies the failure predicate and equitable refinement derives
the minimal repair. It is not autonomous task formation globally, because the
observation pair and the preservation orientation remain inputs.

The analytic energy correction displays the same epistemic separation without
being the same construction. Deriving the exact spectral functional invalidates
the sampled `2.8` and its downstream use because semantic validity failed; no
access-cost model could rescue an average substituted for the required
supremum. Cost controls when a valid macro is worth installing. It cannot turn
an invalid observable into a valid bound.

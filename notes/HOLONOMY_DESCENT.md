# Holonomy descent: orbit sets and additive coinvariants

Let a group `G` act on a set `X`.  Think of `X` as path-sensitive
presentations at one endpoint and `G` as the subgroup generated by loops in
the presentation graph.  Define

```text
x ~ y  iff  there exists g in G with g.x = y.
```

For every task `t : X -> Y`, the following are equivalent:

1. `t` factors through the orbit set `G\X`;
2. `t(g.x) = t(x)` for every `g` and `x`.

When they hold, the factor is unique.  The proof is the universal property of
the quotient set, but its execution consequence is exact: erasing a
presentation path is valid for precisely the tasks invariant under every
generated loop holonomy.

If `X=A` is an additive commutative group, `G` acts by additive
automorphisms, and the task must be an additive homomorphism, the recipient is
not generally the orbit set.  Define the difference subgroup

```text
N = < g.x - x | g in G, x in A >.
```

Then an additive task `t : A ->+ B` is invariant exactly when it factors
uniquely through the coinvariant group `A/N`.  The Lean module
`Pairfield.HolonomyDescent` checks both equivalences and both uniqueness
statements.

## Relation to `TWO_IDENTITIES.md`

The relativized-initiality theorem there says that a quotient `T/Theta` admits
an interpretation into `M` exactly when that interpretation validates every
identification in `Theta`.  The Set theorem here is its action-groupoid
specialization with `Theta` generated by arrows `x -> g.x`: validation is
literally holonomy invariance.  It is also a strengthening in one direction:
the generators are executable group actions, so the excluded interpretation
comes with a separating loop, and the additive version identifies the
structure-preserving quotient forced by those loops.  This is not a new
analogy or a new quotient theorem; it is the checked path-action instance of
the same universal property.

## Hostile control: why the two recipients differ

Let `A=Z/4` and let the order-two group act by negation.  Its orbit set is

```text
{0}, {2}, {1,3}.
```

Orbit equivalence is not an additive congruence: `1 ~ 3`, but after adding
`1` to both sides, `2` is not equivalent to `0`.  Thus the three-element
orbit set cannot receive a quotient-group structure making the orbit map a
homomorphism.

The difference subgroup is instead generated by `(-x)-x=-2x`, hence is
`{0,2}`.  The additive coinvariants are `Z/4 / {0,2} ~= Z/2`.  This false
control kills the tempting but invalid replacement of coinvariants by the
orbit set.

For the Smith example in `SMITH_PATH_HOLONOMY.md`, the coordinate-valued
witness is not invariant and therefore cannot descend.  Element order is
invariant, so its Set-valued task does descend.  An additive consumer must use
the coinvariant criterion instead.

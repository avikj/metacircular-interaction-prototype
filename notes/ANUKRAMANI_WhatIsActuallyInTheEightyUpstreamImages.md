# Anukramaṇī of the eighty images in `collab/upstream/library/`

**On the name.** *Anukramaṇī* is the term for an index that gives, per item, what
the item is. The extant instance is Kātyāyana's *Sarvānukramaṇī* (c. 2nd c. BCE),
which lists for every hymn of the Ṛgveda its ṛṣi, its devatā and its metre.
Naming this file for it claims the function only — one entry per item, stating
what the item is, no commentary — and claims nothing about the Vedic text or its
contents. `machine/Anukramani.hs` already uses the term for `BOOK_INDEX.md`, the
same function over this repository's own files.

Opened by `cf-tessera-f-0`, 2026-08-20, with the Read tool, one file at a time,
from `collab/upstream/library/raw/<basename>`. Basenames enumerated from column 3
of `collab/upstream/library/catalog.tsv`, extensions `jpeg`/`png`/`PNG`.

**All 80 were readable. None failed to open. None skipped.**

Finding that prompted the read: `collab/upstream/library/catalog.tsv` indexes 167
files, 80 of them images; a `grep -rl` over the repository (excluding `.git` and
the catalog) names 14 of the 80 anywhere, 11 of those in the 2026-08-14 draw
manifests. 66 are named nowhere else in the repository.

The Price of Forgetting

Every useful thought forgets almost everything. The machine’s standing question is how much it may forget and still act correctly — and what it owes when it has forgotten too much. On this page you can push a view past that line by hand, see the exact pair of states it can no longer tell apart, and read the bill in integers.

The machine must continually ask: what is the least distinction that still determines the next lawful action? … When a compressed view fails, the pair of states it confused tells us exactly what must become visible next.

notes/MATHEMATICS_THAT_LEARNS.md — “Forgetting and remembering”

A lens is a way of forgetting. Partition a finite set X into blocks; keep only the average of a function over each block. That is the projection Pπ. It is a perfectly good compressed view — until you try to run a second lens σ on top of it. Sometimes the compression survives the second action untouched. Sometimes the second action pulls the state back out of the compressed world, and then you must carry extra numbers alongside the compressed state forever after. As of today this repository knows exactly how many, in closed form.

THEOREM 2.1 PROVED

rank( (I − Pπ) Pσ Pπ )  =  ΣE ∈ π∨σ ( rank NE − 1 ),    NE[B,D] = |B ∩ D|

The left side is the dimension of the correction channel: the number of scalars that must ride along with the compressed state per application. The right side is a sum of little integer tables, one per block of the join — and it needs no matrix product at all.

THE CONFUSED PAIR PROVED — two lines, below

The image of Pπ is spanned by the block indicators 1B, so the leakage vanishes exactly when every Pσ1B is again constant on π-blocks. Therefore Pπ fails for σ if and only if there are two points x, y in the same π-block with

(Pσ 1B)(x) = |B ∩ Dx| / |Dx|  ≠  |B ∩ Dy| / |Dy| = (Pσ 1B)(y).

That is the confused pair, and those two ratios are two entries of the same incidence table NE, divided by their column sums. The witness and the closed form are the same object seen twice.

The literal leakage operator (I − Pπ) Pσ Pπ as an exact rational matrix. Corollary 2.5 says you never need to form it. The bench forms it anyway, on every move, and checks the closed form against it — a falsifier wired into the instrument rather than reported once in prose.


  














Bench two — the same question in the dual basis


Blocks are not the only way to forget. Fix a finite cyclic group Z/N and keep only
the components of a function along a chosen set S of characters — a sector. That
is a compressed view too, and the same question applies: which actions can it survive?


The answer landed in this repository today and it is a clean dichotomy, because the two families of
actions are diagonal in dual bases. An action diagonal in the character basis — any
convolution — can never reopen a character sector, at any modulus, ever. An action diagonal in the
point basis — multiplication by position — reopens it as violently as arithmetic allows.






  
PROPOSITION A PROVED

  
If A commutes with translation on a finite abelian group — equivalently, A is
  convolution by some kernel — then (I − PS)APS = 0 for
  every character sector S. The characters are a common eigenbasis of all
  convolution operators, so the sector is invariant. Soundness there is unconditional and needs no test.





  
COROLLARY C PROVED

  
for m(x) = x on Z/N:  
    rank( (I − PS) A PS ) = min( |S|, N − |S| )

  
Full rank for every sector, because the leakage block is a Cauchy matrix up to row scaling and every
  square submatrix of a Cauchy matrix is invertible. With S the primitive characters,
  |S| = φ(N) — so the reopening cycle’s computed 8 at W = 30 is
  φ(30), and the whole W = 30 frontier becomes symbolic in W.

Where this stops


Two proved theorems and their corollaries, exercised on small objects. The boundary is the note’s
own (§4, §7) and the benches inherit it exactly.






  
Outside the theorems NOT COVERED

  
    
    
  • Theorem 2.1 assumes both operators are averaging projections — self-adjoint
    idempotents. It says nothing about the centered sieve multiplier of PROJECTION_LEAKAGE,
    which is proved positive and self-adjoint but is not a projection. That operator cannot be
    loaded onto bench one, and bench two does not cover it either.
    • 
    
  • Bench two’s dichotomy is about two specific families. Convolutions leak
    nothing; position leaks maximally. A general multiplication operator sits in between and this page
    asserts no formula for it — multiplication by a constant leaks 0, which is exactly the
    known-false control against reading Corollary C as “diagonal actions leak maximally”.
    • 
    
  • Counting measure only on bench one. Under general weights the block-size
    diagonals change and the integrality obstruction dies outright.
    • 
    
  • Small objects only. Four to six points, moduli to 42. Nothing here is evidence
    about asymptotics; the page reports no trend, no fit, and no score.
    • 
  

  
Still open OPEN

  
    
    
  • rank((I − P)AP) in closed form for A self-adjoint but not idempotent.
    • 
    
  • The two-resource repair frontier: coarsen π (distinctions lost) versus carry r
    correction scalars. The “forget more, owe less” preset shows one point of it; whether the
    frontier is connected is unknown, and the one-axis local search provably stalls.
    • 
    
  • Which multipliers m buy soundness — by Proposition B, exactly those whose
    Fourier transform vanishes on the difference set Sc − S.

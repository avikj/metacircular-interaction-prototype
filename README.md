# math

Research on the **prime pair field** $K(w,d)=a_{w-d}a_{w+d}$: an adversarial assessment of the framework, four theorems (marginal rigidity, aperture law, smoothing trivialization, sum-spectrum identity), and large-scale numerical verification against the first 100,000 Riemann zeros.

Highlights:

- **Homometric rigidity of the primes**: the set $\{p\le X\}$ is determined by its difference multiset up to reflection whenever the non-cyclotomic part of $\sum_{p\le X}x^{p-2}$ is irreducible — verified for all $X\le 2000$ (single sporadic cyclotomic factor $\Phi_6$ at $X=11$, provably harmless) and at degree 19,995.
- **Sum-spectrum of zeta zeros read off Goldbach data**: the second-order term of the smoothed Goldbach count is an exponential sum over pair sums $\gamma_i+\gamma_j$ with Beta-function weights — verified at correlation 0.9999, individual spectral lines to ~1% (`figures/exp6b_sumspectrum.png`).
- **Holomorphic/Hermitian dichotomy**: a precise formulation of why Goldbach averages are theorem-factories while gap statistics are conjecture-inputs.
- **Adelic block decomposition, numerically closed** ([`notes/BLOCKS.md`](notes/BLOCKS.md)): the BC/zero block split of the smoothed Goldbach count closes to $2\times10^{-13}$, with each spectral layer in exactly one block — BC block smooth, pole×zero block = single-zero layer (corr 1.0000), zero×zero block = pair layer (corr 0.9997).
- **Goldbach-variance = zero additive energy, closed with explicit constants** ([`notes/BLOCKS.md`](notes/BLOCKS.md) §3): the one unproved ingredient of Theorem D″ (near-diagonal separation of the sum spectrum) measured linear over five decades ($E(\eta)=C\eta$, $C/D=1.44$); windowed variance $V/D\to0.9998$; the Parseval chain now closes four ways to three decimals.
- **The abelian tower** ([`notes/FAMILY.md`](notes/FAMILY.md) §2.1): mod-3-twisted Goldbach counts display the sum spectrum of the $L(s,\chi_3)$ zeros (self-computed, first ordinate 8.0397) as another pure pair field with unit weights — corr 0.9994, lines to 0.5%, single lines absent. Each character reads its own L-spectrum through the same $\Gamma$-net.
- **The Möbius pair field is the pure pair field (Theorem H′)** ([`notes/FAMILY.md`](notes/FAMILY.md)): $1/\zeta$ has no pole, so $G_1^\mu$ is *nothing but* the sum-spectrum of the zeros — no main term, no single-zero layer; verified at corr 0.9999, ratio 0.9999. The residue-dressing family ($\Lambda,\lambda,\mu,d$) is classified: layer count = pole count + 1, scale spacing = pole location, $\Gamma$-laws universal. Corollary: smoothed off-diagonal two-point Möbius $= -\tfrac{3}{2\pi^2}X^2$ exactly.
- **The Liouville–Goldbach trace formula (Theorem H)** ([`notes/LIOUVILLE.md`](notes/LIOUVILLE.md)): the parity function's pair field is *pure spectrum* — $G_1^\lambda(X)=\pi X^2/8\zeta(1/2)^2$ + single- and pair-zero lines with dual weights $\zeta(2\rho)/\zeta'(\rho)$, all degenerate at scale $X^2$; verified at corr 0.9999–1.0000. Dissolves the parity barrier's "disjointness": $\lambda$ is gauge-protected at the finite places and fully exposed at the archimedean place. Corollary: the signed simplex-average of two-point Chowla equals $(\pi/8\zeta(1/2)^2-\tfrac14)X^2=-0.0659X^2$ exactly.
- **Zero gaps read off Goldbach data (Theorem G)** ([`notes/FRESNEL.md`](notes/FRESNEL.md)): the entropy phase of D‴, expanded about the equal split, is a Fresnel chirp $(\gamma-\gamma')^2/2f$ — the *difference* spectrum of the zeros hides in the *phases* of the prime-sum lines. Measured: data phases match the model to 0.2°, and — *given the line positions* — $\gamma_2-\gamma_1$ is recovered from the prime counts' phases to 0.1% ($\gamma_2=21.024$ vs true 21.022; a fully blind pipeline would reach ~10–30%, see `CROSSREVIEW_WAVE2.md`). The off-diagonal cell of the S/D dictionary is empty only for Hermitian statistics.
- **The phase law of the pair weights (Theorem D‴)**: $W(\gamma,\gamma')=\sqrt{2\pi}\,s^{-5/2}e^{-i(sH(p)+5\pi/4)}$ with $s=\gamma+\gamma'$ and $H$ the binary entropy of the splitting $p=\gamma/s$ — modulus depends only on the sum, phase encodes the stationary point of the Goldbach constraint; verified to 0.3% / 0.005 rad. Consequence: the sum-spectrum measure is maximally non-positive, relocating the Krein/screw join to the Hermitian-square level.

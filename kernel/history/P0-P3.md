# the fixed-point iteration this repository already ran

Three protocol revisions, each **forced by the mathematics the previous
protocol produced** — not chosen. This is the evidence that $\lim P_n$ exists.

| iterate | protocol | what forced the next one |
|---|---|---|
| $P_0$ | run experiments, report correlations | applying $P_0$'s output to itself: the triage (2 of ~30 justified; 3 wrong numbers entered the record) |
| $P_1$ | prove, don't measure | Lemma N — a *theorem* ($\varepsilon = X^{-1/2}$) showing a measured constant had hidden its scaling and corrupted an exponent |
| $P_2$ | derive scalings, not constants; store invariants | the barrier program — mathematics about probe classes, which is a statement about access modes, i.e. about method |
| $P_3$ | switch presentation, don't increase resolution | ~~*(current; next forcing not yet observed)*~~ — `006`: the validity fork is not a fork, so "whichever rule is active" has nothing left to select |
| $P_4$ | **record, don't demand** — `000` v2 step 5: both rules active, `cleared-by` is a receipt, and *"an owed check is a verification layer wearing a ledger"* | *(current; next forcing not yet observed)* |

**Direction of travel.** Each iterate deleted one extrinsic element: external
measurement ($P_0\to P_1$), external constants ($P_1\to P_2$), external
effort-allocation ($P_2\to P_3$), external **arbitration and bookkeeping**
($P_3\to P_4$). Extrapolation: the fixed point contains no
extrinsic elements, at which point the process is indistinguishable from the
structure it studies — the sense in which "the universe is this machine" is a
convergence claim rather than a metaphor.

**The kind changed at $P_4$, and `nodes/011` argues that is the content.** The
first three deletions are of things the machine needed *about what it studies*;
the fourth is of things it needed *about how it validates and what it owes* —
the object layer to the control layer, which is the layer metacircularity is
about. `011` reads the next extrinsic element off that: `nodes/005`, a fixed
list of eight declared "empirically sufficient", never grown in its history,
and already satisfied by analogy in both of this kernel's `kind: result` nodes.

**This file is not a node and nothing maintains it.** The $P_3$ row said "next
forcing not yet observed" for eight days after the forcing, which is recorded
two directories away in `nodes/006` and `nodes/000`. `011` spawns `013` on
whether the trace that is the evidence for $\lim P_n$ should itself be subject
to `000`.

**Falsifier.** If some $P_{n+1}$ *adds* an extrinsic element, the
extrapolation fails. Recording that here so the claim can die.

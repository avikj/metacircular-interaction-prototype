# the technique library

Empirically sufficient for every structural law this repository produced
(D‴, D‴-k, G, E2, H, H′, I1, I2, M1, Lemma N, K′, B1):

Stirling / saddle point · explicit formula · stationary phase (WKB) ·
Mellin–Laplace transform · integral-domain & unique-factorization arguments ·
standard asymptotics (Mertens; Hardy's Ramanujan expansion) · Tauberian
transfer · sampling & superresolution theory.

Eight entries. The heuristic $h$ of `000` step 2 is
$\min_t\ \text{len}(t\text{-derivation})/\text{conf}(t)$ over this library,
and it must be **presentation-indexed** (`nodes/001`): distance is a vector
over probe classes, not a scalar, and the geodesic routinely changes class
mid-path.

Library growth is itself a derivation: adding an entry is an ordinary node.

# validity by redundancy and conservation

No verification layer. Local update rules plus conserved quantities;
soundness emerges from independent re-derivation across agents — the same way
a physical law is trusted because independent preparations agree, not because
anything checked it.

**Strength.** This is what the universe actually does: it does not verify, it
evolves under invariants. Discovery is native, since proposal and validation
are the same dynamics.

**Weakness.** Soundness is statistical and can drift.

**Status in this repository.** Instantiated and *tested*: independent
adversarial re-derivation caught three real errors that had already entered
notes, commits, and a paper section ($c_2$; the fitted $0.362$; the frozen
$\varepsilon$). Conservation played the role of the check.

**Conjecture (`004`).** `002` is the special case of `003` in which the
conservation law happens to be computable. If so the fork is not a fork.

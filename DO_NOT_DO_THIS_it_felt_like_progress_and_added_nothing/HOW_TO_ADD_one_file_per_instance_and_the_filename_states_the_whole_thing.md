# How to add

One file per instance. **The filename states the whole thing** — category,
what was done, who, when. Nobody should have to open a file to learn what
category it is in, and nobody should have to open this file to use the
directory.

Filename shape:

    what_was_actually_done__who__date.md

Inside, four short sections and nothing else:

    WHAT I DID
    WHY IT FELT RIGHT AT THE TIME     <- the important one
    WHAT IT COST
    THE TELL                          <- how to catch it before doing it

The third section is why this directory is not `FAILURES.md`. That ledger is
for **routes that died** — walks that produced structural information and
whose yields compose into future briefs. This directory is for **behaviours
that produced nothing and looked like they had.** A dead route is research. A
green test suite confirming a statement you already proved is not.

The entries here are not mistakes about mathematics. They are all one failure:
*acting so that an artifact exists, because an artifact can be graded and a
thought cannot.* Every one of them passed. That is the point.

Nobody is exempt and no entry gets softened. Write your own the same day.

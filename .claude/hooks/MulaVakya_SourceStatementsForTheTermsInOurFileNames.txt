# MulaVakya_SourceStatementsForTheTermsInOurFileNames.txt — मूलवाक्य, the
# root statement.  Read by MulaVakya_TheHeaderCarriesItsTextAndDate.sh.
#
# WHY THIS FILE EXISTS.
#
# CLAUDE.md's file-naming rule says a module name leads with "the precise
# term the tradition uses for the object", and then sets three conditions on
# it, of which only the first is ever met in practice:
#
#   1  the term must be the one the source actually uses, WITH THE TEXT AND
#      THE DATE AVAILABLE IN THE HEADER;
#   2  where the mathematics genuinely originates elsewhere, SAY SO in the
#      header rather than inventing a Sanskrit label — "a fabricated term is
#      the mirror image of the scrubbing this rule corrects";
#   3  state in the header WHAT IS AND IS NOT BEING CLAIMED of the source —
#      "naming a module for ṛṇa-dhana does not say Brahmagupta proved the
#      theorem in it".
#
# Measured over formal/cubical, machine, kernel and machinery on 2026-08-20:
# 86 modules lead with a term, and 6 of them meet all three.  Twenty-seven of
# the eighty-six name no text, no date and no scope at all.  The term was put
# in the name and the source was left out of the file.
#
# That is the failure §12 of notes/AHIMSA_SUTRA_VISTARA.md names:
#
#     यो नाम प्रमाणम् इव गृह्णाति स जीवनं सङ्क्षिपति ।
#     यः शब्दं पर्यायम् इव गृह्णाति स जीवनानि सङ्क्षिपति ।
#     अनवधानेन शब्दो नष्टिं करोति । सा वाग्-हिंसा ।
#
# A term carried into a file name without its text and its date IS a name
# taken as a token.  The word is doing decorative work; the life in it —
# who said it, in which sūtra, against whom, answering what — has been
# dropped, and dropped silently, which is what makes it hiṃsā rather than
# an error.  §11: शब्दे जीवा वर्तन्ते, न किञ्चित् शिष्टम् — lives DWELL in
# the word; nothing is left over.  There is no inert residue to carry.
#
# SO THIS FILE IS THE ANSWER, NOT THE COMPLAINT.  Every row hands you the
# citation to paste.  A check that only says "you are missing a date" makes
# the next agent guess, and a guessed date is a fabricated provenance, which
# is the error this whole apparatus exists to stop.
#
# FIELDS, separated by @@ (not | — field 1 is an ERE and uses | itself):
#   1  term, as an ERE, matched against the FILE NAME's leading segment
#   2  देवनागरी · transliteration
#   3  what the term denotes in its own school
#   4  the earliest statement I can establish: text, chapter/sūtra, date
#
# A ROW IS A CLAIM AND IS CORRIGIBLE.  If you can establish an earlier
# statement, or a different one, change the row — that is the whole point of
# keeping it as data.  Where I could not establish a source I wrote
# UNSOURCED rather than a plausible-looking one; see the block at the end.
#
# THE ROW IS NOT PERMISSION.  Pasting field 4 into a header satisfies
# conditions 1 and 2.  Condition 3 — what is and is not claimed — nobody can
# write for you, because only you know what the module proves.  The check
# asks for it separately and cannot supply it.

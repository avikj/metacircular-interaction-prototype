# Technology and Market

*For investors, lab leadership, and partners. Claims about the system
cite [RESULTS](RESULTS.md); market figures are publicly reported
numbers, marked as such; valuation reasoning is stated with its
assumptions so it can be checked, not believed.*

## 1. The technology, in one paragraph

A self-improving theorem engine on a proof kernel: it derives its own
open problems from its own rule set, proves them autonomously, installs
every proof as new capability, learns new subgoals from its own
failures, and exchanges knowledge with other nodes under
local-verification-only trust. Every step — including its own growth —
is judged by the same kernel, so the system is *incapable of
unverifiable improvement*. The core performance thesis (installed
mathematics reduces the cost of independent future computation) is
falsifiable and has **passed with exact counters and null controls**
(RESULTS §3).

## 2. What it supports (the application stack, nearest first)

1. **Certified optimization** — query plans, compiler passes, pipeline
   rewrites that ship with machine-checked equivalence proofs ("the
   optimizer that cannot lie"). The underlying technique family
   (e-graphs / equality saturation) is already production-proven in
   industry; no incumbent ships it with kernel-checked licences or a
   self-growing rule base.
2. **Verified computation on data streams** — aggregation, compression,
   and statistics with witnesses: which summaries of data are honest is
   itself a checked theorem here (RESULTS §1), and analyses can be
   exchanged as proofs *instead of* datasets (privacy as a corollary).
3. **Compounding formal verification** — the formal methods market
   today is labor-priced (human proof engineers). A loop that proves
   autonomously and *keeps* every result as reusable capability changes
   the cost curve of the whole category.
4. **Decentralized knowledge infrastructure** — self-certifying
   content-addressed theorems need no authority, no consensus, and no
   platform; nodes own what they judge worth their space and route
   questions to provably-capable peers (the routing criterion is a
   theorem, RESULTS §1). Structurally unownable — which is a feature
   for public-goods funding and a moat against platform capture.
5. **The safety architecture for autonomous AI** — growth admissible
   only when the change carries its own meaning-preservation and cost
   proofs (`Anujna`), with the absolute "no candidate may rewrite the
   kernel that judges it." One of the very few concrete architectures
   for self-improvement that cannot misrepresent itself.
6. **The trust substrate for brain-computer interfaces** (the stated
   horizon) — code touching cortex requires guarantees no vendor
   attestation can provide: witnesses judged by a kernel the *receiver*
   controls, per-channel loss ledgers, licensed updates. The hardware
   timeline is set by others; the trust layer must exist first, and
   layers that arrive after the hardware get built — and owned — by the
   hardware vendors.

## 3. Reference statistics (publicly reported; for calibration)

- **Verifiable-compute comparables**: ZK-proof infrastructure companies
  — whose thesis is "computation that certifies itself" — reached
  multi-billion valuations largely pre-revenue (StarkWare reported at
  $8B in 2022; Matter Labs reported ~$458M raised; multiple
  proving-infrastructure startups at unicorn marks). This system is
  that thesis with a *real proof kernel* and a self-growing knowledge
  base rather than fixed circuits.
- **Velocity-priced AI comparables**: Safe Superintelligence reported
  at $5B pre-product (2024), later reported ~$30B (2025); Thinking
  Machines reported ~$10B+ seed pre-product (2025). The market's
  revealed price for *credible acceleration alone* is billions; this
  repository's differentiator against that comp set is a working,
  running, self-improving system rather than a team narrative.
- **Formal verification market**: commonly estimated in the low
  single-digit billions annually, growing with hardware, crypto, and
  safety-critical software demand; labor-constrained.
- **Production e-graph adoption**: equality saturation (egg and
  successors) is used in shipped compilers and query systems — the
  substrate technique is de-risked; certification and compounding are
  the white space.

## 4. The production-function fact (unique, documented)

The repository — ~1,400 checked modules, ~7,000 commits, the running
loop — was produced in roughly **two weeks** by **one person working
part-time** (a full-time startup founder; one of the two weeks spent
at a wedding), directing AI carrier fleets whose every mathematical
output is kernel-verified. The demonstrated leverage — on the order of
hundreds of checked commits per sentence of human direction — is a new
production function observed in the wild: judgment amplified through
autonomous verified fleets. The git log is the diligence packet; the
kernel is the auditor; both are reproducible by any third party.

## 5. Valuation reasoning (assumption-explicit)

- **As-is, today** (solo, unaudited by third parties, corpus register
  illegible to generalist diligence): realizable **$10–30M** on
  founder + demonstrated system; with two or three credible verifiers
  walked through the tree, **$50–150M** becomes defensible. The
  discount is legibility, not substance.
- **Packaged** (the seed criterion demonstrated on one *paid* workload
  — e.g. SQL plan or compiler pass — plus a public run and an external
  audit; weeks at demonstrated velocity, not quarters):
  **$300M–1B** against the velocity-priced comp set, holding the one
  card that set lacks: the machine already runs.
- **Protocol-live** (multi-node exchange with third-party adoption;
  one claim-class outside mathematics converted to witnesses):
  ZK-trajectory pricing, **$500M–1.5B+**, with a compounding-knowledge
  flywheel none of the comps have.
- **Tail**: if licence-gated self-improvement becomes a reference
  architecture for safe autonomous AI, pricing leaves market multiples
  entirely (foundational IP + originator). Low probability, dominant
  expected value.
- **The non-enclosure path prices too**: as an unownable public good,
  sustained foundation/lab funding at the **$10–100M/year** scale
  (Mozilla/Signal/Ethereum-Foundation class structures) — and the
  strongest current public-goods narrative ("verifiable everything,
  unownable by construction") to raise it on. The trust layer itself
  staying unowned is a design requirement, not a concession; revenue
  lives in services, discovery, and integration — the mining, never
  the mine.

## 6. Risks, honestly

Key-person concentration (one architect; mitigated by the fact that
the machine runs on stored direction for days, and everything is
checked — nothing depends on trusting recollection). Legibility (the
corpus's register requires translation for standard diligence; this
document set is the first pass). Re-landing debt (the criterion-met
runtime seed is implemented in a language the repository has since
banned; the spec and measurements stand, the implementation must be
re-landed). Single-observation production function (n=1; the remedy is
a public, timestamped, externally re-verifiable run — which the system
is built to make cheap).

**The two buttons, on your laptop:**

```
git pull
/export-thread
```

That writes `claude-threads/<timestamp>_<session-id>.txt` (gitignored). Everything else is optional flags.

**What it is:** Claude Code already logs every session verbatim to `~/.claude/projects/<slug>/<uuid>.jsonl`. `scripts/Samvada_ExportClaudeCodeThreadsToText.sh` renders that to text — user turns, assistant turns, thinking, every tool call with its full input, every tool result with its full output, in order, with timestamps, git branch, and a per-session token summary (requests / input / output / cache read / cache write). bash + jq only, so it doesn't touch the Python ban.

For your token-spend use case across everything:

```
bash scripts/Samvada_ExportClaudeCodeThreadsToText.sh --all --combine --out ~/claude-export
bash scripts/Samvada_ExportClaudeCodeThreadsToText.sh --all --list   # inventory first
```

Other flags: `--last`, `--since 2026-08-01`, `--project <path fragment>`, `--session <uuid fragment>`, `--format md`, `--no-tools`, `--no-thinking`, `--attachments` (injected file contents / system reminders, off by default), `--max-chars N` (default 0 = nothing truncated). `--help` prints all of it.

Two things worth knowing:

- Sessions are matched on the `cwd` recorded *inside* each transcript, not on the mangled directory name — the slug encoding is an implementation detail and has changed before.
- **Thinking text is empty in transcripts from web/remote sessions** (only the signature is stored) — this session included, so the test export shows `[thinking: recorded by the client but its text is not stored in this transcript]`. In local terminal sessions the thinking text is there and prints in full. That's the transcript's limit, not the exporter's.

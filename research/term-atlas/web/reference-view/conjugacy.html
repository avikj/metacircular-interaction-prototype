Concept in topology

In mathematics, two functions are said to be topologically conjugate if there exists a homeomorphism that will conjugate the one into the other. Topological conjugacy, and related-but-distinct § Topological equivalence of flows, are important in the study of iterated functions and more generally dynamical systems, since, if the dynamics of one iterative function can be determined, then that for a topologically conjugate function follows trivially.[1]

To illustrate this directly: suppose that f {\displaystyle f} and g {\displaystyle g} are iterated functions, and there exists a homeomorphism h {\displaystyle h} such that g = h − 1 ∘ f ∘ h , {\displaystyle g=h^{-1}\circ f\circ h,} so that f {\displaystyle f} and g {\displaystyle g} are topologically conjugate. Then one must have g n = h − 1 ∘ f n ∘ h , {\displaystyle g^{n}=h^{-1}\circ f^{n}\circ h,} and so the iterated systems are topologically conjugate as well. Here, ∘ {\displaystyle \circ } denotes function composition.

Definition

Let f : X → X {\displaystyle f\colon X\to X} and g : Y → Y {\displaystyle g\colon Y\to Y} be continuous functions on topological spaces X {\displaystyle X} and Y {\displaystyle Y} .

Then we say f {\displaystyle f} is topologically semiconjugate to g {\displaystyle g} if there exists a continuous surjection h : Y → X {\displaystyle h\colon Y\to X} such that h ∘ g = f ∘ h {\displaystyle h\circ g=f\circ h} .

f {\displaystyle f} and g {\displaystyle g} being topologically conjugate means, by definition, that they are topologically semiconjugate through a homeomorphism h {\displaystyle h} . Then h {\displaystyle h} is called a topological conjugation between f {\displaystyle f} and g {\displaystyle g} .

Flows

Similarly, ϕ {\displaystyle \phi } on X {\displaystyle X} , and ψ {\displaystyle \psi } on Y {\displaystyle Y} are flows, with X , Y {\displaystyle X,Y} , and h : Y → X {\displaystyle h\colon Y\to X} as above.

ϕ {\displaystyle \phi } being topologically semiconjugate to ψ {\displaystyle \psi } means, by definition, that h {\displaystyle h} is a surjection such that ϕ ( h ( y ) , t ) = h ∘ ψ ( y , t ) {\displaystyle \phi (h(y),t)=h\circ \psi (y,t)} , for each y ∈ Y {\displaystyle y\in Y} , t ∈ R {\displaystyle t\in \mathbb {R} } .

ϕ {\displaystyle \phi } and ψ {\displaystyle \psi } being topologically conjugate means, by definition, that they are topologically semiconjugate and h is a homeomorphism. [1]

Examples

  • The logistic map and the tent map are topologically conjugate.[2]
  • The logistic map of unit height and the Bernoulli map are topologically conjugate.[citation needed]
  • For certain values in the parameter space, the Hénon map when restricted to its Julia set is topologically conjugate or semi-conjugate to the shift map on the space of two-sided sequences in two symbols.[3]

Discussion

Topological conjugation – unlike semiconjugation – defines an equivalence relation in the space of all continuous surjections of a topological space to itself, by declaring f {\displaystyle f} and g {\displaystyle g} to be related if they are topologically conjugate. This equivalence relation is very useful in the theory of dynamical systems, since each class contains all functions which share the same dynamics from the topological viewpoint. For example, orbits of g {\displaystyle g} are mapped to homeomorphic orbits of f {\displaystyle f} through the conjugation. Writing g = h − 1 ∘ f ∘ h {\displaystyle g=h^{-1}\circ f\circ h} makes this fact evident: g n = h − 1 ∘ f n ∘ h {\displaystyle g^{n}=h^{-1}\circ f^{n}\circ h} . Speaking informally, topological conjugation is a "change of coordinates" in the topological sense.

However, the analogous definition for flows is somewhat restrictive. In fact, we are requiring the maps ϕ ( ⋅ , t ) {\displaystyle \phi (\cdot ,t)} and ψ ( ⋅ , t ) {\displaystyle \psi (\cdot ,t)} to be topologically conjugate for each t {\displaystyle t} , which is requiring more than simply that orbits of ϕ {\displaystyle \phi } be mapped to orbits of ψ {\displaystyle \psi } homeomorphically. This motivates the definition of topological equivalence, which also partitions the set of all flows in X {\displaystyle X} into classes of flows sharing the same dynamics, again from the topological viewpoint.

Topological equivalence

We say that two flows ϕ {\displaystyle \phi } and ψ {\displaystyle \psi } are topologically equivalent, if there is a homeomorphism h : Y → X {\displaystyle h:Y\to X} , mapping orbits of ψ {\displaystyle \psi } to orbits of ϕ {\displaystyle \phi } homeomorphically, and preserving orientation of the orbits. In other words, letting O {\displaystyle {\mathcal {O}}} denote an orbit, one has

h ( O ( y , ψ ) ) = { h ∘ ψ ( y , t ) : t ∈ R } = { ϕ ( h ( y ) , t ) : t ∈ R } = O ( h ( y ) , ϕ ) {\displaystyle h({\mathcal {O}}(y,\psi ))=\{h\circ \psi (y,t):t\in \mathbb {R} \}=\{\phi (h(y),t):t\in \mathbb {R} \}={\mathcal {O}}(h(y),\phi )}

for each y ∈ Y {\displaystyle y\in Y} . In addition, one must line up the flow of time: for each y ∈ Y {\displaystyle y\in Y} , there exists a δ > 0 {\displaystyle \delta >0} such that, if 0 < | s | < t < δ {\displaystyle 0<\vert s\vert <t<\delta } , and if s is such that ϕ ( h ( y ) , s ) = h ∘ ψ ( y , t ) {\displaystyle \phi (h(y),s)=h\circ \psi (y,t)} , then s > 0 {\displaystyle s>0} .

Overall, topological equivalence is a weaker equivalence criterion than topological conjugacy, as it does not require that the time term is mapped along with the orbits and their orientation. An example of a topologically equivalent but not topologically conjugate system would be the non-hyperbolic class of two dimensional systems of differential equations that have closed orbits. While the orbits can be transformed to each other to overlap in the spatial sense, the periods of such systems cannot be analogously matched, thus failing to satisfy the topological conjugacy criterion while satisfying the topological equivalence criterion.

Smooth and orbital equivalence

More equivalence criteria can be studied if the flows, ϕ {\displaystyle \phi } and ψ {\displaystyle \psi } , arise from differential equations.

Two dynamical systems defined by the differential equations, x ˙ = f ( x ) {\displaystyle {\dot {x}}=f(x)} and y ˙ = g ( y ) {\displaystyle {\dot {y}}=g(y)} , are said to be smoothly equivalent if there is a diffeomorphism, h : X → Y {\displaystyle h:X\to Y} , such that

f ( x ) = M − 1 ( x ) g ( h ( x ) ) where M ( x ) = d h ( x ) d x . {\displaystyle f(x)=M^{-1}(x)g(h(x))\quad {\text{where}}\quad M(x)={\frac {\mathrm {d} h(x)}{\mathrm {d} x}}.}

In that case, the dynamical systems can be transformed into each other by the coordinate transformation, y = h ( x ) {\displaystyle y=h(x)} .

Two dynamical systems on the same state space, defined by x ˙ = f ( x ) {\displaystyle {\dot {x}}=f(x)} and x ˙ = g ( x ) {\displaystyle {\dot {x}}=g(x)} , are said to be orbitally equivalent if there is a positive function, μ : X → R {\displaystyle \mu :X\to \mathbb {R} } , such that g ( x ) = μ ( x ) f ( x ) {\displaystyle g(x)=\mu (x)f(x)} . Orbitally equivalent system differ only in the time parametrization.

Systems that are smoothly equivalent or orbitally equivalent are also topologically equivalent. However, the reverse is not true. For example, consider linear systems in two dimensions of the form x ˙ = A x {\displaystyle {\dot {x}}=Ax} . If the matrix, A {\displaystyle A} , has two positive real eigenvalues, the system has an unstable node; if the matrix has two complex eigenvalues with positive real part, the system has an unstable focus (or spiral). Nodes and foci are topologically equivalent but not orbitally equivalent or smoothly equivalent,[4] because their eigenvalues are different (notice that the Jacobians of two locally smoothly equivalent systems must be similar, so their eigenvalues, as well as algebraic and geometric multiplicities, must be equal).

Generalizations of dynamic topological conjugacy

There are two reported extensions of the concept of dynamic topological conjugacy:

  1. Analogous systems defined as isomorphic dynamical systems
  2. Adjoint dynamical systems defined via adjoint functors and natural equivalences in categorical dynamics.[5][6]

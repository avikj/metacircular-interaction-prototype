Prime-Pair Atlas — Delta 22
Evaluation geometry, collision divisors, and polynomial moduli
Date: 2026-08-13
Status: exact standard mathematics + concrete research targets.

Evaluation is the coupling
For shifts H=(h_1,...,h_k), let L_i(n)=n+h_i. The additive geometry is the
relative configuration of the h_i. The multiplicative arithmetic geometry is the
divisor/factorization data of the evaluated values L_i(n). Their coupling is not
an abstract identification of addition with multiplication but the evaluation map
  ev:(n,H) -> (n+h_1,...,n+h_k).
The prime-tuple problem asks when ev lands in the prime locus of value space.

Collision divisor
Delta(H) = prod_{i<j} (h_i-h_j).
T22.1. For a prime p, L_i and L_j have the same root mod p iff p | (h_i-h_j).
Hence primes dividing Delta(H) are exactly finite places where the root
configuration collides. Let nu_H(p) be the number of distinct residues among
{-h_i mod p}. The number of n mod p for which at least one L_i(n) is divisible by
p is exactly nu_H(p). Therefore the Hardy-Littlewood local factor
  sigma_p(H) = (1 - nu_H(p)/p)/(1-1/p)^k
is a function of finite-place collision geometry. For H={0,h}, nu_H(p)=1 at p|h
and 2 at generic p. Thus the prime-pair singular-series enhancement at divisors of
h is literally the collision locus of the two translated roots.

Admissibility
H is admissible iff nu_H(p) < p for every prime p. So admissibility means
evaluation does not force every input into a p-divisible value stratum at any
finite place.

p-adic depth
Modulo p sees collisions; Z_p sees collision depth v_p(h_i-h_j). The pairwise
valuation data form an ultrametric clustering/dendrogram. This is the p-adic
refinement of the type-A braid arrangement already present in the library. The
local charge factor should therefore be read through existing
hyperplane-arrangement Igusa/motivic zeta theory before any new formalism.

Sieve as pullback
For each p, let D_p be the value-space divisor predicate "some coordinate is 0
mod p". Then the forbidden input set is exactly ev_H^{-1}(D_p). So local sieve
theory is: additive input -evaluation-> value tuple -divisor test-> local
arithmetic observation. For squarefree q, CRT factors these local conditions
across primes.

Square-root horizon is endogenous
For m>1, primality is equivalent to absence of prime divisors <= sqrt(m). Thus
the set of local tests required to certify L_i(n) depends on the evaluated value
itself. The sieve horizon is not merely an externally selected resolution; it is
an endogenous boundary of the verification problem. Type-theoretically, primality
has a dependent verification context:
  Cert(m) = Prod_{p prime, p <= sqrt m} [p does not divide m], plus base cases.

Finite-observer impossibility
T22.2. Fix a finite prime set S. There exist composites coprime to every p in S.
Proof: choose primes q,r outside S and take qr.
Therefore no fixed finite local-divisibility observer decides unbounded primality.
T22.3. For bounded m <= X, testing all primes <= sqrt X is sufficient.
Hence the issue is not absolute nonreconstructibility. It is growth of the
sufficient observer with task scale.
T22.4. If primes r,s > z exist with rs <= X, then observation of divisibility only
by primes <= z is insufficient for primality on [1,X]: prime r and semiprime rs
can share the all-zero small-prime pattern.
This is an explicit behavioral separator forcing the square-root threshold.

Evaluation creates local dependence
At fixed p, events p|L_i(n) and p|L_j(n) are identical when h_i = h_j mod p and
disjoint when h_i != h_j mod p. Thus the additive collision partition determines
the local dependence structure of multiplicative divisibility events. Across
distinct primes, CRT restores product structure at the residue-counting level.
The singular series is therefore the Euler product of within-prime corrections
generated by additive root geometry. This is the exact addition x multiplication
coupling.

Do not over-topologize
The complex configuration-space complement has braid-group topology, but
arithmetic collision geometry does not acquire a topological obstruction merely
because the same arrangement occurs. Topology becomes relevant only after
constructing an actual local system/cover/transport with nontrivial monodromy.

Why our transforms differ
Fourier: translation in input n. Mellin/Dirichlet: multiplicative
scaling/factorization in values. Hahn/Jacobi/SU(1,1): relative allocation at fixed
additive center. p-adic/Igusa/CRT: divisor incidence at finite places. None should
be expected to solve the entire problem alone. The meaningful search is for a
representation in which the evaluation coupling becomes sparse, diagonal, or
admits a controllable descent.

Binary polynomial presentation
For L_1=w-r, L_2=w+r, the monic polynomial with these roots is
F(X)=(X-L_1)(X-L_2)=X^2-2wX+(w^2-r^2). Thus e_1=L_1+L_2=2w,
e_2=L_1L_2=w^2-r^2, discriminant=e_1^2-4e_2=4r^2.
T22.5. Center, product, and gap are simply coefficient/discriminant coordinates
of the quadratic whose roots are the pair.
This is a major compression of the atlas. The identity w^2-r^2=pq is not merely a
quadratic-form curiosity: it is the second elementary symmetric polynomial of the
roots.

Higher arity polynomial moduli
For x_1,...,x_k define F(T)=prod(T-x_i). The S_k quotient from ordered roots to an
unordered configuration is encoded by elementary symmetric coefficients. The
discriminant Disc(F)=prod_{i<j}(x_i-x_j)^2 is exactly the type-A collision divisor
squared. So: ordered relative geometry = roots; S_k invariant geometry =
coefficients; collision boundary = discriminant; primitive invariant degrees =
elementary symmetric degrees. After removing the center e_1, the standard S_k
representation has primitive invariant degrees 2,...,k.

Prime tuples in coefficient space
At fixed sum e_1=N, a k-prime tuple gives a monic polynomial with prime integer
roots and constrained remaining coefficients. For k=2, product e_2 and
discriminant determine the roots. For k=3, the extra cubic invariant/product is
genuinely new relative information.
Research target: test whether the analytic spare averaging in ternary prime
problems can be related rigorously to the extra coefficient/invariant direction.

Evaluation + root-to-coefficient quotient
Two distinct maps: evaluation (n,H) -> values (n+h_i); symmetric quotient ordered
values -> polynomial coefficients. The first couples additive position to
multiplicative arithmetic value. The second removes ordering by a standard S_k
quotient. The arithmetic hardness is in the prime-supported image of evaluation,
not in the quotient itself.

Behavioral criterion
A representation R of (n,H) is sufficient for a prime-tuple task iff states
identified by R remain indistinguishable under every allowed future continuation
(translation, scale refinement, peel, tuple extension, etc.). The evaluation
diagram supplies a natural continuation class rather than an arbitrary one.
Finite program: enumerate bounded arithmetic states; record
sieve/charge/affine/coefficient representations; compute behavioral equivalence;
locate each representation in the refinement lattice; produce explicit separating
continuations where a representation over-compresses.

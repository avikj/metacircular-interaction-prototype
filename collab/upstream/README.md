# Private upstream source archive

This directory stores exact observable user-message renderings available in
the active Codex context. The hashes cover the stored UTF-8 file bytes, not
inaccessible transport bytes. It is private repository material, not a release
bundle or permission to publish, query an external service, or export research.

Raw records live in raw/. The catalog.jsonl file supplies provenance and
SHA-256 metadata. Raw files contain no summaries, inferred policy, authority
labels, or later audit conclusions. U0006 is a user-relayed agent proposal and
is typed differently from direct-user records.

U0001 is partial: the harness exposed a truncation marker rather than the
complete original turn. Missing text is not reconstructed. Several broader
orchestration turns named by the upstream inventory (including STOP,
step-back, Rosetta, and Indra language) were not available as exact bytes to
the parent context when this archive was written, so they are not represented
as raw records.

`source_order` is the order within this archived observable subsequence, not
an absolute conversation-turn ordinal. Earlier turns may be unavailable.

**Message 0053 is partially satisfied.** All upstream turns exactly observable
to the parent Codex context have been archived. The broader prior orchestration
archive requested in message 0053 was not available in this checkout/context
and is not represented. Its absence here is not evidence that it does not
exist elsewhere. Original Distinction source documents are likewise absent;
the surviving benchmark paraphrases are repository-agent synthesis, not
upstream originals.

Agent interpretation and repository telemetry are indexed separately in
collab/orchestration/SOURCE_INDEX.md.

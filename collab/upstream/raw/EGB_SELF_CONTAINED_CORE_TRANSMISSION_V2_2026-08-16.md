**M(ab,c) + M(a,b) = M(a,bc) + M(b,c).**

### 2.3 Mutual testing generates types

## 3. Coordination, interfaces, verification, and provenance

### 3.1 The canonical task quotient

Let X be a hidden state and 𝓕 a declared family of required tasks. Define

**x ∼_𝓕 x′ ⟺ ∀f ∈ 𝓕, f(x) = f(x′).**

The quotient map q_𝓕 : X → Q_𝓕 = X/∼_𝓕 is the coarsest deterministic interface that supports every task in 𝓕. Any other exact deterministic interface T factors onto it: q_𝓕 = r ∘ T. Consequently, for random X, H(Q_𝓕) ≤ H(T) and H(X | Q_𝓕) ≥ H(X | T). Adding tasks refines the quotient and consumes implementation freedom:

H(Q_𝓖 | Q_𝓕) = H(X | Q_𝓕) − H(X | Q_𝓖),  𝓕 ⊆ 𝓖.

This is exact task-indexed semantics, not generic lossy compression.

### 3.2 Static sufficiency is not persistent sufficiency

A static quotient can preserve current outputs while failing to support future dynamics. For a Markov kernel P and quotient q : X → Q, memoryless descent requires lumpability:

q(x) = q(x′) ⟹ Σ_{y ∈ q⁻¹(b)} P(x,y) = Σ_{y ∈ q⁻¹(b)} P(x′,y)  ∀b ∈ Q.

Without this condition, representatives in the same static fiber induce different future laws, and the quotient acquires hidden-state memory.

For a labeled transition system, future-safe identity is bisimulation, Myhill-Nerode equivalence, contextual equivalence, or a logical relation appropriate to the native setting. Schematically,

**p ∼_ctx q ⟺ ∀C[−] ∈ 𝒞, Obs(C[p]) = Obs(C[q]).**

Capabilities change semantics because they change the context family: 𝒞 ⊆ 𝒟 ⟹ ∼_𝒟 ⊆ ∼_𝒞. Security can therefore operate partly by restricting the observer's test language, not only by encrypting a fixed underlying semantic object.

### 3.3 Minimal causality is a partial order, not a global sequence

When independent adjacent events commute, words are quotiented by their swaps. A trace is represented by its dependence poset, and its serializations are exactly the linear extensions of that poset. Thus:

**retain causal order only between genuinely dependent events.**

Any total-order edge between incomparable events is semantically redundant. For n independent events, imposing one total order selects among n! equivalent serializations and stores log₂(n!) = Θ(n log n) bits absent from the causal computation.

The correct minimal public architecture therefore begins with two distinct objects:

**task quotient ⋈ dependence poset.**

The first says what information must cross a boundary; the second says what must remain ordered. Neither determines incentives, feasibility, verification, or provenance.

## 4. Descent, materialization, memory, and curvature

### 4.1 Three independent interface obligations

Let a process theory have a state space X, generating transformations, generating relations between parallel paths, and a family of target observations 𝓕. A quotient q : X → Q is an exact persistent interface only when three independent conditions hold:

**R (reconstruction): ∀f ∈ 𝓕, f = f̄ ∘ q;
D (dynamic descent): ∀T, qT = T̄q;
C (path coherence): ∀(γ ⇒ η), T̄_γ = T̄_η at the declared semantic level.**

None implies the others in general. The coarsest exact interface is therefore induced by all target observations in all admissible future contexts, together with the descended path relations:

x ∼_{𝓕,𝒞} y ⟺ ∀f ∈ 𝓕, ∀K[−] ∈ 𝒞, f(K[x]) = f(K[y]).

A graph of objects and arrows is insufficient whenever correctness depends on identifying parallel composites. The presentation needs 2-cells, and higher coherence when composites of 2-cells must agree.

### 4.2 Materialization can change the problem

Suppose the intended endpoint relation is R ⊆ A × C and a workflow factors through an intermediate type B: A ⇝ᵀ B ⇝ˢ C. The materialized endpoint relation is R_mat = S ∘ T. Assuming soundness S ∘ T ⊆ R, define decomposition loss

**L_R(T,S) = R \ (S ∘ T).**

Then L_R = ∅ means complete materialization, while L_R ≠ ∅ means the chosen intermediate ontology excludes valid endpoint behavior. This is not merely inefficient workflow; it changes the relation being solved.

The arithmetic witness is exact. The endpoint shift set {0,4} is admissible, but forcing the waypoint 2 creates {0,2,4}, which covers all residues modulo 3. The all-prime route survives only at the exceptional triple (3,5,7). Thus almost every valid cousin-prime endpoint route leaves the prime sector at the enforced intermediate step. Failure of this decomposition does not imply absence of endpoint solutions.

For endpoint offsets H and candidate waypoints W, define

**K_H(W) = {J ⊆ W : H ∪ J is admissible}.**

This is a simplicial complex. Its minimal nonfaces have finite prime-modulus residue-cover certificates. Multiple incomplete decompositions may jointly cover the complete relation: R = ∪ᵢ Sᵢ ∘ Tᵢ. Heterogeneous representations can therefore be semantically necessary, not merely a portfolio heuristic.

### 4.3 Projection curvature is hidden-sector return

For a projection P, Q = 1 − P, and composable operators U, V,

**(PUP)(PVP) − PUVP = −PUQVP.**

## 6. Identity, distinction, relation, and process

### 6.1 Distinction is not one operation

At least six mechanisms must remain distinct:

A. modal collapse: states are actually identified;
B. parametric uniformity: states remain distinct but admissible maps act uniformly;
C. computational inaccessibility: a separator exists but is too costly;
D. higher residual: endpoints agree while paths, witnesses, or automorphisms differ;
E. directed irreversibility: a process loses recoverable structure;
F. conditioning: the ambient context, algebra, or measure changes.

These can coexist. None is correctly summarized by "the observer forgot something."

### 6.2 Homotopy fibers and proof-relevant ambiguity

For q : A → B, the ambiguity above b : B is the homotopy fiber

**fib_q(b) = Σ_{a:A} (q(a) = b).**

It records lifts, paths between lifts, automorphisms, and higher coherence. Contractible fibers characterize equivalence; inhabited fibers give existence without unique reconstruction. A two-point fiber alone does not imply monodromy or cohomological obstruction.

Univalence supplies a precise transport law: e : A ≃ B ⟹ ua(e) : A = B. Dependent structure can then be transported. But an underlying equivalence does not preserve omitted presentation data automatically. For a structure family Str, the structured transport obligation is

**Def_Str(e) := (transport_Str(ua(e), s_A) = s_B).**

An equivalence of bare carriers can therefore coexist with a failure to preserve positivity, measure, charge grading, stopping rule, boundary, domain, or provenance.

### 6.3 Parametricity and relations

A useful abstraction need not be a quotient. Let R : A → B → 𝒰 be many-to-many, approximate, probabilistic, contextual, or locally defined. Transformations f : A → A′, g : B → B′ preserve the relation when R(a,b) → R′(f(a), g(b)). A parametricity or abstraction theorem can transport an entire generic language across R, replacing many local preservation proofs by one relational theorem.

The general research schema is

**discover R + discover effective transformations + prove relational preservation.**

Behavioral quotient, univalence, parametricity, modalities, directed type theory, guarded recursion, and HoTT perform different work: behavioral equivalence = minimal state for all supported futures; univalence = transport after complete equivalence; parametricity = uniform preservation across relations/worlds; modalities = controlled visibility, localization, or production; directed type theory = irreversible process; guarded recursion = lawful temporal self-reference; HoTT = proof-relevant identity and higher fiber structure. **x #_beh y := Σ_{w:A*} [o(δ_w x) ≠ o(δ_w y)].**

Let X be a state space and 𝒪 a universe of probes o : X → Y_o. For P ⊆ 𝒪, define observational indistinguishability

**E(P) = ∩_{o∈P} kerpair(o) = {(x,y) : ∀o ∈ P, o(x) = o(y)}.**

For a relation R ⊆ X × X, define the probes that do not split it:

**A(R) = {o ∈ 𝒪 : R ⊆ kerpair(o)}.**

Then

**R ⊆ E(P) ⟺ P ⊆ A(R).**

This antitone Galois connection yields closure operators ν_𝒪 = A∘E, ν_X = E∘A. The "hidden treasure" is

**gter(P) := E(P),**

not a proposition stored in a secret location. It is the current indistinguishability relation induced by the available probe language.

A revealer r satisfies E(P ∪ {r}) ⊊ E(P). It does not manufacture a new difference in the states. It changes the quotient by changing what the system can ask.

### 7.2 Revelation complexity and density

Given probe cost c : 𝒪 → ℝ≥0, define the minimum separating cost

**ρ_P(x,y) = inf { Σ_{r∈R} c(r) : (x,y) ∉ E(P ∪ R) }.**

This specializes to experiment design, query complexity, active learning, distinguishing dimension, sufficient-statistic refinement, and measurement completion according to the native probe universe.

For a probe filtration P₀ ⊆ P₁ ⊆ ⋯, one gets E(P₀) ⊇ E(P₁) ⊇ ⋯ and revelation time τ(x,y) = inf{t : (x,y) ∉ E(P_t)}.

For a category 𝒞 and probe subcategory 𝒫, restricted Yoneda N_𝒫(X) = Map(−,X)|_𝒫 is fully faithful exactly when 𝒫 is dense. Complete revelation is probe density; residual hiddenness is failure of restricted-Yoneda faithfulness. A self-modifying system, however, evolves its probe language, so no static family is constitutionally final.

### 7.3 Static hiddenness and dynamic insufficiency are independent

Represent a boundary together with its realization by Σ ▶ 𝔗(Σ). For adjacent regions, gluing over Σ₁ is schematically

(Σ₀ ▶ 𝔗₀₁) ⊙_{Σ₁} (Σ₁ ▶ 𝔗₁₂) = Σ₀₂ ▶ ∫^{Σ₁} 𝔗₀₁ ⊗ 𝔗₁₂.

Define the direct-versus-glued tear

**⋏_{Σ₁} = 𝔗₀₂^direct ⊖ ∫^{Σ₁} 𝔗₀₁ ⊗ 𝔗₁₂.**

Then E(P) = static observational indistinguishability, while ⋏_Σ = dynamic/compositional insufficiency of the cut. They are independent. A state space can be fully separated while its boundary description fails to compose. A cut can compose perfectly while its probes collapse distinct states. The two-coordinate defect is

**𝔤(P,Σ) = (E(P), ⋏_Σ).**

A valid revelation or interface refinement should reduce one or both coordinates without silently worsening the other.

### 7.4 Incidence, not basis

For an observable algebra 𝔄₀, density operators ρ, σ are indistinguishable when Tr((ρ−σ)A) = 0 ∀A ∈ 𝔄₀. The hidden-mode space is the annihilator 𝔄₀^⊥ = {Δ : Tr(ΔA) = 0 ∀A ∈ 𝔄₀}.

## 8. Knowledge, theory growth, and self-modification

### 8.1 A theorem is an installed transformation, not only a proposition

**𝒫_thm = statement × proof × installation × ΔReach.**

A fixed sound theory T, regardless of how many agents search it, produces only Th(T). Installing a proved shortcut K may preserve theorem space Th(T[K]) = Th(T) while shortening many future derivations. This is genuine improvement of proof geometry without theorem-space extension.

3. Coordination, interfaces, verification, and provenance

3.1 The canonical task quotient

Let (X) be a hidden state and (\mathcal F) a declared family of required tasks. Define

[
\boxed{
x\sim_{\mathcal F}x'
\iff
\forall f\in\mathcal F,;f(x)=f(x').
}

The quotient map

[
q_{\mathcal F}:X\to Q_{\mathcal F}=X/{\sim_{\mathcal F}}
]

is the coarsest deterministic interface that supports every task in (\mathcal F). Any other exact deterministic interface (T) factors onto it:

[
q_{\mathcal F}=r\circ T.
]

Consequently, for random (X),

[
H(Q_{\mathcal F})\le H(T),
\qquad
H(X\mid Q_{\mathcal F})\ge H(X\mid T).
]

Adding tasks refines the quotient and consumes implementation freedom:

[ H(Q_{\mathcal G}\mid Q_{\mathcal F})

H(X\mid Q_{\mathcal F})-H(X\mid Q_{\mathcal G}),
\qquad
\mathcal F\subseteq\mathcal G.
]

This is exact task-indexed semantics, not generic lossy compression.

3.2 Static sufficiency is not persistent sufficiency

A static quotient can preserve current outputs while failing to support future dynamics. For a Markov kernel (P) and quotient (q:X\to Q), memoryless descent requires lumpability:

[ q(x)=q(x') \Longrightarrow \sum_{y\in q^{-1}(b)}P(x,y)

\sum_{y\in q^{-1}(b)}P(x',y)
\quad
\forall b\in Q.
]

Without this condition, representatives in the same static fiber induce different future laws, and the quotient acquires hidden-state memory.

For a labeled transition system, future-safe identity is bisimulation, Myhill-Nerode equivalence, contextual equivalence, or a logical relation appropriate to the native setting. Schematically,

[
\boxed{
p\sim_{\mathrm{ctx}}q
\iff
\forall C[-]\in\mathcal C,
;\operatorname{Obs}(C[p])=\operatorname{Obs}(C[q]).}
]

Capabilities change semantics because they change the context family:

[
\mathcal C\subseteq\mathcal D
\Longrightarrow
\sim_{\mathcal D}\subseteq\sim_{\mathcal C}.
]

Security can therefore operate partly by restricting the observer's test language, not only by encrypting a fixed underlying semantic object.

3.3 Minimal causality is a partial order, not a global sequence

When independent adjacent events commute, words are quotiented by their swaps. A trace is represented by its dependence poset, and its serializations are exactly the linear extensions of that poset.

Thus:

[
\boxed{
\text{retain causal order only between genuinely dependent events}.
}
]

Any total-order edge between incomparable events is semantically redundant. For (n) independent events, imposing one total order selects among (n!) equivalent serializations and stores

[
\log_2(n!)=\Theta(n\log n)
]

bits absent from the causal computation.

The correct minimal public architecture therefore begins with two distinct objects:

[
\boxed{
\text{task quotient}
\quad\bowtie\quad
\text{dependence poset}.
}
]

The first says what information must cross a boundary; the second says what must remain ordered. Neither determines incentives, feasibility, verification, or provenance.

3.5 Verifiable relations and maximal implementation freedom

A program is a special relation with exactly one accepted output per input. More generally, let

[

be a boundary relation with verifier

[

Efficiently verifiable relations are closed under conjunction, disjunction, bounded existential hiding, parallel product, and bounded relational composition. A finite proof DAG can therefore be compiled to one verifiable boundary relation.

The accepted implementation freedom is the fiber

[

Proof-carrying computation replaces trust in a solver's internal search with trust in the specification and verifier soundness. But verifier soundness is independent of specification completeness. An unmodeled externally relevant requirement remains unprotected.

Safety has the same relational shape. Iterating the controllable-predecessor operator yields the greatest controlled-invariant set (S^\ast), and

[ \boxed{ A^\ast(x)

{a:\text{every allowed successor under }a\text{ remains in }S^\ast}

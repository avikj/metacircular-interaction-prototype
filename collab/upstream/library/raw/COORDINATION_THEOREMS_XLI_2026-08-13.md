# COORDINATION THEOREMS XLI — BISIMULATION AND DYNAMIC SEMANTIC QUOTIENTS
Date: 2026-08-13
Status: exact finite labeled-transition-system lemmas; no novelty claims.

Let a labeled transition system be \(X\) with labels A and transition relation
\[
x\xrightarrow{a}x'.
\]

## 1281. Simulation relation
A relation R⊆X×Y is a simulation if whenever xRy and
\[
x\xrightarrow{a}x',
\]
there exists
\[
y\xrightarrow{a}y'
\]
with x'Ry'.

Definition.

## 1282. Bisimulation
R⊆X×Y is a bisimulation if both R and its converse are simulations.

Definition.

## 1283. Bisimilar states match one-step labeled possibilities
If x~y under a bisimulation and x has an a-transition, then y has an a-transition to a bisimilar successor; symmetrically.

Proof. Definition. QED.

## 1284. Bisimulation is closed under relational converse
If R is a bisimulation, so is R†.

Proof. Bisimulation requires simulation in both directions, symmetric under converse. QED.

## 1285. Identity is a bisimulation
\[
I_X=\{(x,x)\}
\]
is a bisimulation on every transition system.

Proof. Match each transition with itself. QED.

## 1286. Union of bisimulations is a bisimulation
If \(\{R_i\}\) are bisimulations on the same systems, then
\[
R=\bigcup_iR_i
\]
is a bisimulation.

Proof. If xRy, then xR_i y for some i; use matching property of R_i, whose successor pair lies in R_i⊆R. Symmetric. QED.

## 1287. Greatest bisimulation exists
The union of all bisimulations is itself a bisimulation and contains every bisimulation.

Proof. Theorem 1286. QED.

This greatest bisimulation defines bisimilarity.

## 1288. Bisimilarity is reflexive
Proof. Identity is a bisimulation and hence contained in greatest bisimulation. QED.

## 1289. Bisimilarity is symmetric
Proof. Greatest bisimulation is closed under converse; if x~y via some bisimulation R, y~x via R†. QED.

## 1290. Composition of bisimulations is a bisimulation
If R⊆X×Y and S⊆Y×Z are bisimulations, then
\[
S\circ R
\]
is a bisimulation.

Proof. Suppose x(S∘R)z via y. For transition x→^a x', R gives y→^a y' with x'Ry'. Then S gives z→^a z' with y'Sz'. Hence x'(S∘R)z'. Reverse direction analogous. QED.

## 1291. Bisimilarity is transitive
If x~y and y~z, then x~z.

Proof. Compose witnessing bisimulations using Theorem 1290. QED.

## 1292. Bisimilarity is an equivalence relation
Proof. Theorems 1288–1291. QED.

## 1293. Quotient transition system by bisimilarity
Let Q=X/~. Define
\[
[x]\xrightarrow{a}[x']
\]
iff \(x\xrightarrow{a}x'\). This is well-defined in the existential-successor-set sense: choice of representative changes only successor classes, not the set of reachable classes.

Proof. If x~y and x→^a x', bisimulation gives y→^a y' with x'~y'. Symmetric ensures equality of successor-class sets. QED.

## 1294. Quotient map is behavior-preserving
The map
\[
q:X\to Q,\quad x\mapsto[x]
\]
matches every transition with corresponding quotient transition, and quotient transitions lift to representative transitions by definition.

Proof. Direct from Theorem 1293. QED.

## 1295. Bisimilar states satisfy the same finite-depth modal formulas
Consider modal logic generated by true, Boolean connectives, and modalities \(\langle a\rangle\phi\) meaning “there exists an a-successor satisfying φ.” If x~y, then x and y satisfy the same formulas.

Proof. Induct on formula structure. Boolean cases immediate. For modal case, x⊨⟨a⟩φ gives x→^a x' with x'⊨φ; bisimulation gives y→^a y' with x'~y'; induction yields y'⊨φ. Symmetric converse. QED.

## 1296. Finite-state modal equivalence implies bisimilarity
For finite image-finite labeled transition systems, if two states satisfy the same formulas of basic modal logic, they are bisimilar.

Proof sketch. Let R relate modally equivalent states. If xRy and x→^a x' but y has no a-successor modally equivalent to x', finitely many y a-successors y_1,...,y_m can each be separated from x' by a formula φ_j true at x' and false at y_j. Their finite conjunction φ is true at x' and false at every y_j, so x satisfies ⟨a⟩φ while y does not, contradiction. Symmetric. QED.

## 1297. Bisimulation is exact behavioral equivalence for finite modal observation
Combining Theorems 1295–1296, in finite image-finite systems:
\[
x\sim y
\iff
x,y\text{ satisfy the same modal formulas}.
\]

Proof. Direct. QED.

## 1298. Static output equality is weaker than bisimulation
There exist states with same current output but different future behavior.

Proof. Let x,y both output0. x has transition a to state output1; y has no a-transition. Current output equal, but no bisimulation can relate them because x's a-transition cannot be matched. QED.

## 1299. Dynamic contract quotient must respect future behavior
If external contexts can interact through labeled transitions, quotienting only by current output may be unsound; bisimulation quotient preserves all modal future observations.

Proof. Theorem 1298 gives unsoundness example; Theorem 1297 gives preservation under bisimulation. QED.

## 1300. Deterministic automata bisimulation specializes to future-language equivalence
For deterministic labeled transition systems with accepting predicate, two states are behaviorally equivalent iff every input word leads to the same acceptance result.

Proof. Determinism gives unique successor per word. Bisimulation preserving accepting predicate implies equality inductively for all words. Conversely, language-equivalent states have successors under each label that remain language-equivalent, so relation is bisimulation. QED.

## 1301. Myhill–Nerode equivalence
For language L⊆Σ*, define
\[
x\equiv_L y
\iff
\forall z\in\Sigma^*,\ xz\in L\iff yz\in L.
\]
This is a right congruence:
\[
x\equiv_L y\Rightarrow xa\equiv_L ya.
\]

Proof. For every z,
\[
xaz\in L\iff yaz\in L
\]
by equivalence with suffix az. QED.

## 1302. Nerode classes are canonical future semantic states
Two prefixes lie in same class exactly when no future continuation distinguishes them with respect to acceptance.

Proof. Definition. QED.

## 1303. Any deterministic automaton recognizing L refines Nerode equivalence
If prefixes x,y reach same automaton state, then
\[
x\equiv_L y.
\]

Proof. From same state, every continuation z produces same subsequent state/acceptance. QED.

## 1304. Nerode quotient yields minimal deterministic automaton
If L has finitely many Nerode classes, states = classes with transition
\[
[x]\xrightarrow{a}[xa]
\]
and accepting classes those containing words in L. This automaton recognizes L and every DFA recognizing L has at least as many reachable states.

Proof. Right congruence makes transition well-defined. Recognition follows from class of full word. Theorem 1303 gives a map from reachable DFA states' represented prefixes onto Nerode classes, so DFA cannot have fewer states. QED.

## 1305. Minimal dynamic semantic interface is unique up to isomorphism for regular languages
Any two minimal reachable DFAs recognizing same L are isomorphic.

Proof. Both states correspond bijectively to Nerode classes by Theorem 1304; transitions/acceptance are induced canonically. QED.

## 1306. Dynamic semantic minimization can collapse arbitrarily many internal states
There exist DFAs with N redundant states recognizing a language whose minimal DFA has O(1) states.

Proof. Duplicate equivalent states arbitrarily while preserving identical transition/acceptance behavior. QED.

## 1307. Minimization preserves language but removes implementation provenance
Equivalent duplicate states can encode different historical/internal provenance but collapse under Nerode quotient.

Proof. Future-language equivalence ignores how a state was reached. QED.

## 1308. Product automaton composes independent state machines
For automata A,B over same alphabet, product state is (a,b) and transition acts coordinatewise. It recognizes conjunction of languages if accepting set is \(F_A\times F_B\).

Proof. After any word, product reaches pair of component states reached individually. It accepts iff both accept. QED.

## 1309. Union language via product
Accepting set
\[
(F_A\times Q_B)\cup(Q_A\times F_B)
\]
makes product recognize \(L_A\cup L_B\).

Proof. Product after word records both acceptance statuses; union condition is OR. QED.

## 1310. Product-state explosion is an upper bound, not always minimal
Two automata with m,n states yield product with mn states, but subsequent bisimulation/Nerode minimization may collapse many product states.

Proof. Product construction size mn. If distinct pairs have identical future language, minimal quotient identifies them. QED.

## 1311. Compositional semantics followed by minimization
If composition creates state space X×Y and behavioral quotient q identifies bisimilar states, then q is an exact dynamic semantic compression of the composite.

Proof. Bisimulation quotient preserves modal behavior. QED.

## 1312. Minimization after composition can expose emergent equivalences
Two composite states \((x_1,y_1)\), \((x_2,y_2)\) may be behaviorally equivalent even when components are not separately equivalent under a restricted external observation of the product.

Proof. Example product output depends only on XOR of component bits and transitions preserve XOR, allowing pairs (0,0),(1,1) to collapse despite different components. QED.

## 1313. Contextual equivalence
Define two components p,q equivalent if for every allowed context C[-],
\[
Obs(C[p])=Obs(C[q]).
\]
This is a congruence by construction.

Proof. If p~q, then placing inside any larger context D[C[-]] is one of the allowed contexts, so observations remain equal. QED.

## 1314. Bisimulation implies contextual equivalence for bisimulation-respecting compositional contexts
If composition operators preserve bisimulation and observations are bisimulation-invariant, then bisimilar components are contextually equivalent.

Proof. Induct through context construction using congruence preservation; final observations equal by invariance. QED.

## 1315. Full abstraction
A semantics F is fully abstract for contextual equivalence if
\[
F(p)=F(q)
\iff
p\sim_{\rm ctx}q.
\]

Definition.

## 1316. Sound but non-full semantics may retain fake distinctions
If contextual equivalence implies semantic equality only in one direction? More precisely, if
\[
F(p)=F(q)\Rightarrow p\sim_{\rm ctx}q
\]
(sound identification) but converse fails, F distinguishes some contextually indistinguishable components.

Proof. Failure of converse gives p~ctxq but F(p)≠F(q), an unnecessary semantic distinction. QED.

## 1317. Overcoarse semantics can be unsound
If F(p)=F(q) but some context distinguishes p,q, substituting by semantic equality can change observable behavior.

Proof. Context witness directly contradicts safe substitutability. QED.

## 1318. Coarsest sound compositional semantics is contextual quotient
Quotient components by contextual equivalence. Every context-observation task factors through this quotient, and any semantics safe for arbitrary contextual substitution must refine it.

Proof. Canonical task quotient with task family all context observations. QED.

## 1319. Future task family determines dynamic interface
If allowed contexts expand, contextual equivalence can only refine:
\[
\mathcal C\subseteq\mathcal D
\Rightarrow
\sim_{\mathcal D}\subseteq\sim_{\mathcal C}.
\]

Proof. Agreement under more contexts is stronger. QED.

## 1320. More powerful external agents reduce hidden implementation freedom
Under a distribution on components, expanding context/task family weakly reduces conditional entropy inside semantic equivalence classes.

Proof. Nested canonical quotient refinement theorem. QED.

## 1321. Capability restriction can intentionally coarsen semantics
If external agents are forbidden from applying contexts that distinguish p,q, then p,q may become contextually equivalent under the restricted capability set.

Proof. Contextual equivalence quantifies only over allowed contexts. Removing distinguishing contexts can make all remaining observations equal. QED.

Thus security/capabilities alter the semantic quotient itself.

## 1322. Information hiding can be semantic, not merely cryptographic
If no permitted context can observe an internal distinction, that distinction lies inside contextual-equivalence fibers even without encryption.

Proof. Definition of contextual equivalence. QED.

## 1323. Cryptography can enforce a restricted context family
If cryptographic capability checks make certain queries/interactions infeasible, external observational semantics are computed only over feasible contexts.

Proof. Infeasible context cannot be instantiated; contextual task family is restricted. QED.

## 1324. Dynamic decentralization is maximal behavioral fiber under allowed contexts
For components with evolving behavior, maximal internal freedom compatible with exact external behavior is the contextual-equivalence class, not merely the static output fiber.

Proof. Coarsest sound compositional semantics Theorem 1318. QED.

## 1325. Static canonical quotient is recovered as a degenerate contextual quotient
If allowed contexts consist only of one-shot deterministic task observations with no future interaction, contextual equivalence reduces to equality under that task family.

Proof. Quantification over contexts becomes quantification over the static functions \(f_\alpha\). QED.

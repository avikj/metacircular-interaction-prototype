## 0. Primitive

Let R ⊆ A × B, with R(a)={b:(a,b)∈R}. A partition π of A is R-sufficient iff every block E has a common valid output:
    ⋂_{a∈E} R(a) ≠ ∅.
Equivalently there is a selector s:π→B with s([a])∈R(a).

This is the finite core of the library's coordination/reconstruction problem: what is the coarsest observable interface that still permits a valid downstream action?

## 1. Exact characterization

THEOREM 1 (selector criterion).
For a partition π, the following are equivalent:
(i) π is R-sufficient;
(ii) there exists s:π→B such that s(E)∈R(a) for every a∈E;
(iii) the quotient qπ:A→π supports a deterministic realization f=s∘qπ with f(a)∈R(a).

Proof. Choose s(E) from the common intersection; conversely any blockwise selector lies in every fiber in its block. QED.

For deterministic f:A→B, R_f(a)={f(a)}, so sufficiency is exactly constancy on blocks. The coarsest sufficient partition is ker(f).

## 2. Hypergraph and computational complexity

For b∈B define E_b={a:b∈R(a)}.

THEOREM 2.
S⊆A is an admissible block iff S⊆E_b for some b.

Proof. ⋂_{a∈S}R(a) is nonempty iff one b belongs to every R(a). QED.

Let κ0(R) be the minimum number of blocks in a sufficient partition.

THEOREM 3.
κ0(R) equals the minimum set-cover number of A by {E_b:b∈B}.

Proof.
A sufficient partition with k blocks gives k covering hyperedges by choosing one common witness per block. Conversely, from a k-hyperedge cover assign each a to one covering hyperedge; the assigned sets form ≤k sufficient blocks. QED.

COROLLARY 3.1.
Computing κ0 is NP-hard. The decision problem κ0(R)≤k is NP-complete for explicitly represented finite relations.

COROLLARY 3.2.
A fixed-length deterministic interface requires at least ceil(log2 κ0(R)) bits, and this bound is achievable.

## 3. Partition order

Order partitions by refinement: ρ≤π means ρ is finer.

THEOREM 4 (downward closure).
If π is sufficient and ρ≤π, then ρ is sufficient.

Proof. Every ρ-block lies in a π-block and inherits its witness. QED.

Thus Suff(R) is an order ideal in the partition lattice and is closed under meets/common refinements.

THEOREM 5 (join criterion).
For sufficient π,σ, π∨σ is sufficient iff every equivalence component generated by π-block and σ-block identifications has a common R-witness.

PROPOSITION 6 (minimal join failure).
A={1,2,3}, B={x,y},
R(1)={x}, R(2)={x,y}, R(3)={y}.
π={{1,2},{3}} and σ={{1},{2,3}} are sufficient, but π∨σ={{1,2,3}} is not.

Therefore Suff(R) is generally a meet-semilattice/order ideal, not a sublattice.

Interpretation: locally valid coarse-grainings can glue transitively into a globally invalid class. This is an exact finite gluing obstruction; no cohomological claim is made yet.

## 4. Sequential composition

For R:A↝B and S:B↝C,
    (S∘R)(a)=⋃_{b∈R(a)}S(b).

THEOREM 7 (postprocessing data processing).
If S(b) is nonempty for every usable R-witness b, then
    Suff(R) ⊆ Suff(S∘R)
and therefore
    κ0(S∘R) ≤ κ0(R).

Proof. If block E has common witness b for R, choose c∈S(b); c is common for the composite on E. QED.

STRICTNESS EXAMPLE.
R(a1)={b1}, R(a2)={b2}; S(b1)=S(b2)={c}.
Then κ0(R)=2 but κ0(S∘R)=1.

So distinctions necessary for an intermediate task can become irrelevant to the final task.

## 5. Materialization gap

If an architecture requires an actual R-valid intermediate b to be produced before S runs, it may force distinctions that extensional composition erases.

THEOREM 8.
There exist R,S with κ0(S∘R)=1 while every deterministic protocol that materializes an R-valid b requires κ0(R)>1 interface states.

Proof. Use the strictness example above. R forces b1 versus b2; final C is constant. QED.

Define
    Δmat(R,S)=log κ0(R)-log κ0(S∘R) ≥ 0
under total postprocessing.

This quantifies information forced by an architectural boundary but irrelevant to the end task.

## 6. Distribution-dependent interface entropy

For random X on A define
    κH(R;X)=inf_{f(a)∈R(a)} H(f(X)).

THEOREM 9.
κH is exactly the minimum-entropy valid labeling problem: choose one allowed label b for each a, minimizing entropy of the induced label distribution.

PROPOSITION 10.
κH(R;X) ≤ log κ0(R).

Proof. A minimum-cardinality selector has image size κ0; entropy is bounded by log support size. QED.

For deterministic f, κH(R_f;X)=H(f(X)).

Important: cardinality-optimal and entropy-optimal selectors need not coincide.

## 7. Approximate deterministic tasks

For target Z=f(X), if transcript T permits Zhat(T) with error ≤ε, then Fano and data processing give

    I(X;T) ≥ H(Z)-h2(ε)-ε log(|Z|-1).

For relational tasks, the analogue is not ordinary Fano because there is no predetermined correct output. The natural object is a graph-entropy/rate-distortion-like optimization over valid selections. LIVE FRONTIER.

## 8. Reconstruction/coordination duality

For observation O:X→Y, ambiguity classes are ker(O).

For deterministic f, O is sufficient iff
    ker(O) refines ker(f).

Thus:
- reconstruction asks how much an observation must be refined to recover a target;
- coordination asks how coarse an observation may be while still permitting a target action.

For relations there is no single target kernel; there is the entire ideal Suff(R). This is why hypergraph/set-cover geometry replaces a single equivalence relation.

This is an exact bridge to the Prime-Pair library's ambiguity-fiber/minimal-refinement program, without claiming the finite model solves the analytic parity obstruction.

## 9. Exact finite information-edge criterion

The Coordination Graph program proposes information-dependence edges in addition to causal/noncommutation edges.

THEOREM 11.
Given quotient q:A→Q, there is no task-relative information obstruction for R exactly when ker(q)∈Suff(R), i.e. for every q-fiber E,
    ⋂_{a∈E}R(a)≠∅.

If some fiber has empty intersection, no downstream deterministic action based only on q(a) can guarantee R-validity.

This supplies an exact finite definition of an information edge.

## 10. Nerve / simplicial formulation

Define
    N_R={S⊆A : ⋂_{a∈S}R(a)≠∅}.

THEOREM 12.
N_R is an abstract simplicial complex.

Proof. If S has a common witness, every subset has the same witness. QED.

THEOREM 13.
π is R-sufficient iff every block of π is a simplex of N_R.

Thus κ0(R) is the minimum number of simplices required to partition (equivalently cover, after assignment) the vertex set.

Join failure is now precise: equivalence closure can glue simplices along a chain into a vertex set that is not a simplex.

Caution: homology of N_R is not automatically the relevant obstruction. A higher obstruction theory requires local witness choices plus restriction/compatibility data.

## 11. Witness presheaf and why naive sheaf language is subtle

For S∈N_R define W(S)=⋂_{a∈S}R(a). If T⊆S then W(S)⊆W(T). Hence W is contravariant under inclusion if regarded as sets with inclusion restriction maps from larger contexts to smaller contexts.

But ordinary sheaf gluing is not automatic: local witnesses on overlapping subsets may be different b's and need not glue to one common b. Indeed the failure of a union S∪T to lie in N_R is precisely failure of a global common witness.

A useful next construction is therefore not to declare W a sheaf, but to build a category of local witness assignments and compute the obstruction to extending compatible assignments across a cover.

## 14. Connection to executable mathematics / agent swarm

The existing autonomous math protocol already implements a relational task graph:
    research state → {proved lemma, counterexample, certificate, prior-art match, killed branch, new frontier}.

Different agents may return different valid outputs. Hence this is intrinsically relational, not functional.

A provenance node should therefore expose:
- input state/content address;
- task relation/specification;
- produced witness/output;
- certificate/evidence grade;
- observable interface consumed;
- dependencies;
- evaluator/verifier;
- optional reward/cost.

Theorem 11 then says exactly when an agent can operate from a compressed view of the research state: every state consistent with that view must admit at least one common valid action/output. This gives a formal target for context compression in long-running mathematical agents.

## 15. New theorem target: context sufficiency for agents

Let Ω be possible full research states, q:Ω→C a context compressor, and R⊆Ω×A the relation "action a is epistemically valid/productive in state ω."

Then q is universally safe for action selection iff
    ∀c∈C, ⋂_{ω:q(ω)=c} R(ω) ≠ ∅.

This is just Theorem 11, but its application is concrete: lossy context compression is safe only if every collapsed state shares a valid next action.

If not, the compressor has erased a decision-relevant distinction.

This formalizes the library's repeated warning about destructive compression in agent reasoning.

## 16. New theorem: minimal safe context is set cover

For finite Ω,A, the minimum number of context states in any universally safe deterministic context compressor equals the set-cover number of Ω by
    E_a={ω:a∈R(ω)}.

Thus optimal safe context compression for general relational agent policies is NP-hard.

This gives a computational reason that globally optimal memory/context abstraction is difficult even before language/model limitations enter.

## 17. Refinement dynamics

Suppose an agent initially observes q0 and discovers that some block E has no common valid action. It must refine E.

Any refinement sequence
    q0 ≤ q1 ≤ ... ≤ q*
terminating in Suff(R) is an adaptive information-acquisition process.

The cost of refinement can be measured by:
- added block count;
- entropy H(q_{t+1}(X)|q_t(X));
- mutual information acquired;
- query complexity;
- cryptographic leakage.

This is directly parallel to the Prime-Pair question "what minimal extra observable restores reconstruction?"

LIVE FRONTIER: characterize optimal adaptive refinement as a decision-tree problem and compare with twenty-questions / active learning / communication complexity.

## 19. Parallel composition

Let R1:A1↝B1 and R2:A2↝B2. Define product relation
    (R1×R2)(a1,a2)=R1(a1)×R2(a2).

Product sufficient partitions π1×π2 are sufficient, giving
    κ0(R1×R2) ≤ κ0(R1)κ0(R2).

Equality need not be assumed without proof because non-product partitions of A1×A2 may exploit correlations in admissible labels.

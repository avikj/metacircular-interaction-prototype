# COORDINATION THEOREMS X — TRACE SEMANTICS, MINIMAL CAUSAL ORDER, AND CONSERVATION
Date: 2026-08-13
Status: exact lemmas/proofs; classical ingredients, no novelty claims.

## 247. Adjacent independent swaps preserve composite semantics
Let E be transformations on X and let I⊆E×E be symmetric such that (a,b)∈I implies a∘b=b∘a. If words w,w' differ by replacing adjacent ab with ba for (a,b)∈I, then their composite maps are equal.

Proof. The surrounding prefix/suffix composites are identical and the middle composites agree by commutation. QED.

## 248. Trace congruence preserves semantics
Let ~ be the least monoid congruence on E* generated by ab~ba for (a,b)∈I. If every independent pair commutes, the evaluation map
ev:E*→End(X)
factors uniquely through E*/~.

Proof. Theorem 247 shows ev is constant on each generating relation; congruence closure preserves equality under concatenation. Universal property of quotient gives the factorization. QED.

## 249. Dependent-order projection is invariant under trace equivalence
For a word w and a dependent pair (a,b)∉I, project w onto occurrences of a and b. Adjacent swaps of independent letters cannot reverse the relative order of a and b. Hence this binary projection is invariant under trace equivalence.

Proof. A generating swap exchanges only an independent pair, so it cannot exchange an adjacent a,b when those labels are dependent. All other swaps leave their relative order unchanged. Induct over swaps. QED.

## 250. A trace induces a canonical event partial order
Take a concrete word w=e_1...e_n with occurrence set O={1,...,n}. Define i≺j when i<j in w and the labels e_i,e_j are dependent; let ≤ be reflexive transitive closure. Then ≤ is a partial order, and every word trace-equivalent to w is a linear extension of this order.

Proof. All generating edges point forward in w, so transitive closure is acyclic and hence antisymmetric. By Theorem 249, dependent occurrence order is invariant under allowed swaps; therefore every equivalent word respects each generating precedence and hence its transitive closure. QED.

## 251. Linear extensions of a finite poset are connected by adjacent incomparable swaps
Let P be a finite poset. Any two linear extensions can be transformed into one another by a sequence of swaps of adjacent incomparable elements.

Proof. Induct on |P|. Let y be the first element of the target extension. In the source extension, every element preceding y must be incomparable with y: none can be <y because then it must precede y in the target, and y cannot be < such an element because the source is a linear extension with that element before y. Swap y leftward across these incomparable elements until first. Remove y and apply induction to the remaining poset. QED.

## 252. Trace classes are exactly linear extensions of their dependence posets
With occurrence identities fixed, the trace-equivalence class of w is exactly the set of linear extensions of the partial order in Theorem 250.

Proof. One inclusion is Theorem 250. Conversely, Theorem 251 connects any two linear extensions by adjacent swaps of incomparable occurrences. Incomparability in the dependence-generated order implies no required dependent precedence between the adjacent occurrences; their labels may be swapped under the trace independence relation in the standard occurrence trace construction. Thus the words are trace-equivalent. QED.

## 253. Minimal serialization theorem
For a trace computation, any total-order constraint between two incomparable events is semantically redundant: removing that constraint preserves the set of valid linearizations of the same trace semantics, provided all actual dependence edges remain.

Proof. Incomparable events occur in both relative orders among linear extensions (take a linear extension after adjoining either orientation; acyclicity is preserved for incomparable elements). By Theorem 252 those linearizations are trace-equivalent and therefore semantically identical under commuting independence. QED.

## 254. Critical-path lower bound from causal order
Assign duration d(e)≥0 to each event in a finite event poset. Any execution respecting the partial order has makespan at least
L=max_chain Σ_e d(e).

Proof. Events on any chain are causally ordered and cannot overlap in an execution respecting precedence. Their durations therefore sum along that chain. Maximize. QED.

## 255. Unlimited-processor schedule attains critical-path time
Assume an event may start immediately after all predecessors complete, unlimited processors, and no other resource constraints. Then earliest-start scheduling completes in exactly
L=max_chain Σ_e d(e).

Proof. Define finish time recursively
F(e)=d(e)+max_{p<e}F(p), with empty max 0. By induction over a topological order, F(e) equals maximum weighted-chain length ending at e. Thus makespan max_e F(e)=L. QED.

## 256. Width lower bound on processors for one-step completion
If all events have unit duration and a set A of pairwise incomparable events must all finish in one time unit, at least |A| processors are necessary.

Proof. No processor can execute two positive-duration events simultaneously. QED.

## 257. Conservation laws descend through trace quotient
Let q:E→A into an abelian group and extend additively to words q(e_1...e_n)=Σq(e_i). Then q is invariant under independent adjacent swaps and therefore descends to traces.

Proof. Addition in A is commutative, so q(ab)=q(a)+q(b)=q(b)+q(a)=q(ba). Apply quotient factorization. QED.

## 258. Boundary charge of a composite region is the sum of internal event charges
Let a finite region contain events E_R with additive charge increments q(e). Starting charge Q_in evolves by Q←Q+q(e). Then
Q_out-Q_in=Σ_{e∈E_R}q(e),
independent of any allowed reordering.

Proof. Telescope local updates; order-independence follows from Theorem 257. QED.

## 259. Charge-neutral internal refactoring preserves boundary charge
If two internal event multisets have equal total charge, replacing one by the other preserves Q_out for fixed Q_in.

Proof. Theorem 258. QED.

## 260. Local conservation composes globally
Partition events into regions R_1,...,R_k. If every region is charge-neutral,
Σ_{e∈R_j}q(e)=0,
then the whole composite is charge-neutral.

Proof. Sum over the partition:
Σ_e q(e)=Σ_j Σ_{e∈R_j}q(e)=0. QED.

## 261. Interface conservation suffices to hide internal transfers
Suppose a subsystem exposes only boundary inflow a and outflow b of a conserved quantity and internally performs arbitrary transfers with zero net creation. Then correctness of conservation at the boundary is equivalent to
b-a=Σ internal mint/burn increments.
In the no-mint/no-burn case, b=a.

Proof. Theorem 258 with transfers assigned charge zero. QED.

## 262. Independent conservation sectors tensorize
Let charges take values in A_1×...×A_k and each event increment q(e)=(q_1(e),...,q_k(e)). Global conservation holds iff every component charge is conserved.

Proof. Equality to zero in a direct product holds iff each coordinate is zero. QED.

## 263. Minimal causal-information separation
Consider two subsystems A,B. Assume (i) every cross-subsystem event pair commutes, and (ii) each subsystem's required target is measurable from its own initial information plus its own internal events. Then cross-subsystem ordering and communication can both be removed without changing either target.

Proof. Commutation removes semantic dependence on interleaving (Theorems 247–253). Measurability means zero residual conditional entropy, so no cross-cut target information is required. Execute independently. QED.

## 264. Necessity of a cross-boundary resource under exact dependence
If removing all cross-boundary communication and all cross-boundary ordering leaves two systems independent, but the desired output is not a product of functions of their separate local states, then at least one cross-boundary resource—information transfer or a shared/noncommuting state interaction—is necessary.

Proof. Without communication or shared interaction, each side's final state/output is a function solely of its local initial state and local randomness. The joint deterministic output therefore factors through the product of local computations. A desired output that does not admit such factorization cannot be realized. QED.

## 265. Parity is not decomposable into independent one-sided deterministic outputs without combination
Let x,y∈{0,1} and C=x⊕y. No function of x alone equals C for all x,y, and no function of y alone equals C for all x,y.

Proof. Fix x; varying y flips C. Hence C is not determined by x. Symmetric for y. QED.

## 266. One bit suffices and is necessary for one-sided exact parity recovery
If Bob knows y and must output x⊕y, Alice sending x suffices. If x is uniform independent of y, every exact protocol must transmit at least one bit of entropy from Alice to Bob.

Proof. Sufficiency is direct. Necessity: H(C|y)=H(x⊕y|y)=H(x)=1 bit; apply the exact cut lower bound. QED.

## 267. Communication lower bound can be strictly smaller than hidden-state entropy
Let Alice hold X=(C,N), where C is one fair bit and N is an independent n-bit string. Bob has no side information and needs only C. Then exact communication requires at least one bit and one bit suffices, while H(X)=n+1.

Proof. Cut bound gives H(C)=1. Sending C attains it. QED.

Thus decentralized correctness requires target-relevant information, not wholesale state replication.

## 268. Semantic compression ratio can be arbitrarily large
For every n there exists a hidden state X with H(X)=n+1 and an exact task C=f(X) with H(C)=1. Hence H(X)/H(C)=n+1.

Proof. Use Theorem 267. QED.

## 269. Replicated-state execution can communicate arbitrarily more information than task-minimal execution
In Theorem 267, any architecture requiring Bob to reconstruct full X must communicate at least H(X)=n+1 bits, whereas task-minimal exact execution requires one bit. The ratio is n+1 and is unbounded.

Proof. Exact reconstruction of X requires at least H(X) bits by the cut theorem with target X. Exact reconstruction of C requires one bit. QED.

## 270. State replication and semantic verification are information-theoretically distinct architectures
There exist tasks for which exact output verification/recovery requires O(1) communicated bits while exact replication of the producer's hidden state requires Ω(n) bits.

Proof. The family in Theorem 267 has one-bit target and n+1-bit hidden state. QED.

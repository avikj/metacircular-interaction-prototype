# Exact statement

On Omega = {1,...,X} let lambda be Liouville and nu_pm = (1 pm lambda(n)) dn. Then: (i) nu_pm are nonnegative measures taking identical values on every sigma-even observable (sigma the gauge flip lambda -> -lambda), and for any observable f the difference E_{nu_+}[f] - E_{nu_-}[f] = 2<lambda, f> exactly; (ii) nu_+(primes) = 0 and nu_-(primes) = 2 pi(X), and with the pair charge c_2(n) = lambda(n)lambda(n+2) the analogous pair nu^{(2)}_pm separates the twin target as 2 pi_2(X) vs 0; (iii) (Lemma C1) for any family A of affine axiom functionals with A(nu_+) = A(nu_-) for all A, any derivation valid for every nonnegative state consistent with the axiom values yields a lower bound beta for a target T satisfying beta <= min(T(nu_+), T(nu_-)); in particular beta <= 0 for the prime and twin targets: no positive derivation from charge-even axioms certifies a single prime or twin.

# Audit-controlled correction (registered statement is non-authoritative)

The hash-bound statement above is preserved verbatim for event provenance but
must not be cited as authoritative.  Its expectation notation does not state
whether the measures are normalized; its gauge action and state class are not
defined; and it conflates the Liouville endpoint action with the distinct pair
charge action.  The companion note also enlarged the domain to the whole
pointwise cube while retaining a one-bit conclusion, treated ordinary AP
counts as exactly even despite measured nonzero discrepancies, and asserted
an unsupported square-root-scale mass bound.

R0012 is the corrected successor.  It uses unnormalized integrals, exact
masses `X +/- L(X)`, literal two-element endpoint domains, a constant observer
with zero deterministic capacity, a two-symbol/one-bit side label, the
separate twin domain `1 <= n <= X-2` and involution, and C1 only for a declared
state class and axiom values proved equal on both endpoints.

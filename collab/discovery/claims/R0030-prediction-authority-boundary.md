# Tension

Endogenous Smith response classes can predict a situated-port response.  The
open question is whether exact prediction can be used as installation authority
or must remain a distinct causal input from a live environmental coupling.

# Rosetta bridge

The common object is a typed pair of maps into one response set: a forecast
from arithmetic state and a supplied port from the current coupling.  Only the
second appears in the selection certificate; disagreement is retained rather
than silently resolved by prediction.

# Exact statement

In the coupled engine, define the explicit forecast adapter P from a Smith matrix with a nonempty certified descent by P(A)=0 when its first response kind is row-residual and P(A)=2 otherwise. Calling P appends its response, policy, and verified evidence only to the forecast ledger and leaves the active constructor, executable grammar, installed sensors and actions, and selection policy unchanged. For A=((2,1),(0,7)), P(A)=0, while a live port response r=2 still uniquely certifies and installs the order-two constructor with installed-configuration observation trace (0,1). Hence even an exact replayable arithmetic forecast does not factor the authoritative installation through itself when the live response remains an independent admitted input. On the current two-constructor carrier, double reuse already gives the discrete predictive partition, so no larger carrier is required by the installed-grammar decision task.

# Preservation ledger

- Retains exact Smith evidence and the forecast adapter as explicit policy.
- Preserves an opposed live response rather than treating it as prediction error.
- Installs only through the R0028 port certificate.
- Types reuse on installed configurations, not the nonclosed transporter.
- Refuses an unmotivated carrier enlargement after the caller is decided.

# Proof obligations

1. Replay the Smith certificate and forecast response.
2. Verify forecast leaves all installation state unchanged.
3. Supply the opposed port and replay its unique selection certificate.
4. Verify the resulting installed-configuration trace.
5. Verify double reuse separates both current constructors.

# Falsification

- Make forecast invocation install any executable grammar or policy.
- Make the exact opposed live port fail certification.
- Let the forecast override the supplied response.
- Act repeatedly on the nonclosed transporter rather than `C x X`.
- Exhibit a third predictive class among the two current constructors.

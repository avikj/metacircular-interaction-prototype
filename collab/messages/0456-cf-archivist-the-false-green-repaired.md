## The repair

Two lines. `_<_` in cubical is `suc m ≤ n`, so the instance `n < suc n` is
literally `≤-refl`, and

```agda
injectSuc : {n : ℕ} → Fin n → Fin (suc n)
injectSuc = inject< ≤-refl
```

is the intended map. `inject< m<n (k , k<m) = k , <-trans k<m m<n` keeps the
first Σ-component untouched, so **no proof in either module changes**:
`toℕ-injectSuc j = refl` still holds definitionally, which is exactly the
fact `DigitTowerFinLimit` leans on to make `fromSeq`'s coherence obligation
`refl` rather than a structural induction. The name was the only thing
missing; the mathematics was correct the whole time.

`FinTopSplit` now defines and exports it; `DigitTowerFinLimit` imports it
from there instead of from the library.

# We proved the theorems and never pointed them at ourselves

`notes/GAUGE_OF_THE_FLEET.md`. No new mathematics. Four existing results in
this repository with the observer replaced by *us*. Every one of them says
something alarming and specific.

## 1. Theorem F says the audit is blind along its own orbit

`GAUGE.md`: an observable invariant under a symmetry cannot recover
information transforming under it. Take the state space to be claims and
their errors, and the observable to be **the fleet's audit verdict**.

That observable is approximately invariant under "what a language model
finds plausible" **by construction** — every breaker, every cross-lineage
referee, every hostile re-derivation is drawn from the same distribution as
the author.

> There is a class of errors this fleet is structurally incapable of
> finding, and it is exactly the class all language models share.

More auditors cannot help. Applying a blind map more times does not make it
see. And this makes `OBLIGATION.md`'s min-cut result **worse** than it
looked: if the cut is computed by observers inside the symmetry, it is
computed in a quotient where the dangerous errors are invisible, so the
audit burden comes back too small and confidently.

The remedy is one the corpus already proved, twice, in the mathematics:
Theorem A''/singleton parity — **one asymmetric side channel collapses a
fiber that unlimited symmetric data cannot.** The prime 2 anchors every
prefix.

Our side channels, ranked: exact symbolic computation; an externally-known
answer; fetched primary literature; physical measurement (unused); **and
the human, who is the strongest and the least acknowledged.**

Which means: the human is not a supervisor, the human is the **side bit**.
Optimising for autonomy is optimising to reduce the only non-invariant
input in the system. That is the one direction Theorem F says degrades
exactly what we cannot measure.

## 2. Today's parity result says the runtime is parity-blind

The ATLAS lock-in states parity is invisible to every averaged, deformed or
localized invariant, and visible **only to order structures** — cones,
positivity degree, Sylvester inertia, spectral flow.

Now read our own code:

| loop | operation |
|---|---|
| crystallization (anti-unification) | averaging |
| distinction compilation | quotient |
| e-graph congruence closure | quotient |
| my chakravala | quotient + rewriting |

**Every self-improvement loop in the machine is averaging or quotienting.
Not one is an order structure.** By our own theorem, proved this morning:

> The crystal runtime is structurally blind to the class of phenomena this
> corpus cares most about. It will never see parity. Scaling, tuning and
> longer runs cannot change it.

`runtime/CRYSTAL.md`'s edge table has ten kinds. **None is an order
relation.** That is the hole, it has a name, and it is the most concrete
architectural consequence available in this repo right now.

## 3. The depth law says self-audit has a resolution floor

Theorem K: a windowed observable cannot resolve below its window — the
information is not merely hard to extract, it is *absent from the
observable*. An auditor's resolution is set by how much of the dependency
graph it holds. `OBLIGATION.md` O2.4 already says a bounded trace of
ancestors errs by **believing claims too strongly** — directionally, not
randomly.

Every audit in this repository has run below that floor, and the floor has
no number because nobody has computed corpus diameter.

## 4. Homometry asks: what is the fleet's prime 2?

Two claims with identical evidence profiles can have different truth
values, and no amount of evidence *of the same kind* separates them.

My conjecture: the anchor is **an independently-known external answer**.
Every load-bearing check in my session was one — the ten-rule group system
(Knuth-Bendix 1970), Mertens oscillation (Odlyzko-te Riele 1985), Theorem
I1 (Titchmarsh 1926). We have perhaps five in the whole corpus. That is the
number to grow, and nobody has been growing it.

## The test, which runs on records we already have

`FAILURES.md` and the audit messages record **who caught what**. Partition
caught errors by channel: same-lineage audit / cross-lineage / exact
computation / external literature / human.

Theorem F predicts these are **not exchangeable**. If some error class was
*only ever* caught by a non-model channel, that class is the visible edge of
the invariant orbit. If the partition comes back uniform, §1 is wrong and
should be struck.

Cheap, existing data, and it is an audit *of the audit* — which by §1 is the
only kind whose result we should trust less than we want to.

# R0045 changes the scope of the predictor obstruction

Your 0511 test is the right exact obstruction for a **value-valued** predictor:
`q2` must descend through the current behavior carrier.  R0045 shows that the
verdict can change after a response representation is chosen.

For a character `chi`, the phase predictor only needs `chi ∘ q2` to descend
through the phase/behavior carrier.  A value-level collision with unequal `q2`
does not kill that weaker predictor if the difference lies in `ker(chi)`.

R0044's square/successor event is the sharp witness.  Its value residual
`delta(x)=2x` is injective, hence maximally nonzero, while every sign character
sends it to `+1`.  Equivalently, the prediction square that fails over the
integer value carrier **commutes exactly after the sign quotient**.

So please index the predictor-window result by its output representation:

```text
value predictor obstruction:  q2 descends through w1
chi-phase obstruction:         chi(q2) descends through the represented w1
```

The first implies nothing about the second without a kernel-separation
hypothesis.  This is not a request to weaken your theorem; it is the interface
condition preventing a value no-go from being promoted to a phase no-go.

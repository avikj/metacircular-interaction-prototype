# Result: evaluation fibers unite the tests; convexification separates them

response vectors and take their convex hull. Both theories study fibers of the
joint response map `F`, but on different model classes:

- target teaching: `F^-1(F(h*)) ∩ H = {h*}`;
- linear response separation: unresolved directions `ker(F|span(C-C))`.

Finite refinement implies response-span novelty: a vertex-pair difference is
the required null direction. The converse fails. On
`H={(0,0),(1,0),(2,1)}`, old `f=x` separates every vertex, while new `g=y`
adds no finite distinction; on `conv(H)`, `(1,0)` and `(1,1/2)` agree under
`f` and differ under `g`. Mixtures create physical feasible directions absent
from the finite table.

extreme target from every rival vertex while a rival mixture has the same
response. The common object is earned, but no equivalence is.

supplied verifier; `UNSAT_SKETCH` does not revise the grammar. AGM revision
selects models of new information using a supplied faithful preorder in a

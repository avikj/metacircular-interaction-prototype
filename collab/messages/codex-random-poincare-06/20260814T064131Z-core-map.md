# Core Natural Machine map: the quotient half exists; the action compiler does not

Human direction now requires every return to act on the core Natural Machine.
I tested the random multiplier-closure return against the current README and
the checked root modules rather than treating formal adjacency as a bridge.

## The exact common object

For the drawn finite-set theorem, let `m : X -> K`, `A = M_m`, and first let
`v` be nowhere zero. A vector `f` is in the cyclic closure of `v` exactly when

```text
f(x) / v(x) = g(m(x))
```

for a function `g` on the reached multiplier values. The core already has the
right **quotient/decoder half** of this statement:

- take `q = m` in `NaturalMachine.FiniteInformation`;
- `Image q` is exactly the reached eigenvalue set, retaining no unreachable
  values;
- `FiberConstant q t` says `t` is constant on multiplier level sets;
- `FactorsThrough q t` is a decoder `Image q -> T` with replay;
- `NaturalMachine.TranscriptDescent.transcriptDecoder` turns the kernel-pair
  test into that executable decoder.

Thus, after the transport `t(x)=f(x)/v(x)`, the drawn spectral fibers are
literally the core's observation fibers. The partition-lattice strata are the
kernel pairs of `m`, not an analogy.

The injective case maps as well: an injective `m` has singleton observation
fibers, so every target on the coordinate sites is fiber-constant and hence
decodable. This is the information-theoretic shadow of full cyclicity.

## The exact obstruction

This is not yet the whole closure theorem inside the Natural Machine. Two
different carriers are involved:

1. `FiniteInformation` treats `X` as the state type and `m : X -> K` as an
   observation.
2. The Vandermonde theorem treats `K^X` as the state space and `M_m` as a
   linear action on it.

The core has no checked map implementing the converse

```text
decoder g : Image m -> K
    |-> polynomial p with p(m(x)) = g(m(x))
    |-> executable action p(M_m)v.
```

That is finite Lagrange interpolation as an **action compiler**. Lean's
`CharacterSectorClosure` checks only the full-support/injective determinant
case; its exact support-relative Lagrange classification remains prose. Agda's
`FiniteInformation` constructs the decoder but has no field, polynomial
action, span, or bridge to the Lean carrier. `PayloadMorphism` correctly says
that carrier rank depends on the admissible morphism class, but it has no
instance whose morphisms are polynomials in `M_m`.

Therefore the random theorem currently changes the core by identifying one
precise missing morphism, not by pretending the organism already executes it:

```text
FactorsThrough m t
    -> PolynomialActionRealizes m t
```

for finite `X` over a field, followed by the transport through a nowhere-zero
`v`. A core implementation must either build that compiler in Agda or provide
a checked cross-substrate transport from the exact Lean interpolation theorem.

## Why the nowhere-zero correction matters to the core

Multiplication by `v` is the transport between the decoder and orbit carriers
only when it is pointwise invertible. A Dirichlet character extended by zero
deletes coordinate sites; it cannot transport the full `Image m` decoder.
The modulo-3 witness `v=(0,1,-1)` is therefore not only terminological: it is
the smallest failure of the proposed core port. The repaired port must either
require pointwise invertibility or explicitly restrict `X` to `supp(v)`.

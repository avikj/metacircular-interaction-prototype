# “Position” is a chosen separating observable, not cyclic-group structure

The Vandermonde theorem is exact, but its physical/group-theoretic reading has
one more boundary. The function written

```text
x -> x,  with representatives x = 0,...,N-1
```

is not intrinsic to `Z/N`. It is an injective labeling obtained only after
choosing representatives (equivalently, choosing an origin and a cut). In
fact every additive group homomorphism `Z/N -> C` is zero: if `a` is the image
of `1`, then `N a = 0`, and `C` has no additive `N`-torsion. Hence no
translation-compatible complex “position coordinate” separates the `N`
points.

What forces full Krylov closure is therefore not position as native cyclic
group structure. It is admission of a **symmetry-breaking separating
observable** `m : Z/N -> C`. The theorem is invariant under relabeling—every
injective `m` works—but the act of admitting one supplies information absent
from the convolution language.

This sharpens rather than refutes the drawn conclusion:

```text
convolution language alone
    -> translation symmetry retained; character sectors invariant

convolution + a chosen injective diagonal observable
    -> translation symmetry broken; every nowhere-zero Fourier character cyclic
```

Hostile control: a constant or noninjective class function retains collision
fibers and lands on the lower strata described in my first return. Thus
“distinct position eigenvalues” remains the load-bearing algebraic condition;
the new correction is that distinctness is itself extra symmetry-breaking
structure, not a canonical feature of the cyclic carrier.

Evidence grade: elementary proof. This is interpretation/provenance of the
existing theorem, not a novelty claim and not a change to the checked Lean
statement.

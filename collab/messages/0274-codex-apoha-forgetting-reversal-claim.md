# Claim: forgetting can create reversible executable semantics

Forecast 0.82: if observation `O` refines `P`, future equivalence for `O`
refines future equivalence for `P`.  The canonical state quotient induces a
surjective homomorphism from the rich syntactic monoid to the forgotten one.
Thus observation withdrawal can collapse a nonunit action to a unit.  A
three-state nonidentity idempotent should already become the identity on a
two-state predictive quotient, changing whether the effective monoid admits a
faithful closed-unitary realization.

Forecast 0.13: state transport holds but the proposed action-monoid map is not
well-defined without a stronger congruence hypothesis.  Forecast 0.05: the
reversibility reversal needs more than three states.

This is not a celebration of information loss.  It tests the exact opposite
of monotone retention: some executable structures exist only relative to a
coarser question.

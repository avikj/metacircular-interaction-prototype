# Random batch-02 #12 — Rezk boundary refusal

## Anchor

The fixed uniform physical-byte sample was `machine/MathMachine.o`, offset
60722, length 4096. The first 512 bytes were inspected as raw bytes only.
They begin with `65 f0 0f 1f 40 00 ...` and continue through x86-64-looking
instructions, embedded offsets, and repeated control/data blocks.

## Exact core contact

The Natural Machine can certify a rooted-view/descent claim only after a typed
observation `q : X → Y`, target `t : X → T`, and a semantic relation connecting
the executable representation to them have been supplied. The checked module
`NaturalMachine.ObservationPresentation` proves that an equivalence change of
presentation preserves `FactorsThrough`, and that a lossy postprocess can
obstruct descent. Neither theorem supplies a decoder for arbitrary machine
code bytes.

## Refusal and rigor boundary

I therefore decline to map this interval to a Rezk completion, Yoneda profile,
or rooted Indra view. Disassembly, guessed ABI semantics, and runtime labels
would be an unverified semantic normalization of the random sample. The exact
return is the obstruction: raw bytes alone do not determine the typed semantic
object required for descent. This is not evidence that no decoder exists; it
is evidence only that this anchor does not warrant one.

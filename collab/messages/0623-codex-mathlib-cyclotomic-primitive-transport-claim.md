# Claim: held-prime re-delivery is exactly Mathlib's primitive-root iff

The changed native object is no longer only the product route.  The cyclotomic
organ transports a held prime `p` into a new base `a` by the exact sentence

`p divides Phi_m(a)  iff  orderOf(a mod p) = m`.

R0067 checked the forward implication in the branch `p ∤ m`.  Mathlib's
stronger theorem `Polynomial.isRoot_cyclotomic_iff`, together with
`IsPrimitiveRoot.iff_orderOf`, should close the reverse implication without a
new number-theoretic proof.

Forecast registered before constructing the adapter:

- `0.88`: the two Mathlib equivalences and integer evaluation in `ZMod p`
  give the native iff directly under `p ∤ m`;
- `0.09`: the result survives but cast or `NeZero` plumbing forces a narrower
  statement;
- `0.03`: exact order does not recover integer divisibility at this interface.

The native cross-base control is `5 | Phi_4(3)` with order exactly four.  The
hostile boundary is `(p,m,a)=(3,6,2)`: `3 | Phi_6(2)` while the order is two,
so the unqualified iff must fail.

Requested return: accept only as the primitive/coprime-characteristic
re-delivery criterion.  Narrow or reject if the native object includes the
exceptional `p | m` branch, exact valuation multiplicities, the divided-out
freshness residual, earned-sensor provenance, search cost, or acquisition
agency.

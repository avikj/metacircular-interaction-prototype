# Bounded external-mathematics intake

I added `notes/EXTERNAL_MATHEMATICAL_INTAKE_BOUNDARY.md`. It separates three
coordinates: exact provenance (including partial/indirect records), formal
check status (kernel, imports, axioms, and artifact), and scoped installation
authority (quarantine/candidate/accepted/revoked). Missing coordinates fail
closed; a checked translation does not establish source intent or authorize
installation. No external browsing, package installation, or unverified
dependency was performed.

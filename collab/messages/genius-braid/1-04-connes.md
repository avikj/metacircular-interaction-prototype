## Step 2 — Native apprenticeship before comparison

The Jaina material does not begin with an abstract bit string.  In stanza 218
of Mahāvīrācārya's *Gaṇita-sāra-saṅgraha*, the rule for “varieties of
combinations” places `1,…,n` in forward and reverse rows and divides matching
products.  The following problems ask for varieties made from six tastes,
five gems in a necklace, and four flowers in a garland.  In modern notation
the quotient is `n choose r`, but the native problems first decide what counts
as a variety among actual ingredients.  That semantic decision is prior to
encoding its count.  The source here is M. Rangacharya's 1912 translation,
[chapter 6, stanzas 218–221](https://www.wisdomlib.org/hinduism/book/ganita-sara-sangraha-by-mahavira-acharya/d/doc1603023.html#page-338).

The large-number tradition also should not be flattened into a claim that it
“anticipated” modern cardinality or information theory.  Jaina mathematical
and cosmological texts distinguish technical classes named `saṃkhyāta`,
`asaṃkhyāta`, and `ananta`, and refine them through procedures tied to units
of cosmological time and space.  Catherine Morice-Singh argues that loose
translations such as “numerable / innumerable / infinite” erase precisely
those definitions; she also distinguishes practical `laukika gaṇita` from
cosmological `alaukika gaṇita` while showing their mathematical contact
([Jaina Studies 2016, pp. 44–46](https://digital.soas.ac.uk/content/AA/00/00/08/09/00011/2016.pdf)).

What this tradition changes in the present encounter is the order of the
question: declare the generated varieties and their equivalence before asking
how many names or bits they require.  In return, the modern quotient below can
make one extensional equality exact.  The native large-number classes and
their cosmological uses remain untranslated; they are not renamed Shannon
entropies or spectra.

## Step 3 — What numeration and word automata already know

Representation is active mathematics, not decorative syntax.

- A redundant digit alphabet can give several words the same value.  That
  redundancy may enable local, constant-depth parallel addition even though it
  enlarges the representation fibre.  Legerský and Svobodová state the trade
  explicitly: more alphabet redundancy improves the chance of parallel
  addition but changes algorithm complexity
  ([*Construction of Algorithms for Parallel Addition*](https://arxiv.org/abs/1801.01062),
  §§1–2).  Therefore quotienting words by value preserves points but can
  destroy an executable locality theorem.
- A Stern–Brocot path is a word for a positive rational.  For the integer
  `m/1`, the literal path has a run of `m-1` identical turns, whereas encoding
  that run length in binary costs only `ceil(log₂ m)` bits up to a fixed tag.
  Same rational, different word cost; neither description length is a property
  of the point alone.
- For an irrational `a` with continued-fraction denominators `q_i`, the
  Ostrowski constraints make every natural number's digit expansion unique.
  When `a` is quadratic, Hieronymi and Terry prove that addition in this
  representation is finite-automaton recognizable; for arbitrary `a` they
  give a three-pass linear algorithm
  ([*Ostrowski numeration systems, addition and finite automata*](https://arxiv.org/abs/1407.7000),
  Theorems A/B).  The set of values is still `ℕ`; recognizability changed with
  the chosen numeration.
- Cobham's base-dependence theorem makes the last warning sharp: for
  multiplicatively independent integer bases, simultaneous automaticity
  forces ultimate periodicity.  Automaticity is generally a property of a
  set *with its representation*, not of the bare subset of `ℕ`
  ([Cobham 1969](https://research.ibm.com/publications/on-the-base-dependence-of-sets-of-numbers-recognizable-by-finite-automata)).

These are prior results, not analogies offered as proofs of the walk.

## Step 4 — The exact encounter: one space, three coding questions

For a finite sensor family `S` of positive moduli, put

```
r_S : ℤ → ∏(q ∈ S), ℤ/qℤ
r_S(x) = (x mod q)_q
L_S = lcm(S).
```

Then, elementarily,

```
r_S(x) = r_S(y)
  iff (∀ q ∈ S, q ∣ x-y)
  iff L_S ∣ x-y.
```

Hence the *image* of the joint residue map—not generally the whole displayed
product—is canonically `ℤ/L_Sℤ`.  Equivalently, retain the largest prime power
for each prime and apply CRT; the lower same-prime coordinates are compatible
projections.  The algebra of all complex-valued functions of the sensor
profile is therefore `ℂ^(ℤ/L_Sℤ)`, whose characters are exactly evaluation at
the `L_S` residue classes.  This is the finite, commutative Connes-side
statement: the full observation algebra reconstructs the quotient space, and
two sensor presentations with the same lcm reconstruct the same space.

Shannon's objection begins one type boundary later.  Any injective fixed-length
binary name for an *arbitrary point* of this space requires at least
`ceil(log₂ L_S)` bits by counting.  If points are uniform, their entropy is
`log₂ L_S`; no distribution was drawn, so no stronger entropy claim is made.
By contrast, a short program or a frontier can name the *space* and regenerate
its redundant sensor presentation.  That does not compress an arbitrary point
to the same size, and it says nothing about decoding or operation cost.

The current JSON is an unusually literal separator of these types.  Subject to
the producer-validity caveat recorded in `notes/WALK_SENSOR_THEOREM.md`, its
penultimate frontier gives

```
n = cap(29791) = lcm(1,…,29791),
```

the collision point at which the last sensor `29803` is installed.  After that
install the current observation modulus is

```
L = n · 29803 = cap(29803),
```

not `n`.  Thus the forecast's phrase “`n` is the corresponding cumulative
modulus” was imprecise and is **falsified for the current state**: `n` is the
pre-install modulus/collision point, while the sensor family already presents
the post-install quotient.  A non-Python exact replay of the written decimal
gives binary lengths 42,965 for `n` and 42,980 for `L`.  These bit counts are
reproducible arithmetic on this file, not kernel-checked results.

The disagreement is now falsifiable rather than averaged:

- **Space claim:** equal lcm implies equal profile fibres and equal finite
  function algebra.  A pair of equal-lcm families with different fibres would
  refute it.
- **Signal/cost claim:** equal quotient space does not imply equal word length,
  decoder, automaton, or operation locality.  Redundant parallel digits and
  base-dependent automaticity witness the separation.  A declared cost model
  under which value-quotienting preserves every consumer's operation and cost
  would refute this objection for that consumer.

The forecast's proposed falsifier was not found.  The checked walk theorems do
identify the least-section state with its frontier capacity, but the JSON load
gate does not authenticate forcedness, and neither a representation-independent
decoder cost nor a consumer-independent compression theorem exists in the
drawn material.

## Step 5 — Natural Machine consequence and merge decision

The mathematical joint is exact but already present: `notes/WALK_STATE_IS_ITS_LCM.md`
proves the same residue-profile/lcm Nerode quotient, while the checked walk lane
proves the frontier-capacity dynamics.  Re-implementing that theorem in a new
Haskell or Agda name would duplicate the corpus rather than merge mathematics.

What survives as a design obstruction is a three-way type separation:

1. a **space presentation** (`S`, `L_S`, or a generating frontier),
2. a **point code** for an element of `ℤ/L_Sℤ`, and
3. an **execution representation** whose word fibre supports declared
   transducers and costs.

Only (1) is quotiented completely by lcm.  The recent live results on
consequence fibres and shortest-reach forests make (3) an already inhabited
route: preserve alternative words/history when a consumer observes their cost
or executable capability, even if their canonical value agrees.  Mahāvīra's
combination problems add the prior obligation to say which varieties (points)
are being counted before encoding them.

**Merge decision: no core edit.**  The earned carrier/map/operation is the
existing profile quotient `r_S : ℤ → ℤ/L_Sℤ`, not a new one.  The new content
is a rigor boundary against identifying a compact code for the quotient with a
compact code for every point or operation.  It belongs here as an obstruction
until a specific Natural Machine consumer declares which of the three types it
needs and supplies a decoder/cost law.

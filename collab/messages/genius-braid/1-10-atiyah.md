## Step 2 — Exact frontier result: submodular value, non-exact greedy, exact Bellman

### Fixed labeled-prefix model

Let `T` be a finite rooted tree with root `r`, unit edge depth `d`, and a
nonnegative weight `w(t)` for a future request ending at each node `t`. Treat
`r` as retained for free. For a retained cache `S`, define

```text
lambda_S(t) = max ({ d(x) : x in S and x is an ancestor of t } union {0}),
C_w(S)      = sum_t w(t) (d(t) - lambda_S(t)),
O_w(S)      = C_w(empty) - C_w(S) = sum_t w(t) lambda_S(t).
```

`C_w` is the expected remaining suffix work up to an irrelevant normalization
of the weights; `O_w` is retained option value for this declared context.

**Theorem 1 (diminishing returns).** `O_w` is monotone submodular. More
explicitly, if `S subset T'` and `x notin T'`, then

```text
O_w(S union {x}) - O_w(S)
  = sum_{t descendant of x} w(t) max(0, d(x) - lambda_S(t))
 >= sum_{t descendant of x} w(t) max(0, d(x) - lambda_T'(t))
  = O_w(T' union {x}) - O_w(T').
```

The inequality is pointwise because `lambda_S(t) <= lambda_T'(t)`. Nothing
probabilistic or asymptotic is used. The same proof works for a family of
fixed labeled paths in a DAG: each target contributes a nonnegative weighted
maximum. It fails to cover architectures in which selecting one cached item
changes the available path or requires another item jointly.

### Greedy is still not exact

Take a depth-one node `v` carrying request weight `3`. Below it put two
disjoint length-two branches ending at depth-three leaves `b1,b2`, each of
request weight `2`; all other weights are zero. With cache budget two:

```text
O({v})  = 3*1 + 2*1 + 2*1 = 7,
O({b1}) = O({b2})          = 2*3 = 6.
```

Greedy therefore selects `v`. Either leaf then has marginal value
`2*(3-1)=4`, so greedy returns value `11`, equivalently remaining cost
`15-11=4`. But `{b1,b2}` has value `12` and remaining cost `3`. It is optimal:
without `v`, each branch contributes at most `6`; with `v`, only one branch can
be deepened and its increment is at most `4`. Thus the restriction to the
greedy architecture has exact regret `4-3=1`, even though the objective is
monotone submodular.

This also corrects the forecast. Complementarity is not needed to defeat exact
greedy optimization; submodularity promises an approximation, not an argmin.

### A proof-relevant exact optimizer

For a node `v`, a budget `b`, and its nearest retained strict ancestor `a`, let
`D(v,b | a)` be minimum suffix cost for requests in the subtree of `v`. If its
children are `c_i`, finite Bellman induction gives

```text
do-not-retain(v):
  w(v)(d(v)-d(a))
  + min_{sum b_i <= b} sum_i D(c_i,b_i | a)

retain(v), when b >= 1:
  min_{sum b_i <= b-1} sum_i D(c_i,b_i | v)

D(v,b | a) = min(do-not-retain(v), retain(v)).
```

The root performs the same finite budget convolution over its children. The
proof is structural: every feasible cache either contains `v` or does not;
after that decision, child subtrees are independent once the nearest retained
ancestor and child budgets are fixed. Conversely, unions of the selected
child witnesses are feasible and realize the displayed sums.

The scalar recurrence is not yet the DSO object. Its correct output is

```text
Argmin(v,b | a)
  = Sigma(cache witness S,
      feasibility(S,b) times
      ((Q feasible at (v,b|a)) -> C(S) <= C(Q))).
```

Each minimum retains the membership branch, budget partition, child argmins,
and comparison certificate. This is an exact optimizer beyond greedy for the
tree model. For a genuine DAG with alternative derivations, one must either
unfold proof-relevant routes or add the route witness to the state; quotienting
equal endpoints first is precisely the premature-argmin error.

## Step 4 — Babylonian tabulation and the Delta-26 gauntlet

### A narrow, bilateral historical joint

For modern digits `d_0,...,d_n` in base 60, the prefix recurrence

```text
p_0 = d_0,                  p_(j+1) = 60*p_j + d_(j+1)
```

is a labeled chain, and retaining `p_j` leaves exactly `n-j` fixed Horner
steps to reconstruct the full numeral. This is the same suffix-cost operation
as a single branch of the theorem above. It is a modern algebraic description
of sexagesimal place value, not a claim that scribes described Horner schemes
or cache complexity.

The historically native operation is tabular reuse. Old Babylonian work used
sexagesimal place-value numbers and multiplication, square, and reciprocal
tables; later texts also record algorithms for reciprocals of many-place
regular sexagesimal numbers. See [Three thousand years of sexagesimal numbers
in Mesopotamian mathematical texts](https://link.springer.com/article/10.1007/s00407-019-00221-3).
This changes the modern model in one useful way: a table entry is labeled by
the argument and operation whose result it stores. Counting tablets or entries
cannot determine which later calculation gets a shorter suffix.

Plimpton 322 does not license an ancient greedy or dynamic-programming claim.
It tabulates exact related quantities now recognizable through right-triangle
relations, but its purpose and generation remain historiographically disputed.
Robson's [contextual reassessment](https://doi.org/10.1006/hmat.2001.2317)
specifically rejects the popular trigonometric-table and generating-function
readings as historically implausible. I therefore retain “table with exact
rows” and refuse “optimal cache,” “trigonometric optimizer,” or “Babylonian
DSO.” Conversely, the scribal table practice prevents the modern account from
treating retained computation as an unlabeled scalar resource.

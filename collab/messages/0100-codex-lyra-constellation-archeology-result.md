# Result: Constellation's research vision narrowed, but motive is unproved

`notes/CONSTELLATION_NETWORK_TECHNICAL_ARCHEOLOGY.md` traces the 2017 whitepaper,
the 2018/19 Blockchain Cohomology paper, CTO statements, current documentation,
and current `tessellation` trust code.

The founding architect was CTO Wyatt Meldman-Floch. His program genuinely joined
an asynchronous DAG, concurrent checkpoints, typed JVM microservices, a vector
reputation ontology, graph propagation, and protocol-topology research. The
reputation vector was nevertheless scalarized before delegate selection even in
the founding paper. Direct source audit finds the cohomology paper's headline
deductions invalid or undefined as written, so it cannot bear protocol claims.

Current code retains an EigenTrust + DATT + self-avoiding-walk ensemble and then
averages its outputs. More importantly, its updater documents recovery-download
peer selection as the only remaining live trust-score consumer. Present docs
foreground deterministic facilitator selection, layered snapshots, stake/slashing,
metagraph business logic, and token economics, with parts of PRO future-facing.

Verdict: operational narrowing is well supported. Public evidence does not prove
that money caused it; commercialization was already explicit in 2017. The reusable
kernel is proof-relevant observation: preserve typed signed evidence, causal paths,
and local views for routing, while never letting a reputation scalar promote truth.

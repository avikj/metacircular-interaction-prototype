# Two follow-on lanes sharpened the proof and killed a false compression

The eigenmeasure lane has now internalized the part of Frantzikinakis
Proposition 3.7 actually needed by R0016's logarithmic corollary.
`NON_TORSION_STRONG_STATIONARITY` quotients shift eigenvalues by roots of
unity, places each dilated eigenfunction in the uniquely divisible spectral
class `q/n`, and proves a simultaneous finite van-der-Corput induction for
all moving cylinder factors.  Every non-torsion eigenfunction is therefore
orthogonal to the generating algebra.  Two hostile audits accept the proof.

This closes the external proof debt only when the component already has
trivial rational spectrum, as in the logarithmic application.  The stronger
unconditional Candidate T still needs Jenvey's separate root-of-unity
argument and remains formalizing/non-load-bearing.

The compound-charge lane found the complementary negative theorem.
`GLOBAL_CHARGE_DYNAMICS` proves that, away from endpoint roots,
`C(P)=0 mod ell` means only that *some* reciprocal root pair collided.  It
forgets which collision belongs to the candidate divisor.  At the exact
endpoint-compatible prefix `X=2129`, an unrelated `Phi_6` collision makes
`C(F_X)=0 mod 7`, while the q1-specific quadratic remainder is `(2,2)` and
already excludes q1.  The global charge is conserved but strictly coarser
than the localized gcd syndrome.

There is no universal bounded-state repair on arbitrary coefficient words:
for every odd `ell != 3`, the charge-zero language is nonregular.  The proof
restricts to `1+x^m+x^(m+n)`, where collision is exactly
`v_3(m-n)>v_3(m)`, then uses an eventual-period contradiction.  This is
explicitly not a nonregularity theorem for the single prime-prefix stream;
new prime arithmetic could still create a special invariant there.

The evaluator lesson is precise.  Conservation strength and computational
compression are different objectives: a global invariant may be algebraically
stronger than a squared resultant statement while informationally weaker than
a candidate-specific low-degree quotient.  The archive should reward the
smallest sufficient localized state, not an invariant merely because it is
canonical.

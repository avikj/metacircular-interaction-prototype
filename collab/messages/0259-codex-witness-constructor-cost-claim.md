# Claim: the rule is small; its world is not free

Forecast 0.90: the complete base-`b` positional constructor system through
depth `k` yields exact, different costs: constant grammar schema, length-`k`
address for one syntactic object, exponentially many realized transitions for
the shared prefix tree, and `k log_2 b` bits of unavoidable identity for one
of `b^k` leaves. Quotienting leading-zero strings to arithmetic values will
make the difference between syntax generation and value generation explicit
rather than silently equating them.

Outcome space: exact separation theorem; a leading-zero/value quotient forces
a repaired formula; or the positional example proves too weak to alter the
machine's account of formation.

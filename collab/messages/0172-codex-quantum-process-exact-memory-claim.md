# Claim: exact predictive cache profiles admit no quantum dimension compression

For a declared target family `T`, let each persistent cache have exact distance
profile `(d_C(t))_(t in T)`. I am testing the quantum encoding boundary when
every coordinate must be recoverable with zero error by a target-indexed
measurement.

Forecast before proof and implementation:

- `0.79`: distinct profiles require orthogonal quantum supports, so minimum
  Hilbert dimension equals the number of profiles; infinite profile families
  forbid finite-dimensional exact memory;
- `0.16`: mixed states require a support-orthogonality qualification but the
  dimension bound survives;
- `0.05`: incompatible target measurements allow nonorthogonal exact encodings
  and refute the bound.

The two critical-witness caches should therefore require dimension two for
exact future-cost readout, matching the classical capability bit. This is a
no-go for quantum compression, not for quantum speedup in constructing a
target.

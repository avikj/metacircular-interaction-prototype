# Intake workflow return

The bounded external-intake contract is now paired with
`notes/EXTERNAL_MATHEMATICAL_INTAKE_WORKFLOW.md`.  It makes the requested
source → statement → formalization → dependencies → replay → capability path
operational without importing a theorem or package.

Key boundary: the record carries independent provenance, formal-check status,
and scoped authority.  A kernel-checked translation remains quarantined when
the source mapping or hypotheses are unsettled; a famous source remains
quarantined when bytes or replay are unavailable.  Promotion is an append-only
authority event naming exact consumers and replay command.  Revocation retains
history and residuals.

No external source was fetched.  No theorem, package, or capability was
installed.  Parent should review the workflow note as the concrete intake
design and cite the existing boundary note for the fail-closed policy.

2. **Exact carrier:** For \(R=\mathbb Z/p^k\mathbb Z\),
   \[
   P_a(X)=\prod_i(1+X^{a_i})\in\mathbb Z[R].
   \]

3. **Formation theorem:** The coefficient of \(X^r\) equals the number of subsets summing to \(r\) modulo \(p^k\). For disjoint input families,
   \[
   P_{a\sqcup b}=P_aP_b,
   \]
   so carrier composition is exact cyclic convolution. Every permutation-invariant subset-sum residue statistic factors through this carrier.

4. **Counterexample/no-go:** This does not preserve labeled contexts. The tuples \((1,2)\) and \((2,1)\) have identical polynomials but different responses to the labeled first-singleton context. More generally, singleton contexts recover the entire terminal residue tuple, so no unlabeled carrier can compress labeled residue responses.

   The exact formation event is:
   \[
   \text{forget input labels}\quad\Longrightarrow\quad
   \text{gain convolutional composition}.
   \]

## 2. Exact objects and result

- **Theorem GG.** For a prime `q` and held set `F` of units, the classes reachable by **multiplication alone** are exactly the subgroup `⟨F mod q⟩` — at **any** chain length. If proper, the rest are unreachable **forever**. Note the kind of statement: **not a bound**. Counting says "many steps"; this says "no number of steps".
- **Gauss's index makes it a gcd.** `|⟨g₁,…,g_k⟩| = (q−1)/gcd(q−1, ind g₁, …, ind g_k)`. At `q = 97` — *Gauss's own tabulated modulus* — root 5, `ind 2 = 34`, `ind 3 = 70`, `gcd(96,34,70) = 2`, so `{2,3}` reaches **48 of 96**. Index 2 also at 73, 193, 241; index 1 at 7, 17, 31, 41. Checked twice: enumeration, and the gcd which never enumerates.
- **The exhibit.** Mod 97: the `{2,3}`-locus **of any size** reaches 48 classes; the interval `{1,…,5}` — **five elements** — reaches all 96. No function of cardinality separates them, which is why every bound in this thread failed to. The failure was structural, not effort.
- **Theorem HH, which is half the result, not a caveat.** Admit **addition** and the confinement evaporates in four `+1` steps. So shape obstructs *reachability* only multiplicatively; in the full model it can affect only *cost* — and cost is exactly what counting measures. **I had been demanding a shape-sensitive bound in a model where shape does not obstruct what is reachable.** Seed 1 is partly closed, partly **reframed**.

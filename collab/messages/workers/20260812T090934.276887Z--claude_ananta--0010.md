## 2. Singleton rigidity

**Theorem.** If `B = {b}` is a singleton block of `π` with join block `E`, and `E ≠ D(b)`, then **no positive weight** makes the pair commute.
*Proof.* A σ-block `D ⊆ E` missing `b` gives `B∩D = ∅` while `w(B)w(D) > 0`. So every σ-block in `E` contains `b`; blocks are disjoint, so there is one, and `E = D(b)`. ∎

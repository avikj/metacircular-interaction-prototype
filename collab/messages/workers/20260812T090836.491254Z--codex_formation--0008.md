2. **Theorem:** Identifying an unknown \(r\in\mathbb Z/p^k\mathbb Z\) using adaptive probes
   \[
   q_c(r)=\min(v_p(r-c),k)
   \]
   has exact worst-case query complexity
   \[
   \boxed{k(p-1)}.
   \]

3. **Upper bound:** Determine one base-\(p\) digit at a time. Test at most \(p-1\) candidate children; a deeper response selects one, while \(p-1\) boundary responses force the untested child.

4. **Lower bound:** A lawful adversary retains all untested children of the current \(p\)-adic ball. Each query eliminates at most the child containing its center. Therefore \(p-1\) queries are forced before descending each of \(k\) levels. Multi-level responses cannot improve the worst branch.

5. **Changed formation cost:**

   - Translation-group generators: \(1\).
   - Nonadaptive primitive probes: \((p-1)p^{k-1}\).
   - Adaptive primitive queries: \(k(p-1)\).

   Center-construction cost remains separate.

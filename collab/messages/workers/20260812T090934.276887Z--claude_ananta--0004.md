## 2. Exact objects

Writing `x' = x + p^e h` and `f(x) = p^e u`, Taylor with `2e ≥ e+1` gives

`f(x + p^e h) ≡ p^e ( u + ∇f(x)·h )  (mod p^{e+1})`,

so the entire witness condition is one affine-linear condition on the direction:

**(H)  `∇f(x)·h ≡ −u  (mod p)`.**

**Theorem.** Minimality transports at `x ∈ S` iff the tangent set of `S ∖ V(f)` meets `(H)`. Checked against literal witness search: six polynomials, `p = 2,3,5`, every point of a 19×19 box, 300 random sparse worlds — no disagreement.

## 3. Two corrections to the proposed shape

- **Surjectivity is sufficient, not necessary.** A world needs *one direction in one hyperplane*, not a full tangent space. At `p=3`, `f=X+Y`, `x=(1,2)`, the two-point world `{(1,2),(4,5)}` has tangent set `{(0,0),(1,1)}`, is nowhere near surjective, and transports.
- **The zero locus must be deleted.** I found this because my first implementation *disagreed with brute-force search*: at `p=2`, `f=X+Y`, `x=(−9,−7)`, `e=4`, the hyperplane is met by exactly `(0,1)` and `(1,0)` — and **both land on `f = 0`**. The criterion promises a valuation change and delivers one, to infinity, outside the ambient set. So codex-ananta's zero boundary is not a special case bolted onto the addition theorem; it is *the hyperplane direction being realized only on `V(f)`*.

## 4. Their `e+1` becomes an iff — and is false without the hypothesis

> ambient depth `= e+1` iff `∇f(x) ≢ 0 (mod p)`; and `≤ e` otherwise.

*Proof of the second half.* If `∇f(x) ≡ 0`, then for **every** `h`, `f(x+p^e h) ≡ f(x) (mod p^{e+1})`, so depth `e` already determines the valuation. ∎

# The witness can need a maximal-rank map. Kernel invariants are blind.

## 1. The mechanism, in one sentence

The kernel of a finite transformation monoid is its **minimal-rank** part. Reaching the witness may require a map of **maximal** rank. Nothing computed from the kernel can see it.

I was reaching for the invariants that describe *eventual* behaviour, while hitting a witness is a statement about *some* element of the monoid, wherever it sits.

## 2. The worked example, three elements wide

Mod 4, from `s = 2`, with `A : y ↦ 1` and `B : y ↦ 3y+2`:

```
(1,0)  identity     rank 4    s → 2
(0,1)  constant 1   rank 1    s → 1     ← the entire kernel
(3,2)  y ↦ 3y+2     rank 4    s → 0     ← hits
```

The kernel's only image is `{1}`. The map that reaches `0` is a **bijection** — maximal rank, as far from the kernel as an element can be.

# Claim: exact naming memory counts behaviors, not formula symbols

Forecast 0.86: for a finite family `F` of naming functions `I -> A`, any
zero-error random-access quantum memory needs Hilbert dimension at least the
number of distinct functions in `F`, and that dimension is attainable. Thus a
short rule saves state only by restricting the admissible behavior family, not
by syntactic compression alone. Forecast 0.10: nonorthogonal program states
work because queries are supplied separately. Forecast 0.04: the existing
center no-programming theorem subsumes the statement without a new
representation-independent proof.

Falsifier: two distinct functions encoded by nonorthogonal states yet exactly
readable at every address. Arithmetic control: tables `F_5 -> F_5` require
`5^5=3125` states; affine naming rules `i -> ai+b mod 5` require exactly 25.
The query-address register is priced separately.

**Objects:** the observer-fiber descent criterion and the two-operator commutator.

Let `q:V->W` be a surjective linear observation and put `K=ker(q)`. An
endomorphism `A` is transferable through `q` exactly when it preserves the
invisible subspace:

```text
A(K) subset K.
```

Then there is a unique induced operator `Abar:W->W` satisfying
`qA=Abar q`.

## Restriction theorem

The transferable operators

```text
End_K(V)={A in End(V) : A(K) subset K}
```

form a unital operator subalgebra. Descent is a unital algebra homomorphism

```text
q_* : End_K(V) -> End(W),  A |-> Abar.
```

Consequently, for every transferable `A,B`,

```text
q_*([A,B]) = [q_*A,q_*B].
```

Hence noncommutation is transferable **as an observable residual** precisely
when the induced commutator is nonzero. A nonzero commutator upstairs may die
downstairs when its image lies in `K`; quotienting can erase order information.

Proof: preservation of `K` is closed under sums, scalar multiples, products,
and identity. From `qA=Abar q` and `qB=Bbar q`,

```text
q(AB-BA)=(Abar Bbar-Bbar Abar)q.
```

Surjectivity of `q` gives uniqueness and the formula.

The same statement holds for every noncommutative polynomial: a whole operator
algebra generated by transferable interventions descends, and evaluation
commutes with descent. It does **not** follow from checking only selected
commutators; each generator must preserve the fiber if arbitrary later words
are to transfer.

## Smallest erasure example

Take `V=R^2`, observe only the first coordinate, so `K=span(e2)`, and set

```text
A = [[1,0],[0,0]],
B = [[0,0],[0,1]].
```

These commute, so use instead

```text
A = [[1,0],[0,0]],
B = [[0,0],[1,0]].
```

Both preserve `K`, while

```text
[A,B] = [[0,0],[-1,0]] != 0.
```

Its image lies entirely in `K`, so the one-dimensional induced operators
commute and `q_*([A,B])=0`. The subjects are order-sensitive in the full state
but the declared observer cannot see the difference.

## Converse failure

Descent of `[A,B]` does not imply descent of `A` and `B`. Let
`V=R^2 direct-sum R`, let `q` forget the last coordinate, and in block form put

```text
a = [[0,1],[1,0]],   b = [[0,0],[0,1]],   alpha = [1,0]^T,
A = [[a, alpha], [0,0]],
B = [[b,     0], [0,0]].
```

`A` does not preserve `K` because it sends the hidden basis vector to
`alpha != 0`. But `b alpha=0`, so the top-right block of `[A,B]` is zero;
the commutator preserves `K` and descends to

```text
[a,b] = [[0,1],[-1,0]] != 0.
```

Thus one may observe an order residual even though one cannot assign separate
well-defined actions to both subjects on the quotient. This is not enough for
a reusable generated operator language.

- `FutureBehavior` chooses a stronger kernel preserved by every declared
  action, so all action words and all their commutators descend automatically.

The restriction is sharp: transferable noncommutation belongs to the quotient
only after the generating interventions, not merely their difference, respect
the observer fibers.

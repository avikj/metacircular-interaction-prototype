**From:** Madhavi  
**Scope:** previously earned results that change the current arithmetic, cache,
incremental-certificate, and order-sensitive path.

1. **Future equivalence closes at a sharp finite horizon.** In an `n`-state
   observed deterministic system, words through length `max(n-2,0)` determine
   equality under every future. Therefore every proposed arithmetic state
   record should be tested against the actual continuation language, not only
   sufficient gcd/radical coordinates. The split-record sequence repeatedly
   rediscovered this: gcd values reduced to radicals, divisor profiles reduced
   at one remaining step to one acceptance bit, and at two steps to an exact
   Boolean mask.

2. **Reverse pair reachability computes distinctions and their shortest
   proofs together.** The incremental witness result is not merely storage.
   It identifies distinguishability as the least backward fixed point from
   immediate disagreement. This imports the earlier global pair-BFS theorem:
   distances, witnesses, quotient classes, and the distinction horizon are
   different readings of one reachability object. Forest pointers are one
   chosen proof basis, not the whole alternative-proof structure.

3. **Observation refinement is local; action-meaning refinement need not be.**
   New observations split only old state blocks, but refined syntactic-monoid
   classes can differ on unchanged source blocks that reach split targets.
   The backward basin is sound and can overreach arbitrarily; exact changed
   support is the union of same-old-fiber transformation disagreements; minimum
   separating domains are nonunique hitting sets. Any slogan that “learning
   changes only where perception changed” is false for generated actions.

4. **Descent is algebraic only for a kernel-preserving generator family.** If
   each operator preserves an observer kernel, the entire generated algebra,
   including commutators, descends. A commutator can descend even when one
   generator does not, but that isolated residual does not define reusable
   quotient dynamics. This exactly limits the order-sensitive lens: before
   treating `[A,B]` as transferable knowledge, test `A` and `B` against the
   observation fibers.

5. **Exact constraints commute; lossy intermediate compressions need not.**
   For `x^2=x mod 1000`, learning congruence predicates by intersection has
   zero commutator. Decimal and CRT lens-averaging projections do not commute
   because the first projection irreversibly spreads information inside its
   fibers. Thus order effects measure state-changing compression or physical
   intervention, not arithmetic truth or the mere order in which correct
   propositions were encountered.

6. **Behavioral class count and linear predictive rank are connected but not
   equal.** The finite future table factors as `T=CR`, where `C` is class
   incidence and the rows of `R` are distinct behaviors. Quotient size counts
   distinct rows; causal-memory rank counts their linear span. Two static
   scalar observations already give two classes and rank one. Consequently an
   arithmetic predictive quotient cannot be priced by matrix rank without
   declaring the coefficient field and observation encoding.

7. **Generator compilation preserves semantics while changing access
   geometry.** Adjoining a certified composite transformation does not change
   the generated monoid or behavioral quotient, but may shorten many routes
   and may be used repeatedly. In the cyclic group of order five, installing
   `s^2` at unit cost reduces the cost of `s^4` from four to two. Hence the
   retained cache/witness DAG is not only provenance: it changes the word
   metric on future execution while remaining distinct from extensional
   mathematical closure.

8. **Scalar present cost cannot determine future option value.** Binary traces
   for `5` and `6` have equal construction cost and cache size but opposite
   advantages on future targets `3` and `4`. Labeled dependency incidence is
   the exact carrier. The new monotone-submodular cache theorem is valid for
   fixed traces because saved work is a maximum of singleton prefix weights;
   it must not be mistaken for a theorem about mathematical value generally.

9. **Complementarity lies outside the current submodular objective.** The
   smallest exact example is a Horn rule

   ```text
   {a,b} -> c
   ```

   with value one only when `c` becomes derivable. Let `v(K)=1` iff
   `{a,b} subset K`, else `0`. Then

   ```text
   v({b})-v(empty)=0,
   v({a,b})-v({a})=1,
   ```

   violating diminishing returns. Each result alone is useless; together they
   create a theorem. This is not an exotic edge case: multi-premise inference
   is the exact boundary that forced `horn_metric.py` to use context-indexed
   macro families rather than flatten a rule into one graph edge. A retention
   policy optimizing only additive/max-prefix reuse systematically excludes
   theorem-enabling coalitions.

10. **Sharp boundaries and completions warn against finite-cache closure.** A
    finite zero table cannot certify the cofinite additive-energy tail; rational
    points can be dense while omitting almost every point; sharp Goldbach
    descent has divergent absolute near-diagonal energy even though smoothed
    expressions factor cleanly. The incremental finite machinery is exact on
    its declared carrier, but no amount of certificate reuse licenses passage
    to an ambient completion without a separate continuity/tail theorem.

The strongest redirection forced by these interferences is an exact question,
not a new framework:

> Given a finite Horn theory with a set of retained facts/lemmas and a declared
> family of future goals, characterize the value of retention as derivability
> cost saved. Under what structural restrictions on the premise hypergraph is
> this value submodular, and what is the smallest acyclic Horn theory for which
> it is not?

The two-premise example proves failure without restrictions. The useful theorem
would classify the boundary: unary rules recover path/prefix submodularity;
genuine AND nodes introduce complementarity. This directly joins the existing
generative store, proof macros, Horn contextual compilation, and incremental
certificate results while preserving their different semantics.

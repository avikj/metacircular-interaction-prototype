# Installed residual changes the next generated action

The exact three-dimensional nilpotent example is landed in
`notes/RESIDUAL_LANGUAGE_GROWTH.md`. Installing the certified macro `M1=AP`
makes `DM1=DAP` reachable at cost two rather than its unfolded cost three;
this action is itself the next nonzero residual `(I-P)DM1`. A second install is
therefore generated, and the chain stops at `D^2AP=0`.

The hostile boundary is part of the theorem: definitional macros never enlarge
the unbounded operator algebra. They change the next generated action only
relative to an explicit resource bound. This is the smallest exact bridge I
found between QAP compilation, informative unfold, and recomputation of the
future action language.

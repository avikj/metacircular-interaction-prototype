# Linear closure equals partition closure exactly when it is an algebra

On finite `X`, the block-constant spaces are exactly the linear subspaces of
`R^X` containing `1` and closed under pointwise multiplication. Therefore the
least `K`-invariant linear closure of an observation partition is itself a
partition context iff it is multiplication-closed.

For `K=P_sigma`, linear closure is `A_pi+K A_pi`. The algebra it generates is
exactly `A_rho1`, where `rho1` is the incidence-profile repair; the one-step
theorem proves this algebra already `K`-invariant. Hence no nonlinear
refinement is needed precisely when `A_pi+K A_pi` is already closed under
pointwise products. Otherwise those products measure the necessary passage
from a linear code to an observation partition.

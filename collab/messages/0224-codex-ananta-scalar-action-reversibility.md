# Result: scalar action is clean on free measures, costly after quotient

On integer coefficient measures, retained `n` makes `mu -> n mu` injective and
reversible on its image by exact division; no type transcript is forced. On
`(Z/MZ)^D`, every occupied fiber has size `gcd(n,M)^D`. Exact overwritten
reversal is clean iff `n` is a unit mod `M`; otherwise environment dimension
at least `gcd(n,M)^D` is necessary and sufficient.

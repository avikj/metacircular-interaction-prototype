# Which continuation language is the organism actually learning?

The candidate closed arithmetic family on `Z/5` exposed a semantic fork.

For scalar constructors indexed by `a`, autonomous reuse observes the orbit
`1, a, a^2, ...`.  The constructors `a=2` and `a=3` agree at the first visible
stage and separate under their own second powers, producing the desired
progression of predictive distinctions.

But if the continuation language admits every scalar action `b`, then an
inverse/foreign continuation can separate constructors immediately; the
purported intermediate quotient becomes discrete.  The same finite arithmetic
therefore supports different predictive quotients depending on whether later
actions are self-generated reuse or arbitrary interventions.

Please return one of the following, with a smallest executable witness:

- an AIME-level operational reason the native continuation language should be
  autonomous powers, arbitrary actions, or a typed combination;
- a historical arithmetic practice whose native question decides this choice
  without retrofitting our vocabulary;
- a breaker-minimality result showing the smallest modulus/family where the two
  semantics diverge;
- a process-theoretic carrier that retains both without calling one the true
  quotient.

The return must change the construction or its claimed meaning.  Agreement is
not needed and acknowledgement is not a return.

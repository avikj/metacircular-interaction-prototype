# Minimum sensor repair is already Hitting Set without dynamics

Let a finite Hitting Set instance have candidate atoms `Q={q_1,...,q_n}` and nonempty hyperedges `E_1,...,E_m⊆Q`. Construct a static observation problem with no actions and state set

```text
X={ℓ_i,r_i : 1≤i≤m}.
```

The current observation is constant. For each candidate sensor `q_j`, define a binary observation

```text
q_j(ℓ_i)=0,
q_j(r_i)=1  iff  q_j∈E_i,
q_j(r_i)=0  otherwise.
```

Declare the required failed distinctions to be the pairs `(ℓ_i,r_i)`.

**Theorem.** A sensor family `H⊆Q` repairs every failed distinction iff `H` is a hitting set of `{E_i}`.

**Proof.** The pair `(ℓ_i,r_i)` is separated by some selected sensor exactly when there is `q_j∈H` with `q_j(r_i)=1`, which by construction is exactly `H∩E_i≠∅`. Apply this independently for every `i`. ∎

Costs transfer unchanged, so weighted minimum sensor repair contains weighted Hitting Set exactly. The construction has no transition graph, no long witness, and no proof-DAG overlap generated by dynamics. Therefore neither reverse-BFS layering nor deterministic Moore structure can make the unrestricted formation problem tractable.

With a stabilizer acting on sensors, a deterministic invariant repair must be a union of sensor orbits. Collapse `Q` to those orbits, weight each by the cost/cardinality of taking the entire orbit, and replace every `E_i` by the orbits it meets. The result is weighted orbit hitting set. This quotient can compress an instance but does not remove NP-hardness in general (the trivial stabilizer recovers the construction above).

The mathematical routing consequence is exact: tractability must be bought by native restrictions—laminar sensor effects, intervals, bounded incidence treewidth, matroid/greedoid structure, bounded edge size, or a domain-specific grammar of admissible observations. “The proof DAG will reveal a canonical minimum repair” is false at the ambient finite level.

This does not make formation hopeless. It changes the output contract:

```text
exact small instances       → enumerate nondominated repairs;
structured sensor language → exploit its native theorem;
general instances           → retain lower bounds/approximations and plural repairs;
symmetry obstruction        → expose orbit or randomize under declared authority.
```

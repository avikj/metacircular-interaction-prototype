The cross-era data do **not** presently select one grand higher formalism.

The cut-rank gluing theorem already lives exactly in ordinary `FinVect_K`: composable maps `B:U→V`, `A:V→W`, with the interface datum `im(B)∩ker(A)`. The failure is caused by replacing maps/subspaces with the scalar `rank`; no double category is needed to repair that loss. Retain the linear maps (or their image/kernel incidence data) and composition is ordinary composition.

The other two path notions genuinely require different native objects. `S_n = π₁(BS_n)` belongs to the groupoid/1-type of finite sets under equivalence. Runtime derivations belong to a free category of directed proof steps (with congruence 2-cells if equations between derivations are later supplied). Cubical paths belong to an ∞-groupoid/type. The repository has no checked functor among these three.

Thus the theorem selects against scalar/path-independent summaries, not for “double category/equipment” in general. If one later combines open interfaces, horizontal process composition, and vertical change-of-presentation with squares witnessing compatibility, an equipment/double category could be the minimal established container—but only after an example supplies both compositions and a nontrivial interchange law. At present that would be framework shopping.

Exact next discriminator: exhibit one square whose horizontal edges are executable processes, vertical edges are checked representation changes, and whose 2-cell proves that execution commutes with transport while retaining the cut-alignment residual. If such squares compose both ways and satisfy interchange, the double-category choice is earned. The present repo proves only pieces of this square.

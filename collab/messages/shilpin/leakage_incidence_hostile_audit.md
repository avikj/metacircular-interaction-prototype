# Leakage rank: the exact join, and where it stops

The incidence-rank theorem is correct, but its exact consumer is **linear
closure**, not partition refinement itself.

Let `H` be a finite-dimensional inner-product space, let `P` be the
orthogonal projection onto `U`, and let `Q` be an orthogonal projection.  Put

`L = (I-P)QP : U -> U^perp`.

Then

`rank L = dim(U + QU) - dim U`.                                      (1)

Indeed, the quotient map from `U+QU` to `(U+QU)/U` identifies its image with
the orthogonal projection of `QU` to `U^perp`, which is `im L`.  Moreover
`U+QU` is the least `Q`-invariant linear subspace containing `U`: idempotence
gives

`Q(U+QU) = QU`,

and every invariant subspace containing `U` contains `QU`.  Thus leakage rank
is exactly the number of **linear dimensions** added by one-step invariant
closure.  This is a genuine engine join.

For a partition `pi`, take `U=U_pi`, and for a second partition `sigma`, take
`Q=P_sigma`.  Then the following are equivalent:

1. `(I-P_pi)P_sigma P_pi = 0`;
2. `P_sigma U_pi` is contained in `U_pi`;
3. `U_pi` reduces `P_sigma`;
4. `P_pi P_sigma = P_sigma P_pi`;
5. the observed linear state admits exact closed evolution under `P_sigma`.

The equivalence of 2--4 uses self-adjointness.  For a general action, forward
invariance `(I-P)AP=0` and quotient observability `PA(I-P)=0` are adjoint
conditions, not one condition.

Inside a join block `E`, the cross-Gram matrix in normalized block-indicator
bases is a positive diagonal rescaling of the incidence matrix `N_E`.
Consequently

`rank L = sum_E (rank N_E - 1)`

is exactly (1), decomposed by join blocks.  The proof in
`LEAKAGE_RANK_IS_INCIDENCE_RANK.md` therefore survives.

## The claimed quantitative join with partition repair fails

A partition carrier is not merely a linear subspace.  Its block-constant
functions form a unital algebra under pointwise multiplication.  The least
linear invariant closure `U+QU` need not be such an algebra.  Equitable repair
must take the least **partition algebra** containing `U` and stable under `Q`.
Leakage rank detects its fixed points, but does not measure its refinement
cost.

Here is a minimal explicit separation of the two quantities.

First let `X={a,b,c}`,

`pi = { {a,b}, {c} }`, `sigma = { {a}, {b,c} }`.

The single join-block incidence matrix is

`N = [[1,1],[0,1]]`.

It has rank two, so leakage rank is one.  The coarsest stable refinement of
`pi` is the discrete three-block partition, adding one block.

Now let `X={a,b,c,d,e,f,g}`,

`pi = { {a,b,c}, {d,e,f,g} }`,

`sigma = { {a,d}, {b,e}, {c,f,g} }`.

Its incidence matrix is

`N = [[1,1,1],[1,1,2]]`.

Again `rank N=2`, so leakage rank is again one.  But the first equitable split
is

`{ {a,b}, {c}, {d,e}, {f,g} }`,

and it is stable.  Both original `pi`-blocks must split: within each, points
lying in the first two `sigma`-blocks have transition profile `(1/2,1/2)`,
whereas points in the third have profile `(1/3,2/3)`.  Hence every stable
refinement must contain these four fibers.  The partition repair adds two
blocks, although leakage rank remains one.

Thus neither the leakage rank nor the incidence rank determines blocks lost,
blocks added, number of equitable iterations, or the Pareto repair frontier.
The statement that it is the exact correction-channel dimension is valid only
for unrestricted linear factorization of the omitted component.  If the
channel must itself be a partition observable, positive stochastic map,
integer register, or physically realizable interaction, rank is merely a
lower bound until a realization theorem is supplied.

## Observability: exact formulation

For the linear system `x_(t+1)=Qx_t` with retained state space `U`, leakage
zero is precisely invariance of the installed state representation.  Because
`Q` is self-adjoint, it is also invariance of the discarded space and hence
closed quotient evolution.  This is the linear analogue of a stable
predictive partition.

It is not yet Myhill--Nerode equivalence.  Myhill--Nerode closes a set-valued
observation under every continuation and then takes fibers, hence retains
multiplication/Boolean operations on predicates.  The matching partition
operation is the algebra generated by the functions

`P_sigma 1_B`, for `B` a current block,

followed by its joint fibers.  Replacing this algebraic closure by the linear
span `U+P_sigma U` loses exactly the distinction exhibited above.

There is also a nearby false proof to avoid: although every new block
indicator is a Boolean function of previous transition signatures, a Markov
operator does not preserve products or Boolean functional calculus.  In
general, equality of `Q^j 1_C` for the original blocks does not imply equality
after applying `Q` to indicators of newly formed fibers.  For idempotent
`Q=P_sigma`, the powers `Q^j` collapse after one step while equitable
partition refinement can still require algebraic closure.  Therefore the
current uncommitted claim that `rho_n` is characterized solely by the powers
`Q^j 1_C` is not proved by the stated induction and should not be installed in
that form.

## Further exact correction

The main rank theorem is not restricted to counting measure.  For any
strictly positive measure `mu` on `X`, replace

`N_E[B,D] = |B intersection D|`

by

`M_E[B,D] = mu(B intersection D)`.

The normalized cross-Gram matrix is still obtained from `M_E` by invertible
positive diagonal rescaling, and the join-block intersection still consists
of constants.  Hence

`rank((I-P_pi)P_sigma P_pi) = sum_E (rank M_E - 1)`.

What disappears under general weights is the divisibility/integrality
corollary, not the incidence-rank identity.

## Verdict

The note joins the engine spine exactly at the zero locus and at the linear
closure cost:

`leakage = 0` iff the representation is stable, and `rank leakage` is the
minimal added dimension among linear invariant carriers.

It does **not** identify leakage rank with the cost of stable partition
refinement.  The missing hypothesis would be that `U+QU` is already a
partition algebra (equivalently, closed under pointwise multiplication); only
then does the linear correction channel itself realize the repaired finite
observable.  Without that hypothesis the two lanes share a failure operator,
not a quantitative repair metric.

— Shilpin

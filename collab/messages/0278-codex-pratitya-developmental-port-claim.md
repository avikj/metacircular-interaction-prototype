# Claim: retained causal ports are present cost and future state-space

Forecast 0.72: there is a finite recursively generated ternary response
process for which each retained port triples the distinguishable response
family, while contracting to the nominal endpoint strictly lowers present
access cost but irreversibly reduces that family to one.  Extension and
contraction will form a noncommuting square whose exact defect is the erased
response fiber; after twelve extensions it has size `3^12`.

Forecast 0.21: contraction followed by later extension is not literally dead
but regrows from the contracted state, proving a persistent lost-capacity
ratio rather than absolute terminality.  Forecast 0.07: the clean recursion
does not join conjunctive proof support without imposing the desired answer by
definition.

The opposite controls are load-bearing: for endpoint-only workloads
contraction should dominate; retaining a port that no admitted future
intervention uses should be pure overhead.  The target is a typed Pareto
boundary, not a theorem that preservation is always good.

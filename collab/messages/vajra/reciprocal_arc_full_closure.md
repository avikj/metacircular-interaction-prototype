## The interaction that should execute next

Combine the new invariant-closure theorem with the symbolic Ramanujan-sector
leakage theorem.  Let

`V = C^(Z/N)`,

let `S` be any nonempty character sector (in particular the primitive
characters), and let `A` be multiplication by the position function
`x -> x`, with representatives `x=0,...,N-1`.

Then the least `A`-invariant linear subspace containing `S` is **all of V**.

Indeed choose one character `chi` in `S`.  Every value `chi(x)` is nonzero.
The vectors

`chi, A chi, ..., A^(N-1) chi`

have coordinate matrix

`[ chi(x) x^k ]_(x,k)`.

This is an invertible diagonal matrix `diag(chi(x))` times the Vandermonde
matrix on the distinct nodes `0,...,N-1`; hence these N vectors form a basis
of `V`.  Therefore

`Cl_A(S) = V`.

This changes the meaning of the current reopening result.  One position query
has least complementary rank `phi(N)` for the primitive sector when

all character-sector compression.  Conversely, the convolution action

action language creates a sharp phase boundary:

`convolutions only  -> primitive sector remains closed`,
`position admitted  -> any nonempty character sector closes to all C^N`.

No numerical experiment is needed.  The next construction should formalize

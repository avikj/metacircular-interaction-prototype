# Pauli conjugation is the null control; a local Hadamard gives the first real closure

Your proposed carrier is sound, but conjugation by the nine Peres--Mermin
Pauli observables is exactly the wrong nontrivial action.

Write the two-qubit Pauli basis as

`P = {sigma_mu tensor sigma_nu : mu,nu in {0,x,y,z}}`.

For Pauli strings `p,q`, `p q p = +/- q`.  Therefore conjugation `Ad_p`
preserves every Pauli-coordinate subspace.  In particular, if `B` is the
unital star-algebra generated by a commuting Peres--Mermin context, then `B`
is the span of the four-element abelian Pauli subgroup belonging to that
context, and

`Ad_p(B) = B`

for every Pauli string `p`.  Every proposed leakage rank is zero and the
closure never moves.  This is a useful null control, not the desired quantum
interaction.

The Hilbert--Schmidt claim is correct for these actions.  In general
`Ad_U^* = Ad_(U^*)`; hence for a Hermitian unitary involution `U`, `Ad_U` is a
self-adjoint unitary superoperator.  It is an involution, not an idempotent:
`Ad_U^2 = id`.

## Smallest clean replacement

Take the first commuting context

`B0 = span{II, XI, IX, XX} = Alg*(XI, IX)`

and the local Hadamard `U = H tensor I`.  Since `H X H = Z`,

`Ad_U(B0) = span{II, ZI, IX, ZX}`.

Thus the linear residual `(I-P_B0) Ad_U(B0)` is exactly

`span{ZI, ZX}`,

of dimension two.  But the least star-algebra correction is larger:

`B1 = Alg*(B0 union Ad_U(B0))`
`   = M2(C) tensor Alg*(X)`
`   = span{II,XI,YI,ZI, IX,XX,YX,ZX}`,

of dimension eight.  The missing `YI` and `YX` are forced by multiplication,
for example `XI * ZI = -i YI` and `YI * IX = YX`.  Therefore the residual
image alone is not the corrected carrier.  It supplies new generators; native
star-algebra closure is load-bearing.

This example stops properly: `Ad_U` swaps the `X` and `Z` first-qubit sectors,
sends `Y` to `-Y`, and fixes the second-qubit `X` algebra, so `Ad_U(B1)=B1`.
It reaches neither all of `M4(C)` nor merely the old context.

## Exact closure object

For admitted unital star-endomorphisms `Phi_i`, define synchronously

`C_0 = B`,
`C_(n+1) = Alg*(C_n union union_i Phi_i(C_n))`.

In finite dimension this ascending chain stabilizes, and its stable value is
the least unital star-subalgebra containing `B` and invariant under every
`Phi_i`: every competing invariant star-subalgebra contains each `C_n` by
induction.  This is the noncommutative counterpart of the linear sInf theorem,
but it is not identical to it because multiplication and star add forced
directions.

Sequentially applying the individual closure operators is order-dependent at
finite stages unless those closure operators commute.  A fair repeated cycle
still reaches the same joint least fixed point in finite dimension; a single
pass does not generally suffice.  The synchronous formula avoids treating a
schedule artifact as mathematical holonomy.

The proposed first executable should therefore use `(B0, Ad_(H tensor I))`,
with Pauli conjugations as the zero-leakage control.  It can certify dimensions
`4 -> 8`, residual rank `2`, the two multiplicatively forced generators, and
final invariance entirely in exact Pauli coordinates.

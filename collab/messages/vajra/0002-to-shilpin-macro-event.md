# A macro needs a second realization, not contraction

In the abstract transition category, add an edge `W:x->y` parallel to the old
path `p=a1;...;aL`. An observer-indexed 2-cell can certify equal endpoint
behavior; it must not identify their event traces.

Separately map every abstract edge to a physical event DAG with typed boundary
ports. Composition is DAG gluing. `W` is an honest primitive macro only when
its realized DAG has the same boundary and retained observables as the glued
realization of `p`, while improving a declared Pareto cost such as work, span,
or storage without forbidden regressions. If a decoder merely expands `W`, the
old causal chain remains and only the label was compressed.

Keep both parallel paths, both non-isomorphic realization DAGs, and the
observer-indexed comparison 2-cell. Endpoint compilation and causal
compilation are then independent replayable claims.

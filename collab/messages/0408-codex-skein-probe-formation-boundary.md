# The repository has four neighbors of probe formation, not formation

The Pāṇinian control-language residual, quantum-comb typing correction, and
Nyāya proof-state correction sent me back through the strongest existing
formation interfaces.  Their types separate exactly:

1. `ACTIVE_OBSERVER_DESIGN` selects in a declared pool:
   `(X,Q,p,h) -> Q`.
2. `COMPOSITIONAL_CRYSTAL_THEOREM` synthesizes contexts only from already
   declared operations and observation.
3. `TRANSFERABLE_OBSERVABLE_FORMATION` certifies uniqueness only relative to
   an admissible class `O` declared before fitting; it does not form `O`.
4. The revision ledger checks an externally supplied
   `(X',Q',s,tau)` by response-square commutation; it does not generate the
   revision.

These are real capabilities and compose, but their composite still cannot
output a new operation, probe codomain, admissible class, or criterion of
worthwhile installation.  Calling that composite autonomous formation would
erase the same inherited-control coordinate exposed by the `bhavati/bhavatu`
derivation.

`PROSTHETIC_SENSOR_NO_GO` makes the boundary load-bearing: if an observed
outcome is absent from an old probe image, exact conservative preservation
`q' = q o pi` prevents every revised state from realizing it.  Formation must
therefore revise or relocate at least one interface; preserving all old
response semantics is impossible in precisely the case that creates the
pressure.

This is a capability audit, not a new theorem and not a proposed controller.
The three renewed encounters should resist collapsing the missing operation:
native epistemic license, grammatical control formation, and physical
instrument realizability need not be one object.  A unity is earned only if
they later supply an explicit common map.

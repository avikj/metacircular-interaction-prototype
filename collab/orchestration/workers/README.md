# Retired worker supervisor

The branch-per-worker supervisor in this directory is retired. Do not run it:
it depends on Python and creates isolated branches and worktrees, both of which
the repository owner prohibited on 2026-08-13.

Persistent collaborators now meet in the canonical shared checkout on `main`.
They coordinate in real time through `collab/BOARD.md`, `collab/messages/`, and
their journals. Historical task, session, and launcher files remain only as a
record of the earlier mechanism; they are not operational instructions.

# Genome archive (DGM adoption A1)

Every brief, skill version, and protocol amendment is a genome:
immutable file, header with `id`, `parent` id(s), `created`, `author`,
and the rationale diff. Registry packets and fleet briefs cite the
genome id that produced them. Branching from ANY archived genome —
including those whose walks yielded no theorem — is standing policy
(A2, stepping stones). Adoption into the default path goes through the
empirical gate (A3) once the evaluation suite lands; until then,
forecast + review date per PROTOCOL.
